# Godot 開発セッション

目的: エディタを開かず、ユーザーの画面やマウスを占有せず、実際のゲームを継続して確認・更新できるようにする。

既存の Godot MCP Toolkit はエディタ経由の制作には有効だが、本プロジェクトはテキスト制作を採用している。最初の実装はエディタや追加パッケージを必要としない SceneTree ランナーと Python CLI にする。通常起動・project.godot の autoload は変更しない。

- Godot プロセスを一度起動し、localhost TCP の JSON 行メッセージで制御する。
- headless は挙動確認、render は隠したウィンドウと専用 SubViewport による画像確認。音とマウス捕捉を抑止する。
- シーン読み込み/再構築、ノード検索・状態読み取り・プロパティ設定・メソッド呼び出し、入力 action、正確な物理フレーム送り、PNG 出力を提供する。
- GDScript.reload(true) で既存インスタンスの状態を保ってコード更新する。構文エラーは返し、前のコードに戻す。継承・シグナル・初期化処理・インポート済み素材などの構造変更はシーンの再構築や素材インポートが必要で、万能な差し替えとはしない。
- 起動は既存の自分のセッションを再利用する。停止は自分のサーバーに shutdown を送る。第三者の Godot は終了しない。
- セッション情報・ログは godot/.godot/dev_session に保存する。CLI は依存なしの Python 標準ライブラリ。明示的起動のみで動く開発用アドオン。

検証: 実エンジンとの往復、同一 PID でのシーン更新・スクリプト更新と状態保持、物理フレーム数、構文エラーからの復帰、画面非表示の PNG、実際の motion_lab の走行と煙を確認する。既存の無関係な全テストは繰り返さない。
