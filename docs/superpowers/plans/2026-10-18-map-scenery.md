# MAP景観と当たり判定の改修

目的：拠点MAPの「見た目だけ」の実物を、形に合う静的当たり判定と、前回のローポリ密度に揃えた見た目へ変更する。通路・会社入口・軽トラ積み込み・機材置き場・廃材ヤードの破れ目は維持する。

- 会社側 production_office.gd：車庫・車両・小物・家具・植栽・街灯・歩道。既存の良いモデルを優先して再利用。
- 区側 ward_lot.gd / dump_dressing.gd：清掃車・倒れたフェンス・粗大ごみ・集積所・歩道。
- 周囲 production_yard.gd：近景倉庫の本体と電柱。遠景と電線は背景扱い。
- 追加景観：通路の脇 (66.4,0,8) に、完成済み郵便ポストを登録土台 feature_hooks 経由で設置。

判定は主な実体を少数の箱で構成し、脚の間・車体下・灯具の周囲・小屋の開口は空ける。壁ポスター、落書き、葉、細い電線へ一律の当たり判定は付けない。

検証：同一カメラの新旧画像、物理問い合わせで代表物体が遮ること、脚の下などの空間と移動経路が空いていること、CharacterBody3Dの実際の移動をまとめて確認する。既存 office_facade_test と feature_hooks_test、門が変わる場合の関連テストを必要範囲で流す。元の作業ブランチへマージしてpushする。別の未完成作業は含めない。
