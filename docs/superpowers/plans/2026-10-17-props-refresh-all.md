# 全小道具・大道具の置き換え計画

目的：`production_scrap.gd` の180種類を、承認された日本型自販機程度の品質へ揃える。既に良いとされた10種類は維持。簡略版の時計・街灯は再制作し、トイレは便器と台座の形を再修正する。

ユーザー指定の設計承認不要・過剰なテストを避ける方針を適用。既存の別作業は触らず、専用worktreeで制作する。まとまった完成品を元の作業ブランチへ反映してpushする。

品質と制約：実物写真／名称だけから生成した新規資料を参考にする。旧モデル画像は比較専用。輪郭・厚み・支持・開口・主要部品の配置を作り、微細な傷や裏側機械に時間を掛けない。種類名、順番、寸法指定、重さ、タグ、袋出現条件、用途を維持し、旧GLBは残す。扉や舞台セットの既存ヒンジ・可動部があれば維持する。比較は同じ照明・角度、左が旧、右が新。

全対象と進捗の正本は `godot/docs/PROP_REBUILD_MANIFEST.json`。原型ファイル名の凍結一覧は `godot/tools/prop_rebuild_baseline.gd`。

## 実行単位

- [x] 全180種類の一覧と、維持／要修正／未対応の状態を保存する。
- [x] 小物群A：指輪ケース、チョコ箱、香水、手鏡、扇子、日傘、花束、贈り物。
- [x] 機材群A：トランシーバー、ヘッドセット、ヘッドホン、レンズケース、卓上三脚、録音機、ミキサー、モニター。
- [x] 家具群A：監督椅子、ソファ、肘掛け椅子、スツール、食卓、机、バーカウンター、ベッド。
- [x] メイン担当：トイレの修正と、台所・生活小物のグループ。
- [x] 残りを用途別のまとまったグループへ割り当て、未対応がなくなるまで同じ制作・確認を繰り返す。
- [x] 更新した全カタログと比較ギャラリーを生成し、進捗を確定する。

各グループの成果物：専用 `assets/production/rebuild_<group>/source/` の生成コード、出典と特徴のメモ、実測manifest、`assets/production/scrap/` のGLB。統合担当だけが `production_scrap.gd` と進捗表を変更する。

検証：Blender書き出し時の有限頂点・範囲を確認。Godotで新旧比較、裏側、必要な開口部を目視。材質は実際のGodot表示で判断する。対象群ごとに `audit_props`、既存の `collider_fit_test`、袋の品があれば `junk_bags_test` をまとめて実行し、成功後に無関係な検証を繰り返さない。

トイレの注意：前の修正は逆円錐の便器と別の台座に見え、実物の連続する陶器の胴体として不自然。正面だけでなく真横から、床へ連続する下部と後ろのタンク支持を確認する。未修正を完成扱いにしない。

## 追加の制作方針（2026-10-17）

ユーザーから「もう少しローポリ」と指定。輪郭と主要部品を残し、円柱最大16角、回転体最大24角、小さいチューブ6角、面取り1段で生成する。共通の再生成コマンドは Blender CLI の `--python tools/build_lowpoly_props.py -- rebuild_<group>`。制作済みの38種類も同じ設定で再生成する。細部を増やす方向へ戻さない。

制作済みの38種類をローポリ設定で再生成し、Godotの正面・裏面比較と寸法／重さ／当たり判定監査を通過。この時点で既存承認済み10種類を含め48/180まで完了。小物B（探偵小道具8種類）も実装済み。

## 全件制作の最終バッチ

残り132種類を、建築23・屋内家具14・屋外家具22・撮影機材40・冒険／コメディ小物19・大型セット14に分けて制作。手順と出典は各 `rebuild_*/source/README.md` に保持。割り当てと袋出現属性は `godot/docs/PROP_REBUILD_ASSIGNMENTS.json` に保存し、無視対象の artifacts ファイルに再生成を依存させない。機材40種類はすべて袋から出るため処理券は付かず、処理券専用の余分な支持板を取り除く。

## 完了結果

全180種類：170種類を再制作し、承認済み10種類を維持。今回の132種類の前面・裏面比較とGodotカタログを生成。最終の `audit_props` は全件を制作グループごとに実行し、すべてエラーなし。既存 `collider_fit_test` と `junk_bags_test` は全差し替え後にともに通過。`production_scrap.gd` は file フィールド以外が元のコミットと一致することを確認し、ID・順序・寸法指定・重さ・タグ・配置・袋出現条件を維持。未対応なし。

比較画像の正本は `artifacts/props-refresh-all/comparisons.md`（180種類、左旧／右新）。新規モデルの「rebuilt」は実装・表示監査の完了を示し、個別のユーザー承認済みという意味ではない。修正後の機材群に票専用の支持板やアンカーはない。
