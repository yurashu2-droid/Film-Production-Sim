# 大型モニターとカメラ切り替え Implementation Plan

**Goal:** 大型モニターを使うスイッチ係と3台のカメラによる撮影を可能にする。
**Architecture:** 会社カメラAを残し、独立したCameraSwitcherで採用カメラ・操作係・追加機材を管理する。MonitorPopupで映像比較と合図を提供する。
**Tech Stack:** Godot 4.7、GDScript、SubViewport、既存ENet/RPC。
**Spec:** ../specs/2026-10-12-monitor-switcher-design.md

## Constraints

現状の未コミット変更を保存し、今回の完成した変更だけをcommit/pushする。エディタを使わない。狭い対象確認から始め、意味のある単位で検証する。承認待ちや作業ごとのサブエージェントは使用しない。

## Implementation

- [x] `tests/monitor_switcher_test.gd`で機能不在の失敗を確認する。実シーンで画面寸法、3台の実体、権限、本番の切り替え、見返し、操作解放を検証する。
- [x] `production_monitor_prop.gd`をキャスター付き大型モニターにする。`screen_size()`と映像差し替え対応の`attach(view)`を提供する。
- [x] `camera_switcher.gd`を追加する。実体カメラの作成・運搬、`camera()`、`request_control(who,on)`、`request_cut(who,index)`、採用状態の同期を提供する。既存モニターがない場合は自分で作成する。
- [x] `main.gd`に採用カメラのアクセスと記録・見返しを接続する。`production_main.gd`で管理モジュールを起動する。HUD、judge、追加注文、書き出しは採用映像を使い、撮影係のファインダーは各自のカメラを使う。
- [x] `monitor_popup.gd`を追加し、右クリック、1/2/3、合図、T、閉じる動作を接続する。小さな画面でも収まる寸法とする。
- [x] 対象テスト、実ENetの切り替え同期と途中参加、裏側の3D/画面キャプチャを確認する。`run_tests.sh`を一度実行し、関連する失敗を修正する。
- [x] 変更全体を一度確認し、完成した範囲だけをcommit/pushする。

## Review Focus

- カメラB/Cの操作中も、その撮影係のファインダーがAに戻らない。
- 撮影条件と追加注文の判定が実際の採用映像と一致する。
- 見返しの途中カットと終了時の採用カメラを正しく再現する。
- 離れた参加者や操作担当者以外からの切り替えをホストが拒否する。
- 途中参加と次の依頼でも、機材ID・採用カメラ・操作権が一致する。
