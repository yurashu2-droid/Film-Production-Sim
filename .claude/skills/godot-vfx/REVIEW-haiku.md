# Haiku が作った VFX のレビュー（「私ならこうする」）

2026-10-08。対象は、この日 Haiku 5.5 が作った（または Haiku の手順で作った）演出。
見た根拠は、ラボの連続コマ（全体・動き・終わり）。動画は見ていない。

## 全体に共通する問題（これが一番大事）

### 1. 終わりが「元の場所へ戻る」だった
稲妻・光線・帯・柱を、`grow` を下げて**先端を根元へ引き戻して**消していた（黒雷、五つの質感の型、大波、斬撃の一部）。
- 光線や稲妻は、根元へ戻る物ではない。電気は「供給が止まり、すでに出た分が先へ走り去る／ちぎれて消える」。
- 引き戻しは、巻き取りやゴムのような別の物に見える。見ている人は「本当にそう消えるか？」と引っかかる。
- **私ならこうする**：先端は戻さない。根元の供給を止め、**根元から先へ消す**（`eaten`）。外の層が先、芯が最後。先端側の欠片は、進んできた向きへ少し進んでから消す。
- 直した：`vfx_black_lightning.gd`、`vfx_flow_form.gd`（根元から消す）。

### 2. 地面の輪が「円が縮むだけ」だった
`stamp` の `hide` は外から中心へ円を狭める。それまで回っていた模様の意味が消える（水玉、大波、冷気の水、漫画の水しぶき、黒雷の地を這う）。
- **私ならこうする**：回転は止めず、`sweep`（扇形にぬぐう）と `cut`（模様がちぎれる）で消す。輪が複数なら始点と時刻をずらす。落ちた物（墨・水）で色が沈む、波紋が静まる、など「何かが起きた結果」として終える。
- 直した：上の五つ。

### 3. 作り方の判断を、自己採点で甘くした／止まった
- 不合格を自分で見つけて書いたのに、直さず報告した（4人中4人）。手順書に「報告前の関門」を入れて改善した。
- 大きさ（人の高さとの比）の判定が甘かった。漫画の水しぶきを「1〜1.5倍」と書いたが、私の目には1倍弱だった。
- **私ならこうする**：寄り（`--dist`）の画像で、円柱との比を数字で書く。迷ったら不合格にする。

## 演出ごと

### 水玉の魔法陣（水玉・泡・はじける）
- 良い：薄い殻の三層、泡から玉へ水の糸がつながる、青い破片を `cut` で消し切った。
- 弱い：はじけた後に上へ抜ける白い芯が、しばらく白い球に見える。玉が人に対して小さく見える。
- 私ならこうする：芯は球で抜けず、細く伸びて光の筋になって抜ける。はじけは「外の殻がほどけて広がる → 水滴が弧を描いて落ちる → 陣に波紋」まで一つの流れにする。

### 水の斬撃
- 良い：弧が板ではなく三層の帯になった。
- 弱い：外の濃い青が水色と区別しにくい。弧の後ろの細い筋が少し長く残る。
- 私ならこうする：外の層の色を暗くして層を分ける。弧は戻さず、尾を頭に追いつかせて流れ去らせる（これは実装済み）。振りの跡に、水が飛ぶ別の動き（しぶき）を足す。

### 冷気の水
- 経緯：淡い wisp の柱 → 板・結晶に見えて不合格が4回続いた。原因は私の指示ミス（淡い色の殻で霧は作れない）。
- 今：霧の塊が煙玉で、水の筋が細く、霧に見えない。
- 私ならこうする：霧の体を煙玉の連番で厚く（20個以上、色は `recolor()`）。水の筋は主役にせず、霧に飲まれて消える。終わりは「冷気が地面へ降りて、霜が溶けて水たまりに変わる」（霧→水に変わる）。

### 漫画の水しぶき
- 良い：白い塊と黒い輪郭をやめて、水の舌にした。集中線が1本ずつ違う。
- 弱い：全体が小さい。舌の層が束に見える。
- 私ならこうする：舌を一回り太く、7本 → 5本。落ちるしずくの尾を長く。しぶきの終わりは「舌が先端から垂れて、地面の水に戻って波紋になる」。

### 大波
- 良い：5本の中心線で面ができた。巻きと崩れが読める。
- 弱い：崩れの終わりが「高さを下げて引き戻す」。波は引くが、頂きの巻きは前へ落ちて砕けるはず。
- 私ならこうする：巻いた頂きを前へ落として着水、砕けて白い泡（煙玉）になり、本体は海へ溶けて波紋だけが残る。

### 黒雷（本体・渦・地を這う・赤黒い炎・一閃）
- 良い：層で作る方向は正しい。地を這うが一番読める。
- 弱い：黒より赤と白が強く、黒閃らしさが薄い。一閃は細すぎる。
- 私ならこうする：黒を主役に（外の層を太く暗く）、赤は縁だけ。一閃は「一本の太い黒い筋＋白い閃光＋画面の反転」にして、細い三本にしない。終わりは根元から消す（直した）。

### 質感の五型（鞭・球・輪・噴流・星）
- 良い：輪が一番まとまっている。
- 弱い：球が球に見えない（金の棘の花）。鞭と星に結晶のような棘の見え方がある。
- 私ならこうする：球は糸ではなく、殻を重ねた本物の球面＋表面を流れる筋にする。鞭は先端がしなってから、根元から消す。星は帯が放射して、先端が離れて飛んでから消える。

- 手順書：`hide` を使わない。光線・稲妻は根元へ戻さない（下の追記）。
