# 絵柄：パンクなペン画（癖のあるアニメ調）

2026-10-09。ユーザーが見せた参考絵（棘・包帯・赤い布・ギザギザの落書きのキャラ、シャッター、戦車）に合わせる時の決まり。
試作は `godot/vfx/vfx_punk_hit.gd` と `godot/vfx/shaders/punk.gdshader`（ラボ id `punk_hit`）。

## 絵柄の決まり（参考絵から読み取った物）

- 色は4つ：墨の黒、骨の白（少し桃色がかった白）、深紅、薄紫。**べた塗りだけ。発光・グラデーション・半透明は使わない。**
- 線はかすれたペン線。太さが揺れ、所々に二重の下書き線。影は斜めのハッチング。
- 形は鋭い：細い棘、角ばったギザギザ（稲妻の落書き）、ちぎれた赤い布、垂れるペンキ、ばんそうこうの×、落書きの記号。
- 丸い物・やわらかい煙・光の玉は、この絵柄に無い。

## 作り方

- カメラ向きの板に、形をシェーダーで直接描く（`punk.gdshader` の mode）。画像素材は使わない。
- 塗りと線の2色だけを返す。`unshaded`。HDR の値（1 を超える色）は使わない＝グローに乗せない。
- 線の震え：UV を小さなノイズでずらし、そのノイズを 8 コマ/秒で切り替える。動き自体は 12 コマ/秒。
- **赤は暗めに置く。** 0.78 で置くと画面の明るさ処理でピンクになった。0.55, 0.015, 0.045 で深紅に見える。
- 棘の束は、棘を細く（山の形のべき乗を 2 以上）、長さをばらつかせる。太いと葉っぱに見える。

## 終わり方（絵なので、絵として消える）

- 塗りが斜めに掻き消され、輪郭がかすれて点線になる（`wear`）。フェードや縮小はしない。
- ギザギザは、描かれた側から外へ走り去る。根元へ戻さない。
- 最後に残る小物（×印）を決めておくと、余韻になる。

## この絵柄で作れそうな物（未着手）

- 赤い布の斬撃（ちぎれた布の帯が走り、切れ端が落ちる）
- ペンキの垂れ（上から垂れて、壁や地面に落書きの記号が残る）
- 棘の地走り（地面から棘が順に生えて、折れて倒れる）
- 薄紫の稲妻（黒い輪郭つきの太いギザギザ。尾の飾り）
- 落書きの記号が叩きつけられる当たり判定マーク（王冠、どくろ、×）
- 鎖の拘束（鎖が巻きついて締まり、千切れて落ちる）

## 2D に見える 3D（2026-10-09。ユーザーの要望：「全部 2D 的なのはうーん。2D ぽいけど 3D な演出」「トーンも合いそう」）

板に描く 2D だけだと物足りない、と言われた。形は本物の 3D にして、塗りだけ 2D にする。試作は `godot/vfx/vfx_punk_spikes3d.gd`（ラボ id `punk_spikes3d`）。

- 塗り `shaders/punk3d.gdshader`：光の当たる面はべた、影は画面に貼りついたスクリーントーン（網点。影が深いほど点が大きい）、一番暗い面は墨。光の向きはカメラ基準で固定。
- 輪郭 `shaders/punk3d_ink.gdshader`：`next_pass` に付ける。裏面を画面上で外へ押し出す。太さは画面基準で、場所ごとに違い、8 コマ/秒で変わる。
- 形：棘は 5 角の円錐（`CylinderMesh` の上の半径 0）、布は `Lib.path_tube(点, 幅, 0, 2, 太さ)`（sides=2 で平たい帯になる）、稲妻は `Lib.path_tube(点, 太さ, 0, 4)`（四角い断面の角ばった棒）、破片は箱。
- **つるんとした円錐は「三角コーン」に見える。** 細く、角ばらせ、高さと傾きをばらつかせ、網点を大きく（`tone_scale` 64）、輪郭を太く（0.017）、主役に黒の斜め縞（`stripes`）を入れたら絵柄に寄った。
- 終わり：`wear` で網点が小さくなってはがれる。棘は倒れてからはがす。布は飛び去る。稲妻は上から消える。
- 注意：網点は画面に貼りついているので、物やカメラが動いても点は動かない（点の上を物が滑って見える）。この絵柄では味になるが、気になるなら物に貼る方式へ変える。
- 2D の板（落書きの王冠、ギザギザ、×）は、3D の物に添える飾りとして使うと、両方の良さが出る。

## パッケージ（2026-10-09）：`godot/addons/punk_ink_vfx/`

- 20種（小8・中8・大4）を `punk_fx.gd` 一つにまとめた。`PunkFx.spawn(parent, 地面の点, 種類, 大きさ, 配色, 速さ)`。`vfx/` には依存しない。
- 作りは「部品を足す関数」（板 `_board`、棘 `_spike`、破片 `_chip`、布 `_ribbon`、稲妻 `_bolt`、球 `_ball`）と、種類ごとの `_build_<種類>()`。動かす処理 `_pose` は全種類で共通。新しい種類は `KINDS` に1行と `_build_` を足すだけ。
- 見本 `demo/demo.tscn`、説明 `README.md`（英日）、テスト `tests/punkpacktest.gd`。
- はまった所：`_set` という関数名は Godot 本体（Object._set）と衝突してスクリプト全体が読めなくなる。部品の関数名に `_set` `_get` `_notification` などを使わない。
- 並べる時の向き：斜めの線を3本並べる時、ずらす向きを線と同じにすると1本につながって見える。線に直角にずらす。
- 薄い帯（sides=2 の筒）は、裏面が一番暗い影になって真っ黒になる。`punk3d` の `soft` を 0.45 にして影を浅くする。

## パッケージの作り直し（2026-10-09。ユーザーの指摘を受けて）

指摘：「同じパーツの組み合わせが多い」「斬撃が 2D しかない。3D 前提で」「大中小は大きさではなく、装飾や時間の長さ」「走りやポータルのような基本がない」「新しいパーツをちゃんと作る」。あとから「登場・煙・竜巻など、既存の物をこの絵柄にする手もある」。

- **数を増やす前に、部品を増やす。** 棘・ギザギザ・×の3部品で20種作ったら、すぐ見抜かれた。1種類ごとに「この演出だけの部品」があるかを確かめる。
- 足した 3D の部品（`punk_fx.gd`）：刃 `_blade`（ひし形断面の三日月）、土煙 `_puff`、飛ぶ破片 `_shard`、地面のひび `_crack`、置物 `_solid` ＋ コマ送り `_key`（あご・シャッター・じょうご・ポータルの輪）、鎖 `_chain`、渦 `punk_swirl.gdshader`。
- 2D の板は、落書きの印（×・王冠・警告・垂れ）と、脇の飾りだけに使う。主役は 3D にする。
- 規模：S は部品1つで短い。M は主役＋飾り。L は段階がある（予兆 → 本体 → 余韻）。
- 基本の演出を先に入れる：走り（一歩・急発進・ブレーキ・着地）、斬撃、当たり、煙、登場、ポータル。派手な大技はその後。
- ゲームと合わせるための合図 `cue(name)` を付ける（登場の "appear" など）。向きは `forward` で渡す。
- 既存の演出をこの絵柄に移す時は、形を素材から作り直す：竜巻は「縞のじょうご＋巻きつく布」、煙は「白と墨の塊が交互に昇る」、登場は「縞のシャッターが落ちて巻き上がる」（参考絵のシャッターから）。
- まだ弱い：単発の斬撃（皿に見える）、噛みつき（入れ歯に見える）、一歩の土煙（小さい）。

## 長尺（XL）：NO ESCAPE（2026-10-13。依頼は「大・多の五倍装飾つけて長いの一つ究極クオリティで」）

`godot/addons/punk_ink_vfx/ultimate/no_escape.gd`（種類 `no_escape`、22.4 秒、5幕、装飾およそ30系統）。部品は `ultimate/xl_parts.gd`。
見本は `demo/no_escape_demo.tscn`、動画は `C:\Programer___Amano\レッドパンク\vfx_showcase\no_escape_cut.mp4`（カメラ切り替え）と `no_escape_wide.mp4`（引きのまま）。

### 長尺の組み立て方（効いた順）

- **物語の作者役を一人置く。** 浮かぶスプレー缶が「描く → 書く → 署名して去る」。装飾が30系統あっても、缶の行動でつながる。
- **2D と 3D を行き来させる。** 地面に描いた牙（2D）が立体になり（3D）、叩き潰されて絵に戻る（2D）。この絵柄ならではの見せ場になる。
- **退場の表を先に作る。** 系統ごとに「何でできていて、どこへ行くか」を一行ずつ決めてから書く（飛び去る・千切れる・吊り上げられる・倒れる・絵に戻る・剥がれる・地面に呑まれる・掻き消される）。同じ退場が続かないよう時刻もずらす。最後に残す一つ（王冠の署名）も決める。
- **決めのコマ。** 噛む瞬間と叩き潰す瞬間に2コマずつ：1コマ目は白地に黒の影絵、2コマ目はその反転。全部の材質に `flash` を入れ、奥に画面いっぱいの板（集中線）、下に床を出す。静止画でも動画でも一番効いた。
- **時刻はコマ番号（12 コマ/秒）の定数で持つ。** 動きは「時刻 t の関数」で書き、前のコマの状態を持たない。どのコマからでも同じ絵になるので、コマ送りの確認と速度変更に強い。
- **幕ごとに密度を変える。** 予兆（地面と缶だけ）→ 封鎖（門・鎖で画面が埋まる）→ 罠 → 処刑 → 後始末（一つずつ減って、最後は署名だけ）。

### 画像を見て直した所（次も起きる）

- 最初の試し撮りが真っ暗（全面が墨の色）。初めて使うシェーダーは最初の一回が正しく描かれないことがある。撮影の道具では2回描いてから撮る。
- 立て札の札を放射の向きに向けたら、脇の札がカメラから真横になって見えなかった。看板は正面寄りに向ける。
- 缶を「下へ吹く向き」に素直に向けたら、底しか見えず黒い塊になった。逆さに立てて頭から吹かせると、横から見て缶と分かる。
- 地面の線は、引きのカメラだと 1px になる。m 単位で太め（輪 0.4 m、牙の枠 0.14 m）に描く。
- 手前の立て札が主役（罠の中心）に重なった。柱を短くし、正面の間隔を空けた。
- 白い球だけの爆発は「大きなボール」に見える。後ろに棘の破裂の板（2D の mode 0）を敷いて輪郭をぎざぎざにし、色の違う球を外へはみ出させた。
- 瓦礫（破片）は足し算で150個になり、地面の絵が読めなくなった。半分にして、ひびが塞がる時に地面へ沈める。
- 煙の柱が長く残って、次の見せ場（鉄球の引き上げ）を隠した。10個・短めにした。
- 落ちてきた鉄球が、閉じた牙をすり抜けていた。1コマ前に牙を押し開かせてから叩き潰す。
- 門が居なくなった後、門に付いた鎖が元の位置へ戻ってきた（居ない時の位置を 0 にしていた）。居ない間は、はるか上に居ることにする。
- 小さい物・遠い物の輪郭が墨の塊になる。`punk3d_ink` の `world_w` で、線の太さを m 単位の上限で抑える。
- 影の面が墨のべたになって赤が消える（左の門の上の箱）。`soft` を 0.4 にして網点にする。
