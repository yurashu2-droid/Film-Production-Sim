# 修正依頼 water-01：水の演出5種を「固体に見えない・多層・流れる」に直す

読む順：`../PLAYBOOK.md`（全部）→ この依頼 → 必要な時だけ `../SKILL.md`。
1件ずつ進める。1件ごとに PLAYBOOK 4章の画像3種を見て、問い1〜8の答えを報告に書く。

依頼主の言葉：「多重構造や固体感がなく流れるような動き」。今の5種はこれを満たしていない。

## 見本にしてよい物

- `godot/vfx/vfx_water_wave.gd`：5種の中で一番近い。中心線を毎コマ作り直して3層の殻を沿わせている。
  ただし筒の作り方は古い。`Lib.smooth_path` と `Lib.path_tube` に置き換えてよい。
- `godot/vfx/vfx_tornado.gd`：層の重ね方と、地面の模様を時刻をずらして消す方法。

## 1. vfx_water_orb.gd（例1：魔法陣 → 泡が一粒ずつ → 水の玉 → はじける）

**済（2026-10-08、Haiku 5.5 が3周で合格）。層の作り方・糸・ほどいて消す方法の見本にしてよい。** 残り：はじけた後に上へ抜ける白い芯が、しばらく白い球に見える。

以下は当時の依頼文。

今の問題（画像で確認済み）
- 玉が「模様のついた球」に見える。3層とも同じ半径で、1枚に見える。
- 泡が白い綿の塊に見える。小さすぎて層が読めない。
- 人に対して全体が小さい。

直すこと
- 玉の層の半径を外 1.0 / 中 0.65 / 芯 0.3 にする。外の層は `cut` 0.72 以上で、すき間から芯が見えること。
- 玉を真球のままにしない。集まる間は泡が入った側がふくらみ、落ち着くと下がやや重い形、はじける直前に縦に伸びる。層ごとの `scale` を別々に動かして作る。
- 泡が玉に入る時、泡から玉へ水の糸（細い `path_tube`）が1本つながってから吸い込まれる。瞬間移動させない。
- 泡は直径 0.5m 以上、数は 16 → 9。1層でよいが `cut` 0.7、`inner` 0.5 で暗い青を残す。
- はじけ：玉が消えて球の粒が出る、をやめる。外の層が先にほどけて広がり（`cut` を上げながら拡大）、芯が遅れて上へ抜ける。粒は直径 0.12m 以下。
- 全体を 1.6 倍（玉の半径 0.85 → 1.35、陣の直径も合わせる）。

## 2. vfx_water_slash.gd（水の斬撃）

今の問題：弧が `stroke` の3本だけで、青い板に見える。
直すこと
- 弧の本体を、弧に沿う `path_tube`（偏平でよい：置く側で奥行きの `scale.z` を 0.25）に wisp 3層で作る。
- 頭が進み、尾が追う仕組みは残す（中心線の点を頭と尾の間だけにする）。
- 振った後、弧の外側の層だけが遅れて残り、進行方向へ流れてほどける。
- `stroke` は芯の細い白線1本だけに使ってよい。

## 3. vfx_water_ice.gd（冷気の水）※未完。これまで4回試して不合格

題材：固体の氷は使わない。足元に霜の模様が広がり、冷気の霧が地面から昇り、上でまとまって広がり、降りながら消える。霧の中を水の筋が昇る。

これまでの失敗（繰り返さない）
- 淡い色の wisp で柱・傘・裾を作った → 白っぽい平たい板、割れた氷に見えた。
- 煙玉に替えたが、色が土煙のクリーム色のまま、数が少なく綿の塊に見えた。霜が明るすぎて白い光の円盤に見えた。水の筋が平たい青い帯だった。

直すこと（今のファイルは土台にしてよいが、書き直してよい）
- 霧：煙玉を 18〜24 個。PLAYBOOK 1章「煙玉の使い方」のとおり `rise` と `recolor()` を使い、青白い霧にする。地面の3か所から時刻をずらして昇り（0.2〜2.2秒に出る）、高さ 2.5〜3.5m で横へ広がる玉を足し、4.6秒までに全部の寿命が終わる。
- 水の筋：wisp 3層の細い `path_tube` を2本だけ（外の半径 0.35m、暗い青 → 水色 → 白）。霧の中をゆるく曲がりながら昇り、中心線は毎コマ揺らす。3.8〜4.2秒に cut を 1.0 まで上げ切って、霧より先に消す。
- 霜の模様：`stamp` 2枚。色は 1.0 前後に抑える（光らせない）。外径 6m。霧より先に出し、4.4秒までに消す。
- 光：淡い青の `lamp` を弱く。
- life は 5.8 のまま。id は `water_ice`、ラボの表示名は「冷気の水」で始める。

## 4. vfx_water_manga.gd（漫画の水しぶき）

今の問題：`Lib.cloud_mesh` の白い塊が小石に見える。落ちるしずくが単純な球。
直すこと
- 白い塊をやめる。しぶきは、着地点から外へ開く「水の舌」（`path_tube` を6〜8本、wisp 2層、先が細る）で作る。舌は立ち上がってから外へ倒れ、先端から地面へ戻る。
- 落ちるしずくは、縦長の wisp 2層＋後ろに引く尾。
- 集中線は残す（好評の可能性あり。ただし本数を 16 → 10）。
- 黒い輪郭は外す。

## 5. vfx_water_wave.gd（大波）

今の問題：太い1本の弧（チューブ）で、波の「面」がない。崩れ方が「縮む」だけ。
直すこと
- 同じ形の中心線を、奥行き方向に 5 本並べる（z = -1.6 〜 +1.6）。本ごとに巻く時刻を 0.08 秒ずつずらし、高さも ±10% 変える。これで面に見せる。
- 崩れ：頂きが前へ落ち、着水点から低いしぶきの舌が前へ走る。本体は根元側へ引き戻す。
- `Lib.smooth_path` / `Lib.path_tube` に置き換える。
