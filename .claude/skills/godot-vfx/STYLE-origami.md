## なぜこの絵柄にしたか（赤黒パンクの逆を選んだ）

| | 赤黒パンク | 折り紙 |
|---|---|---|
| 塗り | べた4色・墨の輪郭・網点の影 | 輪郭なし。面ごとの明るさで折り目を出す。場面の影を受ける |
| 模様 | 縞・落書き | 千代紙（麻の葉・青海波・市松・七宝・鹿の子）。表と裏で色が違う |
| 動き | 叩きつける・噛む・千切れる | 折る・立ち上がる・ひらひら落ちる・風で飛ぶ |
| 気分 | 処刑・封鎖 | 祭り・儀式 |

共通にしたのは、効いたと分かっている骨組みだけ：12 コマ/秒、時刻はコマ番号の定数、動きは時刻の関数、作者役を一人置く、退場の表を先に作る、決めのコマ。

## 絵柄の決まり

- 全部が紙。丸い玉・光の球・煙の塊は使わない（雲も切り紙、稲妻も紙垂の形、衝撃も蛇腹の輪と山折り）。
- 紙は表と裏で色が違う。折ると裏が出る（白い一枚を半分に折ると、朱の三角になる）。
- 面は平ら。頂点ごとのなめらかな法線は使わない（三角形ごとに法線を持たせる）。折り目は明るさの差で出る。
- 動きは 12 コマ/秒。折る・立つは「行き過ぎて、戻る」をコマの列で書く（例：鳥居 `[-86, -62, -28, 7, -3, 0]` 度）。
- 光るのは提灯・稲妻・炎だけ（紙越しの灯り）。ほかは光らせない。
- 終わり方：縮小・フェード・ノイズの穴は使わない。折りたたむ・ひらひら落ちる・風に飛ばされる・昇っていく・転がっていく・飛び去る。

## 作り方（次に同じ絵柄で作る時に使える物）

- **紙の材質 `shaders/paper.gdshader`**：明るさは自前で決め（`og_shade`）、場面の平行光源からは影だけを受け取る。
  `ALBEDO = col * s`、`EMISSION = col * (1 - 2s)`、`light()` で `DIFFUSE_LIGHT = 1 + ATTENUATION`（複数の光ではいちばん暗い値）にすると、
  日なたは `col`、影は `col * (1 - s)` になり、光の強さや環境光に左右されない（`ambient_light_disabled`）。`unshaded` だと影を受けられない。
- **どの面にどの色を出すかは、頂点の色で決める**（G＝表の面、B＝裏の面）。折り重なった層は「カメラ側が白・向こうが朱」「両面とも朱」が混ざるので、
  材質を分けずに `tri(..., shown)` で面ごとに指定する。R は明るさの掛け算（隣の面と少し変えると、折り目が読める）。
- **面を作る道具**（`origami_fx.gd`）：`tri` `tri_out`（外向きを自動でそろえる）`fan` `lathe`（蛇腹）`ribbon_mesh` `path_tube` `crane_mesh` `crumple_mesh`。
- **折りの手順**（`descent_crane.gd` の `_fold_shapes`）：折りの図を 2D の点で持ち、`_folded(点, 軸の両端, 角度, 向き, 浮かせ)` で一枚ずつ回す。
  数学的に正しい展開ではなく、手順ごとに「動かない面＋回る面」を描き直している（7手：半分・もう半分・つぶす・凧・花弁折り・脚を細く・首と尾）。
- **ひらひらする紙**（`_leaves` / `_leaf` / `_leaf_gust`）：MultiMesh 一つで数百枚。飛ぶ → 舞い落ちる → 寝る → 風に飛ばされる、を時刻の関数で書く。
  着地の時刻は、作る時に式をたどって求めておく。色はインスタンスの色、模様の番号は色の A、羽の角度と明るさは CUSTOM。
- **千代紙の模様**は式で描く（`paper_inc.gdshaderinc`）。遠くや斜めで細かくなったら、`fwidth` を見て、ならした濃さに寄せる（ちらつかない）。
- **決めのコマ**：全部の材質を一色（切り絵）にし、奥に画面いっぱいの板、下に床。主役（折り鶴）だけ別の色（朱）にすると、何が起きたか読める。
  `"flash": false` で切れる。

## 画像を見て直した所（次も起きる）

- 鳥居が舞台に対して小さく、主役の背景にならなかった。1.25 倍にした。
- 羽を広げた折り鶴が、正面のカメラから真横で一本の線に見えた。こちらへ向き直らせ、舞台を見下ろす角度にした。**薄い物は、カメラから見た面積を先に決める。**
- 決めのコマの床が、敷いた紙の下に隠れた（床を紙より低く置いていた）。床は一番上に置く。
- 決めのコマで全部が同じ色だと、主役が鳥居の影絵に埋もれた。主役だけ朱にした。
- 風に飛ばされる物の「重さ」を大きくしすぎて、屏風と幟が最後まで残った。重さを 1.3〜1.4 にそろえ、見える時間を延ばした。
- 紙垂の稲妻を細い紙垂の形のままにしたら、引きの画で点の列になった。幅 0.8 m の蛇腹の帯にした。
- 着弾で散る紙を上へ飛ばしすぎて、カメラの前を覆った。飛ぶ向きを低くし、落ちる速さを上げた。
- 見本の空を赤紫にしたら、朱の鳥居が沈んだ。藍に寄せた。提灯の灯りは 2.1 だとにじみで形が飛ぶので、1.5 に下げた。
- くす玉の椀は、内側が見える（`lathe` の面に出す色を、内側は裏の色にする）。
- 式神を白一色で作ったら、白い紙の中で見失った。袴を朱にした。
- 千羽鶴の連は、糸が無いと宙に浮いた鶴の格子に見えた。糸を足した。
- **回る親の子にした物へ「風で飛ぶずれ」を足すと、親が半回転したコマで逆向きに飛ぶ。** 幟の布（倒れて回る竿の子）が、1コマだけ画面の右へ長い白い帯になって出た。風に飛ばす物は、回る親の子にせず、演出の座標で動かす（幟の布、風車）。
- 幟の布を、位置ごとに違う速さで飛ばしたら、6 m の布が 40 m の帯に伸びた。旗のように風下へ流れてから、長さを変えずにちぎれて飛ぶ形にした。
- 紙垂の稲妻をコマごとに大きく回したら、真横を向いたコマで「白いまっすぐな線」になった（ユーザーが前に却下した形）。正面を向けたまま、少しねじるだけにした。

## 道具のはまりどころ

- 撮影の道具（`origami_shots.gd`）自体を直した時は、常駐の Godot に `reload` → `load` が要る（道具が読み直すのは、パッケージのスクリプトとシェーダーだけ）。
- 画面なしの自動確認は、出した直後のコマに時間が詰まる（1 秒目に 0.67 秒しか進まなかった）。「寿命で片付く」の待ち時間は、1 秒ほど余裕を見る。
- `SurfaceTool` に `get_instance_id()` は乱数の種に使えない。面ごとのばらつきは、頂点の位置から作る。
- Bash の heredoc に入れた長いパッチは、引用符で壊れる。パッチは Write で `.py` にしてから実行する。
- **全コマを小さく（320×180、12×8 枚）並べて見る。** 1コマだけの異常（上の白い帯）は、間引いたコマでは見つからなかった。`shoot` に `size` `cols` `rows` を渡す。

### 作り方（次に種類を足す時）

- `KINDS` に1行、`basic/` のどれかに `_build_<種類>()`。動きは `_act(func(t): ...)` の中に時刻の関数として書く。見える・見えないも毎コマ t から決める。
- 最後に残る紙は `_blown_node(物, 元の姿, t, さらわれる時刻, ばらつき, 見えている秒)` で風にさらう。風の向きは `OrigamiFx.wind`（ワールド）。
  進む向きのある種類は、`_face_blow(±1)` で「出どころへ戻らない向き」にそろえる。
- コマごとに入れ替える形（開く棘、走る三日月、ふくらむ風船、開く傘）は `mesh_*` が寸法ごとに一度だけ作って使い回す（`_cached`）。
  毎コマ形の変わる物（重ね切り紙の穴、紙テープ、巻いた紙）だけ、その場で作り直す。
- 出しっぱなしにできる種類（`fire` `guard`）は、終わりはじめる時刻を `_until` に持ち、動きの中では毎コマそれを読む。`finish()` が `_until` と `life` を書き換える。
  火の粉や煙のように繰り返す物は、周期で割った「今の一回ぶんの生まれた時刻」から動かす（前のコマの状態を持たない）。

### 画像を見て直した所

- **斬撃を水平に近い面で作ったら、横からのカメラで一本の線に見えた。** 面を二軸で傾けて（法線がおよそ (-0.58, 0.58, 0.58)）、前・横・上のどこからも面が見えるようにした。
- **ポータルを同心の蛇腹の輪（金・白・朱）で作ったら、的（まと）に見えた。** 藍の濃淡の切り紙を 4 枚、穴の形と回る向きを変えて奥へ重ね、いちばん奥に金の月を置いた。
  奥行きは、戸が開く時にせり出し、閉まる時に畳まれる（飛び出す絵本）。同系色の重ねは輪っかに見えにくい。
- **炎を三重に重ねたら、外の朱が内側を隠して、赤いつぼみに見えた。** 外と中の炎をくり抜いて、内側の色が見えるようにした。
- **紙風船が弾けて、同じ朱白の縞の玉が出たら、「大きくなっただけ」に見えた。** 弾ける2コマに棘を出し、玉を白と金にした。
- **竜巻を細い紙テープ 2 本と舞う紙で作ったら、体が無かった。** 幅 0.6 m の帯を 5 巻きにした「巻いた紙」を主役にした（紙の巻き取りの玩具の形）。
- **急発進の紙飛行機と、飛び道具の丸めた紙が、風にさらわれて出どころへ戻ってきた**（風向きと進む向きが逆だった）。ユーザーが嫌う「元へ戻る」になる。
  飛行機は空へ抜けさせ、残る紙は `_face_blow` で向きをそろえた。
- 紙吹雪が寿命までに着地しきらず、最後のコマで消えていた（登場）。`_leaf_rest` が、寿命までに必ずさらうようにした。
- 遠目で「白い輪が二重」に見えた和傘は、寄ると一重だった。**小さい画像で不具合と決めつけず、切り出して拡大して見る。**
- **斬撃の刃（平らな三日月）は、刃の面と同じ向きから見ると細い線になった**（前・横・上は面が出たが、斜め後ろの低いカメラで線）。
  弧に沿って山折りを入れた（`mesh_crescent` の `ridge`）。どの向きからも面が出る。**薄い物は、4 方向（前・横・上・斜め後ろ）から撮って確かめる**
  （`gallery` の種類に `slash#1,slash#2,…` と書くと、同じ種類を別のカメラで並べられる）。
- 花吹雪の桜が、白い紙に見えた。桃色を濃くし、120 枚に増やし、降りはじめを低くし、一枚を大きくした。
- 手裏剣の尾を紙テープ二本にしたら、二重らせんに見えた。ねじれる一本にして、星を大きくした（0.38）。
- **大きさ（`size`）を変えると、花吹雪の範囲と花火の高さだけ付いてこなかった**（長さの設定を、省いた時も場面のメートルで扱っていた）。

### 作り（次に足す時）

- ファイル：`wa/wa_parts.gd`（部品）を、`wa_small.gd`・`wa_medium.gd`・`wa_large_a.gd`・`wa_large_b.gd` が継ぐ。**兄弟どうしは、互いの関数を呼べない**。二つ以上で使う物は `wa_parts.gd` へ置く。
- 登録：`origami_fx.gd` の `KINDS` と `FAMILIES`（ファイル → 種類）。見本は `demo/showroom.gd` の `CAMS`・`NAMES`（墨の種類は `SUMI`、空に大きな物を出す種類は `YOI`、人の目安を立てる種類は `DUMMY`）。
  名前・説明・合図・設定は `tools/build_origami_package.py` の `CATALOG`。`--catalog` で、`catalog.json`・README の表・`scenes/<種類>.tscn`・置くノードの種類の一覧まで作る。
  自動確認は `tests/origamitest.gd` の `CUES`（出る合図の順）と種類の数。ラボは `vfx/vfx_lab.gd` の `ITEMS` と `OG_VIEW`。
- **墨（`shaders/ink.gdshader`）**：帯（`brush_mesh`）と筒（`ink_tube`）の上に、かすれ・毛先・筋を式で描く。`head` で描き進め、`tail` で根元から先へ消す（戻さない）。しみは `blot`（`grow` で広がる）。
  UV.x＝幅（筒なら周）、UV.y＝道のり（m）、UV2.x＝道のりの割合。すき間は `discard`（半透明は使わない）。
- **墨は、暗い場面では読めない。** 紙の上に置く・淡墨と金を添える・見本は明るい舞台（`"sumi"`）で流す。空に置く墨（雁）は、淡墨の色にすると、暗い空でも月の前でも読める。
- 折れる物に描いた絵（屏風の松）：絵を「屏風の左端からの道のり, 高さ」で持ち、帯の両端を一つずつ屏風の面へ移す（`screen_brush`）。折れに沿い、畳むコマは作り直すので、絵ごと畳める。
- 物が別の物の模様になる（月へ跳ぶ兎）：行き先は時刻の関数から先に求めておく。着いたコマで立体を隠し、相手の子にした切り紙を出す。
- 小道具の退場は `_fling`（放り上げる・紐で引き上げる・転がす・跳ねて去る・泳いで去る・凧のように舞い上がる）。風にさらう（`_blown_node`）ばかりにしない。
- 色はリニアの値で決める。sRGB の感覚で書くと明るく出る（定式幕の黒・柿・萌葱が、灰・橙・黄緑に出た）。

### 画像を見て直した所（次も起きる）

- **抽象の線で気分を出すと、別の物に見える。** 見得の飾りを、体のまわりへ走る朱の筋 6 本にしたら、触手に見えた。題材そのものの物（隈取りの面）に替えたら読めた。
- **大の演出は、画面のどれだけを占めるかを先に決める。** 月見は、月（直径 2.6 m）も兎も小さくて、空が余った。月を直径 4 m にして、カメラを寄せた。
- 月を地平へ沈めたら、手前の地面にめり込んで見えた（演出は場面の 3 m 奥にある）。どの場面でも空いているのは上なので、空の高みへ遠ざかる終わりにした。
- 見本の舞台の物（月）と、演出の物（月・面）が重なると、二つあるように見える。月の無い舞台（`"yoi"`）を足した。
- 手前の物（幕の竿）が、奥の主役（面）の顔を横切る。竿の高さを、屏風の上の縁に合わせた。
- 小の小道具は小さいので、カメラを 3 m 前後まで寄せ、物も 1.3〜2 倍にした。竹・稲妻・鯉のぼりは、初めの太さでは引きの絵で線になった。
- 墨しぶきは、平たい帯だと葉に見えた（先に玉の付いた細い筒にした）。だるまは、平らな顔が丸い体を突き抜けた（皿の形の顔にした）。
- 床と同じ高さの面は、ちらつく（8 mm 浮かせる）。
- 回転体（`lathe`・`ball_mesh`）の輪郭は、軸の向きで決まる。軸を上に向けた玉を正面から見ると、輪郭は縦の刻み（少ない方）の多角形になる。
  月は 16 角形に見えた。軸を奥行きへ向けて、周の刻み（48）が輪郭になるようにした。
- **「細い」の原因は、太さではなく向きのことがある。** 雷神の稲妻を二度太くしても細く見えた。帯の幅の向きが奥行き（Z）で、正面のカメラからは帯の端しか見えていなかった。
  空中を走る帯（稲妻・太刀筋・矢の筋・拍子木の線・細い煙）は、直角に二枚にする（`_tape(..., cross = true)`、`ribbon_mesh(..., cross)`）。太くする前に、幅の向きを見る。

### 自動確認と計測で見つけた物

- **乱数で着く時刻が変わる物は、「最後のコマに何も残らない」を通ったり落ちたりする**（しずく・升・半紙）。寝ている時間を、寿命から逆算して詰める（`_shot` の `stay`）。
  墨の木は、`tail` で全部消えたあとも物が見えたままだった（`_span` で隠す）。直したあと、3 回続けて通ることを見た。
- **作ったメッシュを読み戻さない**（`surface_get_arrays`）。描画つきだと 1 回 4〜40 ms、初めは 86 ms かかった。**画面なしでは 0.7 ms で、気づけない。**
  いくつもの形を一つにする時は、一つの `SurfaceTool` に足す（`brush_bundle`・`tube_bundle`）。
- **シェーダーとスクリプトは、持ち続ける。** 使っている演出が無くなるたびに手放されて、次に出す時に読み直しになっていた（出すたびに 12〜34 ms。初めからあった land・bolt・ofuda もそうだった）。
  `OrigamiFx.shader()` と `_script()` が静的な辞書に持つ。出すのは 0.2〜7 ms になった。`OrigamiFx.warm_up()` で、読み込み中に先に済ませられる。
- **重さは、動いている場面で、描画つきで、間を空けて一つずつ出して測る。** 続けて 10 個出した平均では、読み直しが隠れていた。作業用の `probe_live.gd`（出す時と、流している間の最長フレーム）と `probe_steps.gd`（コマごとのスクリプトの時間）。
- 組ごとの一度目は、スクリプトの用意に 0.1〜0.2 秒かかる（`wa/` のファイルは 800〜1,300 行）。
- 小の 10 種にも、音を合わせる合図を足した（`stamp`・`clap`・`ring`・`catch` など）。何度も起きる合図は、そのたびに出る。
