# 生成素材で組む墨金VFX（試作）

2026-10-09。大項目「生成素材」→「墨金の噴流」で再生。動きのソースは `res://vfx/vfx_generated_ink.gd`。素材の画像生成には内蔵 image_gen を使用しています。

ユーザーの意図はテクスチャ・AO・ノーマルを素材として使う制作。連続コマだけをVFXの完成品にする方式へ寄せすぎたため、今回その違いを分けて記録します。

## 素材

- `ink.png`：透過の墨の房。2本の動く3D流路の外・中層に使用。
- `gold.png`：透過の金の流れ。墨より早く接線へ抜ける内側の流路に使用。
- `splash.png`：透過の飛沫。実際の墨の落下位置で発生する地面の染み。
- `burst_4x4.png`：16コマの連続素材。弾ける短い区間のみ曲がる3面で再生。
- `height.png`：生成した濃淡を高さとして解釈する模様。3Dの流路の細かな変位に使用。
- `normal.png`：高さの勾配を計算して正規化した接線空間ノーマル。512×512、RGBは0〜1へ符号化。
- `ao.png`：高さの周囲4方向の差から計算したくぼみの遮蔽近似。3Dメッシュ全体のAOを焼いたものではありません。
- `roughness.png`：同じ高さから粗さの分布を計算。金と染みの光沢へ使用。墨は粗さを強く設定。

生成元の5枚は保存した原画のコピーです。データマップ3枚は `res://vfx/bake_generated_relief.gd` で再計算できます。`PROMPTS.json`、`FLIPBOOK_PROMPT.txt`、`HEIGHT_PROMPT.txt` が最終プロンプト。原画の焼き込まれた陰影は物理的な高さの保証ではなく、この濃淡を制作側が高さとして解釈しています。完全なシームレス性やAlbedoとの物理的整合も保証していません。

## 動きと修正

供給時刻が違う墨が螺旋へ巻き上がり、供給停止後もその素材が落下して染みへ移ります。金は肩が返る前に短い接線の出口へ。染みは位置を固定し、乾く前線と粗さの変化で終わります。寿命6秒、親のageで全層を駆動し、一時停止に従います。寿命用のノイズ穴は使用していません。

初回は上の金の肩が固い線として目立ちました。1回目で画像の白い光沢を弱め、2回目で金の出口そのものを短く分離。3回目で高さ・ノーマル・AO・粗さをつなぎ、照明に反応する材質に変更。最後にデータマップをファイルへ保存して同じ材質に接続しています。

正面と斜め、全体・流れ・落下・最終状態の連続コマを実見。最新の動画は `godot/tests/shots/vfx_review/generated_ink_preview.mp4`。撮影198コマ、960×540、30fps。通常速度の動画を目視再生したとはしていません。全体suiteは変更セットでexit0、最後の材質変更後は `VFXTEST_OK` と実描画エラー0を確認。

## 残る課題

短い拍は曲面の連続画像なので、角度によって平面の層や灰色の密集が読めます。細い流路の体積と拍の接続は改善余地があり、ノーマル/AOを増やすだけでは解決しません。ユーザー未評価の素材方式の試作として扱い、完成品質の見本にはしません。
