# 画像生成から運動へ: Flow / Erosion

## gen_flow: 流線から数値方向場

入力 `streamlines.png` はベクトルマップではない。96×96へ縮小し輝度の中心差分を求め、5×5近傍の構造テンソル（Σgx²、Σgy²、Σgxgy）から画像の線に沿う接線を算出する。接線の符号を上向きに揃え、coherenceが低い場所は上向きへ寄せる。RGへ正規化した方向、Bへ5×5近傍の平均輝度、Aへcoherenceを格納する。これは見た目の画像から推定する2D方向場であり、物理的に正しい流体場・速度データではない。

4回の供給（開始0.05 / 0.61 / 1.55 / 2.19秒、長さ2.50 / 2.00 / 1.20 / 0.75秒）が、方向場をサンプリングしながら別の3D軌跡を辿る。線のRGBをそのまま速度にしていない。縦向きの圧力・重力は演出側で与え、画像から横向きのせん断と奥行きの巻きを受ける。

放出時刻に対応する移動窓で、尾・腹・頭を毎フレーム作り直す。暗い外殻・金の中殻・白い芯は半径と遅れが異なる。空隙は生存期間を通じて一定の疎密構造で、寿命の穴消しではない。供給停止後は尾が頭を追い、下がった材料が地表の薄い流れとなって流出する。

ソース: `godot/vfx/vfx_gen_flow.gd`, `godot/vfx/shaders/gen_flow.gdshader`。

## gen_erosion: 亀裂から区画・順序

入力 `lacquer_fractures.png` を160×104へ縮小し、輝度差分をエッジ強度に変換する。輝度0.22未満の黒い亀裂を障壁とし、1ピクセル分広げて縮小時の橋を閉じる。白い島のconnected-component flood-fillで11区画を得る。種は各島の重心で、亀裂のない内側へ人工的なグリッド境界を加えない。生成画像の各ピクセルをそのまま区画IDとは解釈していない。閾値と画像縮小による推定分割であり、厳密な材料破壊解析ではない。

各区画の面積内のエッジ強度から剥離開始時刻をずらす。生成画像はシェーダーの色だけでなく、区画の輪郭・境界・剥がれる順序を決める。非対称の膨らみ・細まり・不揃いな高さを持つ薄い塗膜に沿う形状を、区画中心の接線座標で作る。根を残して3Dへ曲げ、供給元から裂け、重力で落下する。同じメッシュが接地後に平らな染みとなり、暗く乾いて地面へ吸収される。個体の拡縮やノイズ穴消しは行わない。

ソース: `godot/vfx/vfx_gen_erosion.gd`, `godot/vfx/shaders/gen_erosion.gdshader`。

## 共通

Godot Image / ImageTextureでPNGを実行時に読む。エディタimportは不要。`vfx_base`のageを唯一の時計とし、pause・speedに追従する。寿命6秒。通常速度の再生による評価はこの資料では主張しない。

## 連続コマの確認

`godot/tests/shots/vfx_review/` に `gen_flow_whole.png` / `gen_flow_motion.png` / `gen_flow_end.png` / `gen_flow_angles_front.png` / `gen_flow_angles_side.png` と、同じ名前構成の `gen_erosion_*` を保存。全体は0.15,0.5,1.0,1.6,2.3,3.0,4.2,5.7秒、動きは2.3〜3.0秒を0.1秒刻み、終わりは4.85,4.95,5.05,5.15,5.25,5.35,5.45,5.7秒。正面と横は0.5,1.0,1.6,2.3,2.7,3.2,4.2,5.7秒。

撮り直し: Flow は短い孤立した葉状塊→供給期間を延長して根元・腹・頭をつなぐ→細い縦筋を廃し画像の平均密度へ→照明を有効にして幅を保った透過流路へ→高さを抑えて横撮影の上端欠けを修正。Erosion は低解像度の亀裂橋で1区画になる問題→黒い障壁の1pixel拡張・160×104分割→曲げと時差を強める→直円筒を非対称・多葉・不揃い高さに変更。シェーダーの予約語`flat`衝突も修正した。

連続コマでは、Flowの供給元から伸びた頭・遅れた腹・供給停止後に追い付く尾、外の茶金・中の金・白芯の重なりと空隙を確認した。Erosionは生成画像の島の輪郭に沿って区画が割れ、朱の表面が曲がって金の裏面を見せ、別々の時刻で落ちて地上の染みに移る。終了の5.7秒では両方とも本体・染みは画面に残らない。

出力: `gen_flow_frames/` と `gen_erosion_frames/` に各216枚（30fps、7.2秒）。撮影後のソースを固定した。映像の通常速度再生は確認していない。Flowは運動を数値方向場へ結び付けた演出用近似で、実流体シミュレーションではない。斜めからは細長い光沢面が帯のように見える箇所がある。Erosionは曲がる漆の膜として設計しており、気体・液体の非固体表現とは異なる。区画境界は有限解像度の画像分割で、非常に寄ると階段状の辺が残る。
