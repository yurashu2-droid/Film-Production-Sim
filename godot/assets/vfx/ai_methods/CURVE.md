# 生成画像 → 曲線骨格 → 分岐する放電

`branch_lines.png` の白い線を実際の曲線へ使う。絵を板へ貼る方式ではない。
Godot の `Image.load_from_file` で直接読み、96×96へ縮小し、輝度しきい値0.32、
Zhang–Suen細線化、根からのBFSで分岐の接続と距離を得る。現在の生成画像から
接続した668画素、20流路を抽出。主枝から分かれた流路は根元の重複を除く。
XYは画像、Zはゲーム用の曲面への埋め込みであり、画像から正確な3Dを復元したものではない。

0.15 / 1.05 / 2.20 / 3.72秒に供給。根からの距離×1.08秒の遅れで先頭が到着。
通過する白芯・橙の導電部・疎なコロナは異なる幅、遅れ、供給窓を持つ。
先頭の肩が各地点を通ると局所的に曲がり、殻の半径も変わる。
最終供給の後端は根→先へ進み、外側の余光も枝の外へ少し流出する。
寿命でノイズ穴を増やす層は0。寿命6.0秒、`age`のみで駆動する。

## 実描画と修正

- 0周: 全体で枝先の見切れ、細い均一な導電部が目立った。
- 1周: 高さ4.6→3.8相当へ調整、深度と外層幅を増やして撮り直し。
- 2周: 進む先頭の肩にY/Z方向の局所変形を加えた。
- 3周: 外のコロナだけ別の遅れの変形を加えた。
- 4周: 終わりの枝飾りの滞留を減らすため、外層の供給窓を短縮して外向きへ流出。
