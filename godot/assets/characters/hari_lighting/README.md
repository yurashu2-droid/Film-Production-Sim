# あかり係ハリ / HARI — LIGHTING CREW 02

「参考画像の生成から始め、部位を比較して改善する」制作例。
撮影現場の小柄な照明スタッフ。短い紺色ボブ、大きな丸眼鏡、黄色の短い作業ジャケット、
緑の作業ズボン、赤茶のブーツ、腰のケーブル、左手から吊るした小型作業灯を目印とする。

## 参考画像とデザインの扱い

`reference/design.png` は組み込みの image_gen で新規生成した全身・部位参考画像。
生成に使った詳細プロンプトは `reference/prompt.txt` に保存している。
左側の大きな斜め向きの全身画像を主な形・配色の基準とし、正面・側面・背面と接写を補助にした。
生成した複数方向は計測された図面ではなく、背面や隠れた接続は3D側で解釈して構築した。
細かい布目、髪の繊維、指の形などは単純化している。参考画像の完全な再現を主張するものではない。

## 制作ループ

先に全身と道具の比率を組み、同じ照明・カメラ・静止ポーズの部位画像を保存して比較した。

| 部位 | 最初の候補で観察した問題 | 残した修正 |
|---|---|---|
| 顔・眼鏡 | 前髪で片方の目が隠れ、頬が別パーツとして浮く | 前髪の位置・幅を調整。頬を別の球から頭部表面のなだらかな膨らみへ変更 |
| 髪 | 前髪の大きな持ち上がり、後ろの同じ束の並び、根元の段差 | 大束の曲線と幅を調整。後ろは不均等な束へ変更し、頭の断面に沿った奥行きと埋めた細い根元に修正 |
| 袖・手 | 袖の付け根の角張った輪郭 | 肩側の断面を丸く段階的に変更。巻いた袖口の内側の開口と、前腕・手袋との接続を保持 |
| ズボン・ブーツ | 左右同じ折れ目、箱型の足先 | 膝・裾の折れを控えめかつ左右別に配置。足先を丸い断面から作る形へ変更 |
| 作業灯 | 取っ手・手・筐体の接続を部位接写で確認 | 最初の吊り下げ構成を保持。全コマで手の子ノードであることを確認 |

`preview/part_comparison.jpg` は最初の候補と最終候補の同条件比較。
修正した部位を全身へ戻し、正面・左右・背面・上面・斜めで再確認した。
最初と途中のGLB、接写はローカルの `artifacts/hari-lighting/round01` / `round02` に保存している。

## 成果物

- `hari_lighting.glb`：22,664三角形、113メッシュ、19マテリアル、+Y上・+Z正面、メートル単位。
- `build_hari.py` / `controls.json`：輪郭、衣服断面、髪の曲線、材質、関節角度を編集できる生成元。
- `clump_mesh.py`：提供ZIPの髪スキル付属の閉じた束生成ヘルパーをコピーして使用。
- `geometry_report.json`：各メッシュの境界・非多様体辺・縮退面確認の情報と参考画像のハッシュ。
- `capture_hari.py`：非表示の常駐Godotで、全方向・部位・全96コマと比較表を撮影する手順。
- `preview/hero.png` / `turnaround.jpg` / `light_check.gif`：実際のGLBをGodotで読み込んだ描画。
- `preview/runtime_evidence.json` / `rebuild_evidence.json`：実行時の確認と、別フォルダーから同一GLBを再生成した証拠。
- `res://hari_lighting_lab.tscn`：独立した展示シーン。前の展示用スクリプトを継承して共通の照明・操作を利用する。

プロジェクトのルートから表示：

```powershell
& ./tools/godot/Godot_v4.7.2-stable_win64_console.exe --path godot res://hari_lighting_lab.tscn
```

Spaceで再生・停止、左右キーで回転、Rで初期ビュー。
作業灯を保持して周囲を見て、カメラへ向き直り小さく頷く `Light_Check` を4秒で繰り返す。
展示文字はOSのフォント（Yu Gothic / Noto Sans CJK JP / Arial）を使用する。

再生成と撮影：

```powershell
python godot/assets/characters/hari_lighting/build_hari.py
python godot/assets/characters/hari_lighting/capture_hari.py
```

Python標準ライブラリとPillowを使う。GLB書き出しは隣の `../cardboard_stunt/build_model.py` にある
既存のライターを再利用する。配布・移動時はこの依存ファイルも必要。
参考画像、生成元、ヘルパー、設定、ライターだけを別フォルダーへコピーして再生成し、GLBのハッシュ一致を確認した。

## 確認範囲と限界

Godot 4.7.2 / Forward+でGLBを再読み込み、全方向と4秒24fpsの全96コマを確認した。
足の接地点の移動は0m、作業灯は全コマで手の子ノードとして保持される。
縮退三角形・非多様体辺は生成時に確認。レンズと胸の印字のみ意図した開いた面を持つ。
全体の `bash run_tests.sh` は開始画面と演出単体の確認後、既存の通信演出テスト
`PERFORMANCE_NET_TEST_CLIENT_FAIL` で停止した。

各部品はノード関節に親子付けした方式。肌を一体で変形するスキニング、指・表情の可動、歩行、
布・髪の物理シミュレーションは含まない。衣服の折れは断面を手で設計したもの。
眼鏡レンズは薄いアルファ透明の図案的表現で、光学的な透過・屈折ではない。
作業灯は発光マテリアルを使用し、周囲へ動的な光を投射するライトは含めていない。
メッシュと材質の数が多いため、大人数を出す本編用途には対象に応じた結合・リグ化が必要。

手順の出典はユーザー提供のキャラクター・髪・素材・アニメーションの各スキル。
モデルの形状はコードで新規作成し、胸の印字も生成元から作成した。Blenderは使用していない。
