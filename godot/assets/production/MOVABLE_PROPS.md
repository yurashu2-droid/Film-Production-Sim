# Movable production carts

Instantiate preload("res://scripts/production_prop.gd").new(), call build_model("lift_cart" or "cleaning_cart") before adding it to scene, then assign game/pid as for existing Prop. They inherit host-only RigidBody carry, holder control, world/prop/character layers and restoration. Both rolls=true; mass is 24 / 12 kg, source metre scale. No original GLB changed.

F wiring: broadcast set_active(not prop.active) through existing host_ev. Lift raises over three seconds to 1 m, false reverses to 0.44 m using the original Lift clip. Cleaning true starts the source Wringer cycle; false rests it, subsequent true repeats. Host advances phase; get_state() adds [active, action_time] after existing three fields. _apply_extra consumes those fields and samples the imported AnimationPlayer manually, so clients and playback reproduce the exact same pose and deck collision height from authoritative snapshots. Keep existing generic state replication; it must retain extra fields. Late join uses the same state.

Lift deck_top and a 1.0x0.05x0.50 m top CollisionShape follow TABLE_RIG. Existing game.props riders whose rider_of equals this pid receive the per-tick deck delta in ride_local.origin.y. Existing rider snapshot path must keep ride_local, as for other carts. can_board() is false during movement; parent should check it before boarding to avoid loading new items during transitions. Existing riders remain attached during raising/lowering. Set fixed=true while using as a stable camera platform if desired; its animation still runs. The top collision is a kinematic proxy within the existing cart body, not articulated Jolt machinery. Handle/chassis collisions are deliberately coarse.

Verified on Godot4.7.2 via production_prop_testshot.gd, compatibility renderer, fixed60fps: both assets load; original clips evaluate; top 0.440->1.000->0.440 m, rider local height follows, can_board true at endpoint, inherited held rolling drive moved cleaning cart X0->1.484m. State has expected five fields. Screenshots artifacts/production_carts_low.png and production_carts_high.png show handle/chassis/top collision outlines, source materials and rider at both heights. Run console with --debug-collisions to recreate. Full gameplay suite intentionally deferred to parent integration.
