# Q07 スケッチブック型カンペ / 改訂3

橙寄りの黄と、ほぼ黒の深緑が交差する表紙。上辺をツインワイヤで綴じた、A3横持ちのスケッチブック型カンペです。前の板・クリップ・背面ハンドル型から変更しました。

図案スケッチブックの視覚的な特徴を参考にしたオリジナルのゲーム小道具です。実在ブランドのロゴは使用しておらず、公式・ライセンス商品という意味ではありません。

## 開いた姿と閉じた姿

- Q07_Replaceable_Cue_Board.glb：カンペ表示姿。表紙を裏へ折り返し、紙に台詞を表示
- Q07_Sketchbook_Closed.glb：閉じた表紙姿。橙／黒系の幾何学柄が見える状態
- Q07_Replaceable_Cue_Board.blend：編集用。既定はカンペ表示姿。画像はパック済み
- Q07_Cue_Board_Preview.jpg：表紙、カンペ、綴じ部、紙束、背面の比較画像

2種類のGLBは静的な姿です。紙めくりアニメーションではありません。実物同様、表紙を完全に裏へ返した状態では、裏から見えるのは表紙の内側の無地ボール紙です。

## 台詞の画像を差し替える

1. textures/cue_blank.pngを複製して、好きな台詞や絵を書きます。1536×1086pxの横長比率を保ちます
2. 上辺には実際の綴じ穴があるので、文字は上から120px程度を空けます。cue_layout_guide.pngは安全範囲の作業用ガイドです
3. PNGまたはJPGで保存します。不透明なsRGB画像を使ってください
4. Blenderで「Page 01 • REPLACE IMAGE」のマテリアル「CUE_FRONT_REPLACE_IMAGE」を開き、画像ノード「REPLACE_THIS_IMAGE」の画像を変更します
5. UV0は正面全体に0〜1で割り当て済み。再UV展開や文字のメッシュ化は不要です
6. File > External Data > Pack Resourcesで画像を内蔵し、保存・再出力します

サンプルは「愛してる！」と「ここで爆発」。正面だけを交換するので、表紙の柄と他の紙は変わりません。ゲーム側では該当マテリアルのBase Color / Albedo画像を差し替えます。実ゲームエンジンでの動作は未検証です。

## Blenderで静的な姿を切り替える

Cover • front board • FOLD_BACK が表表紙です。
- 開いて裏へ返した姿：表紙 Location Y = 0、Page 01のShape Key「CornerLift」= 1
- 閉じた表紙姿：表紙 Location Y = -0.00620 m、Page 01のShape Key「CornerLift」= 0（紙を表紙の下で平らにする）

これは綴じ輪の前後に置いた2つの完成姿の切り替えです。この位置の間を直線補間しても正しい紙めくりにはなりません。ページめくりを付ける場合は、リングを回り込む別の動作設計が必要です。

## 構造・寸法

- Z上、正面−Y、単位メートル
- 本文：420×297mm、画用紙24枚
- 各紙の造形厚：0.16mm。数値はゲーム用の造形設定で、紙の坪量から推算した実測値ではありません
- 表紙／裏表紙：423×301mm、各0.65mmのコートボール紙として造形
- 42組のツインワイヤ、84本の輪、背側の連結部
- 綴じ穴は実際に開いた形状。黒い四角を貼った表現ではありません
- 一番前の紙だけ、右下に約1.15mmの小さな反りがあります
- ATTACH_SUPPORT_LEFT / RIGHT / BOTTOM は手を添える位置の目安

持ち手やバインダークリップは付いていません。キャラクターの指、手首、IKとの接触確認は未実施です。紙の弾性、リングの開閉、紙めくり、落下の物理挙動は付属しません。

## 制作と検証

公式の製品写真・仕様を観察し、印刷表紙、薄い紙束、ツインワイヤ、穴、切り口を分けて制作しました。保存したBlenderを開き直し、実納品GLBも読み込み直して確認。QAフォルダに構造・画像内蔵・UV・三角形・確認範囲を記録しています。

sourceに再生成用Python、texturesに交換画像、referencesに出典を収録。第三者の製品写真自体はZIPに同梱していません。旧ボード版は制作環境の別保管に残しています。

## このゲームでの利用

元ファイル：`小物/撮影機材/カンペ/Q07_Replaceable_Cue_Board.glb`（改訂3）。
GLBを変更せず、本文の幅が1.12mになるよう全方向を同倍率で拡大して使用。
`CUE_FRONT_REPLACE_IMAGE` の画像だけをゲーム内ペイントのライブテクスチャへ差し替える。
表紙・他の紙・ワイヤの形状と素材は元モデルを使用する。
