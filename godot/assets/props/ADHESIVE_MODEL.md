# 接着剤・重り

接着剤は付属の霧吹きボトル `P090_spray_bottle.glb` をスプレー接着剤として利用。元の形・比率を保持し、ゲーム内ラベルを追加。
出典: `小道具大道具(仮)/film_crew_small_props_P076-P100_v01.zip` の `exports/P090_spray_bottle.glb`。付属 `README_ja.md` を確認。元資料では今回制作のオリジナル素材で外部素材不使用、1 unit = 1m、GLB床面原点。
重りは既存の `P068_sandbag.glb` を利用。ゲーム内質量12kg。

# ロープ

荷台の物を押さえるロープ（爆弾の導火線にも使う束）は、付属の巻いたケーブル `P065_cable_coil.glb` を利用。元の形・比率を保持し、1.8倍に拡大。ケーブルの面（材質 rubber）だけをロープの色に差し替え（金具と留め具はそのまま）。
出典: `小道具大道具(仮)/film_crew_small_props_P051-P075_v01.zip` の `exports/P065_cable_coil.glb`。付属 `README_ja.md` と `LICENSE.txt` を確認。今回制作のオリジナル素材で外部素材不使用、1 unit = 1m、GLB床面原点。
荷台に掛けたロープは、導火線と同じ物理のひも（`scripts/fuse_cord.gd`）。荷台のフックからフックへ渡し、荷物の形に沿って垂れる・張る（`scripts/cargo_kit.gd`）。
フックは、軽トラのモデルに元からあるロープフック（左右のあおりの下に5つずつ）の位置に合わせ、目印の黄色い輪だけを `scripts/truck.gd` で下げている。鳥居の柱（左右1つずつ）と、ロケバンの荷室の壁には金具が無いので、小さな板と輪を足している。
