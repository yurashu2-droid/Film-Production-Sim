# Pixel × Real 50 / 小型補助10種

全て演出量S。接触・回復・走り・応答用。主役1系統に補助0〜1系統の構成で、物理的な寸法を分類基準にしない。使用APIとシーンはREADME参照。

既存ポータルの五段色、ピクセル格子、ディザ、HDR床光を共通の絵柄として使用。外殻・中間流・短い芯を別の奥行きと供給時刻で重ねた。18区間の流路を再構築し、先頭が移動した後から材料が供給され、止めた発生元から後尾が追いつく。寿命をノイズの穴で消す層は0。恒常的な動く空隙とは区別する。

| ID末尾 | 動きと拍 | 出口 |
|---|---|---|
| strike_snap | 五方向の短い圧力解放、頭と尾の時間差 | 後尾が先頭へ追いつき、色が冷めながら排出 |
| ricochet_skip | 0 / 0.52 / 0.91秒の三拍、浅くなる跳弾の弧 | 先発から排出し、後発の弧が最後に前進 |
| heal_sprout | 0.02 / 0.21 / 0.64 / 0.98秒の四つの上昇芽 | 芽が上へ抜け、根元の五弁印を区画順に払う |
| mana_tick | 位相の違う三本の上昇螺旋 | 根元の供給を切り、上へ抜けてから印を閉じる |
| frost_touch | 接触から四方向へ逃げる低い冷気の肩 | 旧腹が上へせん断され、冷たい後尾が流路の先へ抜ける |
| ember_contact | 高さと開始時刻が違う四つの炎舌 | 炎舌が上へちぎれ、後尾の色が暗く冷める |
| poison_drop | 一滴の落下、0.73 / 0.90 / 1.14秒の反跳 | 着地点へ滴を渡し、飛沫が弧の先へ、床印は最後に払う |
| dust_step | 前へずれた五房の茶色い肩、別位相の剪断 | 放出を止め、房を上へ引きずりながら前へ排出 |
| rune_ping | 床より少し上を周回する三本の応答 | 周回材が先へ抜け、各印は別の始点から角度順に払う |
| charge_seed | 四本の内向き螺旋、1.26秒から上向きに解放 | 流入は中心で消費、放出尾は上へ抜け、印を時差終了 |

素材の形は12fpsで更新し、ageで一括駆動する。シェーダーTIMEやTweenは使用しない。小型を大きく見せたい場合は生成時にsizeを指定する。等倍の主要寸法は約0.7〜2m。床照明はlit材質が必要。砂煙は芯の明度を抑え、床灯をほぼ出さない。

制作で行った修正は、(1)発生と排出の時間窓・素材ごとの経路を分ける、(2)色強度を0.58倍へ下げ白飛びを減らす、(3)砂煙の幅・複数の肩・剪断・密度・床灯を専用化する、の三段階。撮影台の中央箱が低い流路を隠していたため、箱を左へ移し小型用の焦点を0.8mへ下げて最終撮影した。

最終ソースから全10種×216枚を30fps / 7.2秒で出力した。全体・動き・終わり各8時刻の画像は連番から最近傍フレームを切り出し、実時刻を画像とreview_times.jsonに記載。10種の動き・終わりを連続静止画で確認した。全50の流れ→主形→出口の比較一覧も確認。瞬撃・跳弾・砂煙・刻印は追加でX/Z方向を撮影した。撮影フラグfrontはX方向、sideはZ方向で、一般的な正面/横の呼称とは対応しない。

## 53種版での改善ループ

1. 同じ葉形の頭と密な砂塊を確認。流路UVを残存区間の正規化から放出時刻へ変更し、材料に肩とくびれが乗って移流する形にした。砂煙は専用の透過材質にして、上昇・膨張・希薄化させた。beforeは `artifacts/pixel_real_53/before_micro/` に保存。
2. 瞬撃が水平の一枚へ重なるコマを確認。方向ごとの加速度・高さ・横への曲がりを変えた。汎用の床印を回復の五弁、毒の着水後の分割波紋、蓄勢の菱形へ分離。`r2` で火花と接触を比較。
3. 毒滴が緑の炎に見える問題を確認。動く空隙を持つ火流材質から、連続した表面と移動する反射を持つ液体材質へ分離。`r3` で滴→反跳→床波の受け渡しを確認。

火流の先端に小さな房が読める画角はある。これらは連続静止画による制作確認で、通常速度動画の目視評価、ユーザーの好みへの合格、販売市場の評価を確認した記録ではない。
