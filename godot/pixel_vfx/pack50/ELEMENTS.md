# Pixel × Real 元素14種と露の反転（53版）

呼び出し: `preload("res://pixel_vfx/pack50/px50_elements.gd").spawn(parent, position, size, variant)`。
`elements_catalog.json` はID、寿命、全体8コマ、動き8コマ、終了8コマの時刻を保持する。`size_class` のL3・M9・S2は旧版の物理ラベルを互換用に維持する。現在の演出量は `complexity_class` に記録し、旧14種はS12・M2・L0。噴口と聖泉だけがMで、他は主役一系統＋補助一役以内のS。パケットの反復・左右の同役・三つの技術層は、独立した演出へ数えない。

新作は `px50_dew_inversion.gd` と `additions_elements_catalog.json`（配列一件）。Sの「露の反転」は約5〜6mの領域を使う一筋＋一枚波であり、演出量の少なさが寸法とは別である。撮影距離は9m。詳細は `DEW_INVERSION.md`。

共通参照は、このフォルダ系統の `px_portal.gd` の前後に離した層と床への光。既存エフェクトを発生させる呼び出しは行わず、独自の曲面・流路・シェーダーから描画する。外部テクスチャやVFXライブラリを使わない。

## 実装の範囲

- `px_base.gd` の `age` と12fpsの `_step` を使う。Tween・シェーダーのTIME・ランダム時計を使わない。ツリーの停止に従う。
- 各有限パケットの先頭・尾の区間から連続した曲面を再構築する。節ごとの筒は並べない。外・中・芯を異なる半径、開始時刻、奥行き、位相にする。
- 流路の恒常的な空隙と5階調・市松ディザを独自シェーダーで描く。寿命でノイズの穴を増やす消去は使わない。
- 気体の2種は独自の薄い房用シェーダーを使い、面内の長いストライプを避ける。インクと砂は暗い材料を加算で飛ばさない。
- 床の型は三枚。供給・接触点の位置と素材に応じて配置する。雨・水の輪は外に進み、最後は区画を拭う。輪全体を縮めない。
- 実際のOmniLight3Dを二つ置き、床と周囲へ色の光を落とす。グローは使用先のWorldEnvironment設定に依存する。

## 旧50版の実画像での修正

初回の極光全体画像で密な管と切れた端を発見した。修正1: 恒常的な空隙を増やし、パケットの肩・頭・尾を分け、極光の色を青緑へ変更。`e1_full/flow/end` は14種すべて画像で確認した。

修正2: e1で炎の奔流と疾走が似ていたため、上向きの奔流と低い二拍の疾走へ分離。霊気を左右供給へ変更。雨の長い筋を三滴へ、小葉の立方体を折れ目のある葉メッシュへ変更。素材の出口を固定した末端で切らず、その先へ進ませた。`e2_full/flow/end` は14種すべて画像で確認した。

修正3: e2で毒・冷気が板状の筋に見えたため、薄い房の独自材質へ変更。極光・噴口の上端切れは上昇経路を低くし、玄武岩・油・亀裂と癒やしの十字を地表へ追加した。出口を越えた曲面の接線を補正した。

`e3_full/flow/end` は14種すべて画像で確認した。極光、折り返し滝、毒霧、霊気の連結は正面・側面の8コマずつも開いて確認した。滝は正面で狭く見えるが、前後の離れた水の首と肩を保持する。毒気は正面から房の奥行きが見え、外形の多角形の縁が残る。霊気は側面に二つの供給が読め、正面には短い肩が重なる。

撮影は `res://tests/shots/review_px50.gd`。`godot/tests/shots/vfx_review/` に全体・0.1秒間隔の動き・終わり、代表4種の正面と側面、30fps・7.2秒の連番を出力する。

旧50版のコード固定後、14種それぞれの `px50_<variant>_frames/000.png`〜`215.png` を出力し、各216枚を確認した。最終連番からカタログ時刻で `px50_<variant>_full.png`・`_flow.png`・`_end.png` も再構成した。`elements_frozen_audit.png` は14種のピークと215番の比較で、最終コマには素材が残っていないことを画像で確認した。旧50版スクリプトのSHA256は `19497fd7c4f3d8ff312566eba7caedeb0a143d9dd295b284556eda52330f5eb5`。

## 53版の改善監査

修正前の全体・動き・終わりと代表の角度画像46枚を `artifacts/pixel_real_53/before_elements/` へ退避した。描画画像から、非水系にも同じ輪が繰り返される点、気体の短い長さに対して半径が大きく円盤化する点、炎の奔流の上昇部が細い棒へ集まる点を発見した。

- 地表: 極光は曲がった磁気流跡、砂は風下の扇、炎は熱跡、気体は薄い堆積、霊気は二端の印、風はせん断跡へ変更。小葉の地表輪は削除。水と雨の波紋、聖泉の字形の輪だけを素材上の役割として残す。
- 気体の1回目: 短い房と細分曲面・視線に対する薄い外縁へ変更したが、初回画像で終盤が円盤状になった。2回目: 房の長さに対する半径と出口の膨張を抑えた。3回目: 長い白い芯を先頭寄りの短い明部へ分配した。
- 炎の奔流: 有限パケットを短くして局所的な肩を太くし、低い疾走との差を残す。
- 砂: 大きな帯の破片が木片に見えたため、砂だけ恒常的な細粒のマスクと細かい格子へ変更。2回目でも密な表面だったため、3回目は粒密度を下げ、有限の肩を短く分けた。
- 霊気: 二つの供給が孤立した房に見えたため、供給窓を長くして中盤の連結を読めるようにした。
- 小葉: 葉より風の帯が目立ったため、補助の風を暗く抑えた。

地表と流路の共有材質を変更したため、最終版は影響する14種すべてを再描画し、画像を開いて確認した。撮影は共有の `review_px50.gd`、各変種は全体・0.1秒間隔の動き・終わりを8コマずつ、正面・側面の全体も8コマずつ。12fpsの同じageを30fpsの216連番へ記録する。API、Lab、共有テスト、パッケージ処理には担当側の変更を加えない。

## 最終固定と確認

旧14種は全体・流れ・終わり各8コマと正面・側面の全体各8コマ、新作の露はそれら3種類を両角度でも開いて確認した。旧14種は素材別の地表が読み分けられ、砂は細粒の疎な流れ、小葉は主役の葉が風より明るく読める。気体は円盤と長い白い棒を抑えたが、正面で薄い曲面に見える限界は下記に残す。

描画コード固定後、15種それぞれの `px50_<variant>_frames/000.png`〜`215.png` を30fps・7.2秒で再出力した。各216枚、全プロセスの終了コード0、ERROR行なし。最終連番からカタログ時刻の `_full.png`・`_flow.png`・`_end.png` を再構成した。ピークと215番の比較画像は `artifacts/pixel_real_53/elements53_frozen_audit_1.png`〜`_3.png`。最終コマで素材が残らないことを確認した。ソース6ファイルのSHA256と描画結果は `artifacts/pixel_real_53/elements_freeze.json` に記録。固定後にソースを再照合した。旧14本体のSHA256は `185095cb1363738bb86b3d60edadd17debf883a590c3ba769885267200653a88`。

## 判定の限界

ユーザー未評価。静止画の連続コマで形・前後・出口を確認する方式であり、通常速度の動画を視聴したと主張しない。気体は外縁と明部を改善したが、正面の冷気の肩は角度によって薄い曲がった舌や面に見える。物理流体シミュレーションや衝突追従は行わず、墨の染みは永続デカールではない。葉は床近くで表示を終了し、接地・跳ね返りの物理判定は行わない。曲面を12fpsで再構築するため、多数同時発生の性能は別途実機で判断する。
