# Pixel × Real: Portal 12 + 星図の織門

好評だった既存 `px_portal` の暗い外側、明るい内側、前後に離れた実際の枠、ドットの段色とディザを継承する。この13種自体はユーザー未評価。価格・公開・利用許諾の確定はこの資料では扱わない。

```gdscript
const Portals = preload("res://pixel_vfx/pack50/px50_portals.gd")
var gate = Portals.spawn(self, Vector3.ZERO, 1.0, "astral_gate")
const Loom = preload("res://pixel_vfx/pack50/px50_constellation_loom.gd")
var constellation = Loom.spawn(self, Vector3.ZERO, 1.0, "constellation_loom")
```

位置は床上の発生点。垂直門は+Zが正面。召喚井戸と帰還印は水平。返されたNode3Dを回転すれば全体の向きを変えられる。大きさは生成時に指定。転送判定・衝突・通過処理は含まない。

分類は見える演出の構成量を表す `complexity_class`。従来の物理寸法 `size_class` と撮影距離 `dist` は別の値として保存する。五枚の膜やそのシェーダーは、一つの門の描画技術であり五演出とは数えない。構成の根拠はcatalogの `composition` と `tier_reason` に記録した。既存12種はS4/M8で、件数合わせのL指定をしない。

既存12種は五枚の曲面枠＋別の闇、種類ごとの床印0〜2枚、8〜24個のMultiMeshセル、OmniLightを持つ。曲面は24×24に分割した実メッシュをshaderで曲げ、深度と剥離を親時計で動かす。床は星図・月影・波の流出・六方向のアンカー・六角括弧・走査レール・接続パッド・文字で役割を分けた。Sの四種は別床印を持たない。

星図の織門は幅約5.5m内の三門。0.12sの左門から金色の頭尾付き流れを送り、1.10sの中央門、2.05sの右門へ渡す。三組の周回杼、左右で離れた床星図、折れた天冠の結線が続く。左から門を閉じ、各深度の四扇区を交替で消去。闇は反向きの走査で閉じ、連結流は排出、天冠と床星図はそれぞれ別時刻の横走査で終わる。供給・織り・受け取りの役割に色を割り当てた。

全時間は `px_base.gd` のageと12fpsの_stepのみ。TIME・Tween・別時計の粒子は使わず、pauseに従い寿命で削除する。variant文字列のhashから既定seedを決める。ノイズ穴を寿命全体へ広げる出口や輪の縮小終了は使わない。

依存は `px_base.gd`、`px_common.gdshaderinc`、`px_voxel.gdshader` と同梱のportals_field、portals_ground、constellation_loomのshader。ゲーム `vfx/` や外部画像への依存はない。Forward+のHDR/glowで芯がにじみ、lit材質の床はOmniLightの実光を受ける。

## 改善と描画確認

初回12種の全体・動き・終了36枚とソースを `artifacts/pixel_real_53/before_portals/` に保管。既存の二枚の共通床輪を役割別の一枚へ置き換え、S四種は床輪を削除した。潮汐の粒は縁から落ちる滴へ、六角の粒は頂点アンカーへ、小門の粒は口から立つ列へ変えた。五層を曲面メッシュに変え、真横の紙の線を浅い湾曲と層の幅へ改善。枠の終了を角度・六扇区・八扇区・方向走査へ分岐した。終了監査で裂晶・六角・刻印の黒い放射形が枠の後に残ることを発見し、闇を線走査へ変更して0.25秒前倒しした。再描画では放射形の残留が消え、各枠の先端が終わりを担う。

新作は四回の実描画で三組の観察修正を行った。

1. 初回は流れが門の闇に隠れ、左副門も横向きで細かった。連結経路を上へ通し、有限の頭尾を太くし、供給・織り・受け取りの色と向きを分けた。
2. 次の描画では闇の終了が黒い十字に見え、天冠が床印の複製に見えた。闇を反向きの線走査へ変え、天冠を閉じない折れ線にし、均等な粒の輪を三組の頭尾付き杼へ変えた。起動も流れの到着へ合わせた。
3. 真横では三門と床印が同じ深度に重なった。副門と床星図を異なるZへ配置し、副門を逆向きに傾けた。再描画で独立した門の深度と床印を確認した。

Godot 4.7.2 / Forward+ / RTX4060の実描画で全13種のfull・flow・end各8コマ、既存12種の真横と代表5種＋新作の正面を確認した。これは等速動画を視聴したという主張ではない。撮影台の `--side` が+Z正面、`--front` がX軸の真横で、ファイル名はそのフラグに従う。保持時の円形門は輪郭変化が控えめ。真横では薄い枠と闇の積層として見え、正面ほど穴は広く見えない。水平二種の奥は低い視点で短く見える。転送用ゲーム機能や性能保証は含めていない。

最終ソースから各7.2秒・30fps・216枚を記録し、sourcehashと撮影設定を `artifacts/pixel_real_53/portals_final_sourcehash.json` に記録する。構文確認は所有する二scriptの `--check-only`、全体のAPI/統合検証は統合担当が行う。
