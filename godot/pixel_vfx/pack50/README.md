# Pixel × Real 53 / ソースデモ

Godot 4.7.2 / Forward+向けの53種。既存50種を見直し、大・中・小へオリジナルを1種ずつ追加しました。ドットの段色とディザ、12fpsの形、HDRの光、実際に床を照らすライトを組み合わせています。

**大・中・小は演出・装飾の量です。** 小は主役中心、中は主役に異なる役割の補助、大は複数の展開と豊富な装飾。物理寸法や表示倍率では区分しません。各作品の `composition` と `tier_reason` に根拠を記載し、描画用の三層や同じ粒の複製は別の演出として数えません。旧 `size_class` は過去の物理サイズ記録で、分類には `complexity_class` を使います。

新作は大「星図の織門」、中「反響の縫合」、小「露の反転」。3種の初期カメラ距離は9m、焦点高さは1.8mで共通です。ファイル名 `pack50` と旧IDは既存の参照を維持するため変更していません。

ZIPを展開し、付属の `project.godot` をGodotで実行するとデモが始まります。Godot実行ファイルはZIPに含みません。コマンドなら `Godot --path <展開先>` でも起動できます。デモの起点は `pixel_vfx/pack50/demo.tscn` です。

デモでは演出量、プリセット、表示倍率、速度、ループ、再生、停止を操作できます。「追加オリジナル」で3種を比較できます。速度0で一時停止。左ドラッグで視点を回し、ホイールで近づいたり離れたりできます。表示倍率を変えると演出が初めから再生されます。白い人形は1.7m、床格子は1mの目安です。カメラは実際の占有範囲に合わせ、演出量の分類とは連動させません。

## ゲームへの組み込み

`pixel_vfx/` をコピーし、同じ `res://pixel_vfx/` の位置を維持します。既存ゲーム側の `vfx/`、ネットワーク、音声autoload、外部画像への依存はありません。

`pixel_vfx/pack50/scenes/` の53個の `.tscn` は、ゲームのシーンへ配置できるプリセットです。Inspectorの `effect_size`、`playback_speed`、`loop`、`auto_play` で設定できます。コードから使う場合は共通APIを呼びます。

```gdscript
const PixelReal50 = preload("res://pixel_vfx/pack50/px50.gd")
var fx = PixelReal50.spawn(self, Vector3.ZERO, "px50_astral_gate", {
    "size": 1.0, "speed": 1.0, "loop": false
})
fx.playback_speed = 0.0 # 一時停止
fx.playback_speed = 1.0 # 続きから
fx.stop()              # 現在の表示を停止
fx.play()              # 初めから再生
```

`size` は生成時の倍率、`speed` は親の進行速度、`loop` は寿命後に間隔を空けて繰り返す設定です。SceneTreeのpauseにも従います。通常は終了後に自動削除します。ノードを保持したい場合は生成後に `free_on_finish = false` を指定します。位置は発生点で、ポータルは床に接する位置を原点として組み立てます。

一覧は `CATALOG.md`、ID・寿命・退出・撮影時刻は `pixel_vfx/pack50/catalog.json` を参照してください。ポータルの構造・視点制約・修正記録は `PORTALS.md` にあります。

## 表現と確認の範囲

素材とコードは今回のオリジナル制作です。第三者テクスチャは使用していません。売上・市場評価・新規演出のユーザー評価は未検証。販売条件と利用許諾は制作者が別途定めるものです。

基準レンダラーはForward+です。床の色光を受けるにはlit材質の床とライト範囲が必要です。HDRの芯のにじみはEnvironmentのglow設定に依存します。ポータルの真横は薄い面の積層が見えます。撮影確認は連続静止コマで行っており、等速動画の視聴やゲームプレイでの最終評価を行ったという意味ではありません。

53種は演出だけを提供します。ポータルの転送、攻撃判定、ダメージ、アイテム獲得、音声はゲーム側で実装してください。
