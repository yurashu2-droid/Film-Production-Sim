# 引力返し / px_gravity

自作Pixel×Real試作。APIは `spawn(parent, pos:Vector3, size=1)->Node3D`、足元pos。px_base / px_commonだけに依存。life5.2秒、推奨gap1.1秒。

5方向からの異時刻の流入が落ち、中心で約.14秒圧縮してから接線へ返す。素材の速度が流入・圧縮・外向きへ変わる。3回の有限供給を時差で送り、尾も同じ経路を進んで空になる。固定ring、塊scale、fade、noise寿命穴0。3薄層、固定5色、12fps、.055m Grid、中心の圧縮拍と同期した実ライト。

## 実描画QA

全体 .2,.6,1.15,1.6,2.2,2.8,3.6,4.7。flow .8〜1.5 の.1秒8コマ。end4.0〜4.7。全体/end dist9、flow dist6。CLI固定60fpsの全PNG目視。通常速度動画の視聴ではない。

- 3: 進む肩、遅い腹、中心への集まりと返しの向きが隣のコマで変わる。
- 4: 深紫外、中間紫、短い白桃芯が数えられる。
- 5: 房を構成する曲面が開き、ピクセルの隙間で奥が見える。
- 6: 終わりは接線方向へ進む有限の房。宙に止まる残骸なし。
- 7: 外・中・芯は供給幅と最終区間が違い、別時刻に末尾が抜ける。

0回: 房が細く小さく、中心が弱い。
1回: 高さと断面を広げ、断面を立体に。房が泡に近づいた。
