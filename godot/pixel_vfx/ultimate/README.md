# 星海の戴冠門 — Celestial Apotheosis

22秒のPixel×Realポータル。主役の門に、床6・天冠7・空間流7の20系統を組み合わせています。前作「星図の織門」の補助・装飾4系統を基準に5倍です。系統のコピー数やシェーダーの重ね枚数は装飾数へ加算していません。

## 試す

- このリポジトリ: VFX Lab →「Pixel×Real・大／多」→「星海の戴冠門」。
- 単独デモ: `demo.tscn` を実行。ZIPのデモはGodot 4.7.2 / Forward+向けです。
- マウスドラッグで視点回転、ホイールでズーム。ボタンで再生し直し・一時停止、下のスライダーで任意時刻へ移動できます。

## 組み込む

`pixel_vfx/ultimate/` フォルダーをそのままプロジェクトの同じ位置へコピーし、`apotheosis.tscn` を3Dシーンへ配置します。自動再生し、22秒で子ノードごと削除されます。

```gdscript
const Apotheosis = preload("res://pixel_vfx/ultimate/px_apotheosis.gd")
var fx = Apotheosis.spawn(self, world_position, 1.0)
fx.playback_speed = 0.5 # 0で停止
```

主鑑賞方向は正面〜斜め。門はXY面、床はXZ面、+Z側が正面です。等倍でおよそ幅10m・高さ8m。実行中の向きはNode3Dの回転で変えられます。デモのカメラ・照明・床・UIは演出本体へ含まれません。外部テクスチャやプラグインは不要です。

`free_on_finish=false` なら終了後もノードを残します。`start(size)` で作り直し、`stop()` で非表示にします。手動プレビューの `pose(seconds)` は見た目の位置指定で、寿命管理は通常の `_process` が担当します。

## 構成と退出

0–3秒: 発生印と地表脈路。3–7秒: 左の熱流と右の液膜。7–12秒: 門・文字・鍵・冠。12–16秒: 圧力膜の放出。16–21.8秒: 冠の消灯、上昇する残材、床へ落ち切る星雨。

ノイズの穴開けによる一斉消失は使っていません。文字は筆順で消灯、流体は後尾まで流れ切り、花弁は根元から離れて上へ抜けます。20系統の詳しい役割・タイミングは `FLOOR.md` / `CROWN.md` / `FLOWS.md`、合成改善は `DIRECTION.md` を参照してください。

実描画と自動動作確認を行った試作です。販売用の性能保証・幅広い端末検証はまだ含みません。
