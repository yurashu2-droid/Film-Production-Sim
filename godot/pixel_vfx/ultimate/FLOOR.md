# 星海の戴冠門 — 床の6系統

`celestial_floor.gd` は親の時計だけを受け取る。APIは `setup(size)` と `update(t)`。22秒で完全非表示。シェーダーの TIME と Tween は使用しない。

| 系統 | 役割と動き | 終わり |
|---|---|---|
| 六つの発生印 | 0.25秒から時間差で筆順に開く結び文字。供給の到達時だけ小さな金の印が応答 | 16秒から線の始端を後端が追い、個別の筆順で排出 |
| 流入脈路 | 2.35秒から放出。六つの印から中心へ、屈曲路を短い脈が渡る | 最終供給停止後も進行先へ進んで到達 |
| 分割方位盤 | 5.4秒から12の独立区間が描かれる。後半周だけ方位目盛り | 17秒から始点をずらして扇形にぬぐう。半径は固定 |
| 地表文字行 | 7秒から中央通路を避けた六行各4字を一文字ずつ筆記。前景に独立した二行を置く | 読む順に色が沈み、文字が少し地面に沈む |
| 花弁状反響 | 10.4/12.6/14.3秒の応答。六つの離れた弓状波面が周縁へ伝播 | 外へ抜けつつ横へ広がり減衰。完成した輪の拡大ではない |
| 低密度地霧 | 16.1秒から六印の残りが地表を曲がって運ばれる | 放出済みの肩が外へ移流し、上昇・拡散して密度を失う |

色は青緑・深青・紫を主とし、金は重要な印と応答に限定。中央主役を覆わない。寿命ノイズ穴は0層。6系統は描画材質数ではなく意味の違う現象を数える。

## 合成確認と改善

- r0観察: 線の太さが一様に細く、1.5〜4秒の床単独時間が弱い。
- r1: 六つの供給印を左右と手前へ分散し、字画を太細に分けた。流入脈の幅、方位盤の線幅を調整。反響の滞在を3.4秒にして外への伝播を読みやすくした。
- r2: 印の中へ短い太字画を追加。前景二列の地表文字を独立配置し、字形を大きくした。反響は中央の波面を厚く、両端を細くして放射する花弁の形を明確にした。
- r3: 手前印と地表文字が接近していたため、印をZ2.65→2.30へ移し、両者の余白を確保。
- `tests/shots/vfx_review/apotheosis/floor_r3.png` 全体、`floor_flow.png` 12.4〜13.1秒、`floor_end.png` 16.4〜20.4秒を確認。Forward+でGDScript/シェーダーエラーなし。
- 連続コマでは、流入の前後移動、外へ向かう反響、印→文字→盤の時間差で減る退出を確認。霧は低密度で主張を抑えているため、引きではほぼ読めない。通常速度の視聴評価は含めない。
