# 低音の三打（sound_bass）

床の低い圧力を .55 / 1.05 / 2.05秒に三度放出する。第一打は左肩の短い強打、第二打は低く短い、第三打は一番広く長い。約1.67–2.05秒の描画が空になる間がある。

API `spawn(parent,ground,size=1)`。life5.6 / speed1。共有vfx_sound_scoreをattach。音は親のage/speed/pauseに同期する。

旧版の暖簾状の平行横縞は親レビュー後に撤去した。各打は三層×二つの広い圧力房。左の肩が先へ出る→短打では0.1秒後、第三打では0.32秒後に右の広い房が出る→右の房が1.42m/sで、0.88m/sの左肩へ追いつき追い越す。局所の圧力肩と遅い腹がシルエットの凹みを動かす。閉じたリングや同じ全体形状の拡縮を使わない。

紫の外層、青い腹、短い白～淡金の圧縮芯。白熱は最初に供給元から前へ抜け、青は3.9前後、紫の上肩は4.9前後に空になる。短打も下側から上肩へ空になる。寿命のノイズ穴消し0層。

参考: 極光の励起伝播とTechnoramaの[Sound Patterns](https://explorer.technorama.ch/en/exhibit/sound-figures)の振動/共鳴。空気圧の房は芸術的解釈、科学的可視化ではない。

自己QA: `tests/shots/vfx_review/sound_bass_qa_full.png` / `_flow.png` / `_end.png`。独立スタジオ、fixed-fps60、距離9、注視高2.2、1.7m人型併置。full `.25,.65,1.15,1.75,2.35,3.00,4.35,5.10`、flow2.1–2.8、end4.4–5.1。全画像を実見。通常速度動画を見たとは主張しない。

修正: 初版の低い縦カーテン→高さと横圧力筋→短打の立ち上がりと供給終了（2回）。親レビュー後、単一の曲面/平行縞を捨て、先行肩と追い越す後続房へ分割（3回）。短い白熱と青/紫の出口時間を分離（4回）。

8問: 1)三打と間。2)第三打高約2.5–3m。3)一つの左房から後ろの右房が追って前へ出る。4)紫/青/圧縮芯が別。5)手前から奥と床が見える。6)静止した白い浮き玉なし。7)芯/腹/上肩が別時刻で抜ける。8)5.1秒は空。

限定: 自己QAの未評価。初めの二打は第三打よりかなり控えめ。低音そのものの感覚は静止画だけでは評価できない。旧版の平行縞と連結した巨大な暖簾は撤去した。
