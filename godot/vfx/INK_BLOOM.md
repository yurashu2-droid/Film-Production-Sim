# 墨の開花

地面の小さい裂け目から墨が噴き、薄い杯の肩が不揃いな五本の舌へ分かれる。最も高い舌は約3.8m。供給は3.0秒で止まり、各流路の尾から切れても前方の墨は巻き返して地面へ落ち続ける。金・短い白芯が先に流れ去り、黒が下流の膜に変わり、その膜が別の順序で吸収される。

実装は `vfx_ink_bloom.gd` と `shaders/ink_bloom_flow.gdshader`。標準の `spawn(parent, ground, size)`、age/speed/停止に対応。life=5.7秒。方向・高さ・発生遅れ・移流時間が五本で異なり、局所の肩の幅、中心線、巻き返し、黒/金/白の径を毎フレーム作り直す。22x12の殻15枚と15x12の地表膜5枚で、32x32の大量メッシュは使用しない。恒常的な流れの疎密は使うが、寿命で増えるノイズ穴は0層。

参考画像は `tests/shots/vfx_review/ink_dragon_mid.png` と `ink_dragon_end.png` を実際に見た。その他の全演出を再生したとは扱っていない。物理的な流体計算ではなく、上昇圧力と重力落下を素材ごとの時刻差で誇張した表現。

## 描画と修正

専用の無登録スタジオ、距離9m、白い1.7m円柱と0.5m箱、fixed-fps60。全体8コマは0.22/0.55/1.0/1.55/2.1/3.05/4.05/5.2秒。動きは1.3〜2.0秒、終わりは4.5〜5.2秒を0.1秒刻みで8コマずつ撮影した。動画を視聴した確認ではなく、実レンダリングの連続静止画確認。

- 初回：細長い金の戻りが棘に見え、問い1/4に弱さがあった。
- 修正1：黒の肩と落水幅を広げ、金/白の径を絞った。太い黒が硬い面に見える問題が残った。
- 修正2：左右交互の巻き返し、軸方向の時間差、粗密と断面の分割数を変更。暗い縁の角張りが残った。
- 修正3：上昇と重力下降を非対称の流路へ変更。金/白を流れる短い腹へ限定。輪郭の変化は読めるがマスクが破片状だった。
- 修正4：長い筆筋の恒常マスクを試した。面がべた塗りに寄ったため不採用。
- 修正5：流れる粒度と別位相の柔らかい疎密を重ね、薄い膜の透過を導入。黒の奥の流れが見える状態へ変更。

最終画像：`tests/shots/vfx_review/ink_bloom_r5_whole.png`、`ink_bloom_r5_flow.png`、`ink_bloom_r5_end.png`。三種とも実際に見た。

## 八つの問い

1. 地面から上昇して開き、落ちる流れは読める。花の固定メッシュの拡縮ではない。
2. 1.7m円柱に対して主役は約2〜2.3倍。過大な高さではない。
3. 隣り合う動きのコマで左の肩、最上部の傾き、下流の首が変わる。
4. 広い黒い外膜と、細い金の流路、短い白芯が別々に見える。
5. 黒の空隙と透過から奥の膜と床が見える。
6. 終盤の上側は落下する材料として地表へ接続し、残留する宙の塊はない。
7. 金/白の通過終了、黒の落水、地面の膜の下流吸収が別時刻・別方向で進む。
8. 5.2秒のコマではエフェクトは残っていない。白い円柱と箱は基準物。

残る弱さ：黒の薄い縁は写実的な液体より筆線・薄い膜寄りに見える瞬間がある。好評を得た作品と断定していない。

所有範囲の確認ハーネスでロード、8時刻の再構築、speed=0停止、speed=12で寿命片付けを確認し、`PAIR_PAUSE_AND_CLEANUP_OK`。全体の登録とテストは統合担当が行う。
