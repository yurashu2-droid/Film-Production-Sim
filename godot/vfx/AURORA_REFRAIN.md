# 極光の返し：設計と制作記録

## 意図
畳まれた発光の幕へ励起の波が届き、先行する波と遅れる返しが折り目を動かす。
短い二つの応答の後に空白を置き、左右からの波が合流して幕が大きく開き、上へほどける。
見どころは不等間隔の応答と流れの受け渡し。カメラは固定、音なしでも拍が読める構成。

既存LabのIDと、近い形の `water_wave` / `ff_ring` / `ff_whip` の描画を確認。
輪・噴流・飛ぶ頭・殻を持つ球・斬撃を主形状にせず、横方向の折り返す極光を新規に作る。
既存VFXを全て動画で見たという記録ではない。

## 拍と形
| 時刻 | 拍 | 主形状と力 |
|---|---|---|
| 0.00–0.65 | 低い予備動作 | 薄い短い幕が中央へたわみ、光が根元へ集まる |
| 0.70–1.12 | 強い先行 | 左からの励起が折り目を右へ押し、後部が遅れて伸びる |
| 1.18–1.70 | 小さな返し | 右から戻る波が先行する折り目を追い越す。面全体を一斉に揺らさない |
| 1.75–2.10 | 間 | 底の低い光とゆっくりほどける折り目を保ち、次の動きを溜める |
| 2.20–2.85 | 最大の開き | 左右から中央へ波が合流し、白い折り目と背後の緑の流れが立ち上がる |
| 2.90–3.12 | 遅い余韻 | 山を越えた波の折り目が遅れてほどける |
| 3.12–3.70 | 芯の受け渡し | 白い励起が両端から中央へ伝わり、緑の流れへ渡る |
| 3.60–4.45 | 緑の出口 | 左が先に外へ抜け、右は遅れて曲がる。肩と首が異なる時間で動く |
| 3.95–4.75 | 外の出口 | 下部への供給が切れ、上に残る薄い幕が引き伸ばされて離れる |
| 4.85–5.80 | 回復 | 空間が空になり、次の再生前に余白が残る |

各部を単純な移動・scaleだけで動かさない。各地点を通過する波により、奥行きの折り目、下端の曲線、局所高さと密度が変わる。
3層の低密度の発光流を異なる奥行きに置く。外の青緑→緑→白い芯。寿命ノイズ穴消しは0層。
原型は薄いwisp層。固い輪郭を避け、極光の光学密度と異なる出口を出すため専用シェーダーを使う。
粒・地面陣・火花を足して主役を隠さない。

## 参考と演出の区別
- 極光の波・折り目・幕：[NASA Auroras: Dancing in the Night](https://science.nasa.gov/earth/earth-observatory/auroras-dancing-in-the-night/)。自然の秒数を再現するものではない。
- 拍の予測と適度なずれについての音楽研究：[Witek et al. 2014](https://pubmed.ncbi.nlm.nih.gov/24740381/)。映像の心地よさを保証する研究とは扱わず、余白と遅れる返しの設計の参考にする。

## 描画QAと修正
- 0回目：縦の光が個別の棒として伸び、音量メーターに見えた。形と層の問い3–5が不十分。
- 1回目：光の通路を広げて連続した幕へ戻し、奥行きの折り目と遅れる余韻を作った。白い面の占有率がまだ大きかった。
- 2回目：通過する波が肩を横へ押し、遅れる部分が首を引く変形を追加。白い芯を下端へ集中し、背後の緑を見せた。左右端が硬い三角のひれに見える箇所が残った。
- 3回目：端の白熱部を短くし、端の密度を滑らかに落とした。全体・隣接コマ・終わりを再描画。

確認した範囲は全体8枚、見せ場2.2–2.9秒を0.1秒刻み、出口3.7–4.4秒、最後4.6–5.3秒、通常/撮影露出の30fps連続コマ。
動画そのものを視聴したという記録ではない。固定60fpsでシミュレーションし、6秒/180枚をMP4へ保存。

手順書の問いへの回答：
1. 横に続く光の幕へ波が走り、返しと合流が起きる形が読める。
2. 寄り距離9mで、最大の山は人物の約2倍の高さ。幅は6.6mの横広がり。
3. 隣接コマで左右の山が中央へ進み、肩・首・奥行きが変わる。
4. 暗い高い幕、緑の折り目、低い明るい芯が別の高さ/奥行きに見える。
5. 密閉した面を作らず、低い部分や折り目のすき間から背景と奥の流れが見える。
6. 終わりに独立した塊・球・棒の残骸はない。
7. 改訂後は左の緑が先に抜け、右は遅れて曲がり、外の淡い幕が上へ離れる。白い芯の中央への伝播は控えめ。
8. 改訂後の確認コマでは4.6秒以降が空になる。

初回制作時の明度差分の参考値（通常表示、空の最終コマとの差の画面平均。心地よさの判定ではない）：
1.00秒=2.396、1.43秒=1.291、1.93秒=0.370、2.50秒=6.190、5.17秒=0。
最初の応答→弱い返し→休符→最大の開き、という配分が出力にも残っている。

初回の検証：`vfxtest.gd` の生成・一時停止・寿命片付けはOK。`bash run_tests.sh` は全項目を完了し終了コード0。
MP4は960×540、30fps、6秒。`play_vfx.bat --only=aurora_refrain` でラボ再生。

## 消え際の改訂（PLAYBOOK 0.5）
拍の構成を保ち、白い芯→緑の流れ→外の薄い幕の順で出口を作り直した。寿命ノイズ穴消しは引き続き0層。

- 1回目：白の中央への伝播、緑の両端への伝播、外の上昇を追加。左右端が二枚の硬いひれとして残った。
- 2回目：左と右の伝播速度を変え、緑の各地点を外へ運びながら曲げた。まだ面の上下端が硬かった。
- 3回目：緑の上端・下端・左右端の発光供給を先に弱め、流れの輪郭をほどいた。

出口3.2–4.6秒を0.2秒刻み、最後4.6–5.3秒を0.1秒刻みで目視確認した。
3.2–3.4秒では左右の三角形が残るが、3.6秒で中央の膜が離れ、3.8–4.2秒では右の光が曲がって細く抜ける。
4.4秒では上側の薄い余光と短い筋へほどけ、4.6秒以降は空になる。
白い芯が中央へ集まる動きは画像上では弱め。左右の時間差と外の上昇は読み取れる。

改訂の検証：通常表示・撮影露出の描画でシェーダーエラーなし。`vfxtest.gd` は `VFXTEST_OK`、終了コード0。
全体テストの再実行はしていない。修正版は `tests/shots/vfx_review/aurora_refrain_exit_revised.mp4`。
960×540、30fps、180フレーム、6秒の書き出しを確認した。
