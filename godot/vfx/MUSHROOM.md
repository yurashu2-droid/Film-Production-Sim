# 提供動画を基準にした白熱爆発

`Desktop 2026.10.08 - 00.35.38.03.mp4` の白熱火球・くびれた火柱・橙の炎輪・地面の炎を基準にした実装。以前の連続密度場の試作は薄い炎と茶色い煙へ変わったため不採用。現在の `mushroom` は `vfx_blast_reference.gd` と `vfx_reference_aux.gd` を呼ぶ。

**状態：実装・描画確認済み、ユーザーの見た目評価待ち。** 配置と拍を合わせた作り直しであり、元動画の完全再現とは評価していない。特に炎の細かな分岐・地面の房の密度・カメラの軌道は差が残る。

## 再生

`play_vfx.bat --only=mushroom`。Pで停止、Enterで再発火、ドラッグで視点回転。撮影露出への切替も可能。

```gdscript
const Blast := preload("res://vfx/vfx_mushroom.gd")
Blast.spawn(self, ground_position, 1.0, "mushroom")
```

接地点と大きさ倍率を指定する。親のscaleは生成時の倍率だけで、運動中は変更しない。4.5秒で本体・補助・飛散物が片付く。

## 参考動画の拍と出口

動画の約1.30秒を発火0秒として比較する。0.2秒で半径が先に広がり、0.3秒ほどで火球が地面から持ち上がる。約0.43秒で炎輪が出現。約1.95〜2.35秒で明るい火球が崩れ、その後は小さい火の粉が残る。途中の接近カメラは近似。固定視点でも形を点検する。

| 層 | 運動 | 消え始め／出口 |
|---|---|---|
| 白熱火球 | 圧力膨張と浮上を別の拍にする。太い7本の主舌の高さ・肩幅・曲がりを時間差で動かす | 1.95秒。明るい皮が上・外へ離れながら割れる。ノイズ穴を使う唯一の層 |
| 火柱 | くびれを保ち、根元から上へ熱の筋を送る | 1.90秒。供給の根元が上へ追い上げられ、首が細って火球側へ抜ける。穴消しなし |
| 地面の8房 | 外へ張り出す腹から冠へ膨らみを伝播する | 約2.0秒から房ごとに時差。色が冷め、冠を先に落とし、根元へ畳む。穴消しなし |
| 地面の炎舌 | 太い3本が先行し、短い枝が遅れて噴く。外向きの初動から上向きの折返しへ変わる | 約1.7秒から時差。根元の切離点が先端へ進み、残った腹が昇りながら細る。穴消しなし |
| 圧力の炎輪 | 火球より遅れて冠の周りに開き、外へ進み続ける | 1.65秒から断面を薄くし、2.45秒までに薄れる。穴消しなし |
| 火の粉 | 異なる高さから短時間に噴き出した熱の束。放出時刻ごとに方向・速さを変え、先頭・腹・尾がせん断される。6本の供給と、腹から遅れて剥がれる3本の枝 | 白熱は最初の0.12秒まで。供給停止後は尾の材料を先に絞り、古い材料が燃え尽きるにつれ輪郭を前から失う。黄→橙赤へ冷める。固定の球状の芯・オーラ・ノイズ穴なし |

火の粉は `vfx_ember_stream.gd` / `ember_stream.gdshader` に分離した。旧版の7個のSphere芯とSphereオーラはユーザーに「個体っぽさがすごい」と指摘された。新しい版は同じ物体の過去位置を尾へコピーせず、各地点を別の放出時刻の材料として動かす。最大幅と高温の腹も先頭へ固定しない。見た目の採否はユーザー評価待ち。

## 素材と確認

所有者提供 `C:/Programer___Amano/VFX/LeLu's Noise Pack (FREE).zip` の `T_FirePanningCyl45.png` を使用。取り込み済みの `assets/vfx/lelu_noise/firepanningcyl45.png` は画像を加工していない。火球の主舌の先端の細分岐と地面炎の色の筋へ使い、外形の運動は別の頂点変形で作る。出典・利用条件は同じフォルダの `SOURCE.md` と原文 `readme.txt`。元の有料爆発エフェクトは使用していない。

`Lib.flow_noise()` のRGは歪みの方向場。形・流れ・色・供給停止は別の情報として扱う。

`tests/shots/record_reference_rebuild.gd` は30fps、144枚を記録する。通常は固定カメラ、`--zoom` は接近、`--film` は撮影露出。接近カメラは元の軌道を復元したものではない。

`tests/vfxtest.gd` は出現・停止・片付けを確認し、`VFXTEST_OK`。画面あり録画でシェーダーを確認する。`bash run_tests.sh` は既存の `LAB_CHECK dust geometry expires FAIL` で停止する。爆発の変更とは別の土煙テストであり、この作業では修正していない。
