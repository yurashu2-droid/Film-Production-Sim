# 墨の寄せ波（ink_undertow）

三本の太い墨舌が左右の時差で地面から噴き、先に出た唇が巻き下がる間も、新しい腹が遅れて立つ。旧版の連結した波面は親レビューで膜に見えると判定されたため撤去した。実見した墨龍mid/endの広い黒筆跡、細い金脈、短い白熱を参照した未評価の試作。

API `spawn(parent,ground,size=1)`。life5.8 / speed1。三本の発生は .05/.27/.54秒、供給終了は1.15/1.40/1.55秒。各材料の放出時刻を保った弾道で中心線を再構成する。古い先頭が先へ落ち、新しい腹が追い、供給停止後に根元が空になる。black/dark umber/gold/brief whiteの四層。外形の幅・首は材料年齢と放出圧で変わる。直径の均一な筒を並べた構造ではない。

空中の30滴は描画と同じ材料位置/速度から分かれ、その弾道の正確な着地点へ個々の染みが出る。goldは前へ抜け、whiteは短く終了、黒の古い腹は重力落下、染みは大きさを保って左から乾く。5.2秒までに空。寿命のノイズ穴消し0層。

自己QA: `tests/shots/vfx_review/ink_undertow_qa_full.png` / `_flow.png` / `_end.png`。独立スタジオ、fixed-fps60、距離9、注視高2.2、1.7m人型併置。full `.25,.65,1.15,1.75,2.45,3.10,4.00,5.30`、flow1.8–2.5、end4.6–5.3。全部実見。通常速度動画の視聴はしていない。

修正: 初版の壁→前へ巻く膜→永久マスクの横向き化→暗褐内層/白熱独立→画面内着地/乾燥時刻（4回）。親レビュー後、連結波面を撤去し時差の三本の墨舌へ構造変更（5回目）。外側の透けと内部空隙を増やし、太い閉じた塊を削減（6回目）。

8問: 1)時差で噴いて前へ落ちる。2)主役高約2.7–3m、人型約1.6–1.8倍。3)早い左舌が巻き落ちる間、中右が追う。4)黒/褐/金と短い白熱が別。5)床と奥の流路が透ける。6)滴は弾道中だけ、静止塊なし。7)芯→金の流路→黒の落下→染み乾燥が別時刻。8)end最終コマは空。

限定: 自己QAの未評価の試作。単一の大波から独立した三つの液体舌へ変わった。写実の液体シミュレーションではない。内部の細筋は残るが、側面をつなぐ巨大膜と同じ全体ポーズは撤去した。
