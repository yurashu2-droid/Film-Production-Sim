# どたばた乱闘雲

撮影用の独立したVFX。約3.25秒で「集まる → 殴り合う → 縮む → 弾ける → 消える」を見せる。
土煙の房が中の拳に押されて伸び、交互の打撃で形を変える。最後に回転を止め、決着の瞬間の方向へ小房が飛ぶ。

```gdscript
preload("res://vfx/vfx_brawl.gd").spawn(self, ground_position, 1.6)
```

`ground_position` は接地点、`size` は演出全体の倍率。役者、当たり判定、ネットワークのイベントは変更しない。
現時点の試用場所はVFX Lab。`play_vfx.bat --only=brawl`、またはLabの一覧から「どたばた乱闘雲」を選ぶ。
一時停止、スロー、撮影カメラの明るさ切り替えにも対応する。

## 既存VFXから抽出したルール

全ライブラリ、9種のシェーダー、ゲームに接続された旧土煙3種を読み、Labの10項目と走り8スタイルを描画して確認した。

| 既存の演出 | 観察した役割 | 新作への反映 |
| --- | --- | --- |
| 爆発・小爆発・旧爆発 | 閃光から塊、破片、余韻へ主役が移る | 決着のマークから外へ飛ぶ房へ受け渡す |
| 炎 | 根元の芯、炎の面、上の煙でまとまりが出る | 乱闘中の雲を中央に保ち、筆線は補助にする |
| アニメ調煙・フラット煙 | 房の形と陰影の段、最後の溶ける穴 | 継続中は穴を開けず、終盤だけ溶かす |
| 炎・秘術・毒の飛び道具 | 溜め、頭、軌跡、着弾に別の仕事がある | 溜め、拳、円弧、打撃マークを同じ時間表へ揃える |
| 落雷 | 細い予兆から本流へ、光り直しで強弱が出る | 低い煙の予兆から膨らませ、3発の間隔を不揃いにする |
| sculpted / mesh / kenney | 接地、伸び縮み、房や絵の輪郭が足の力を伝える | 地面より下へ潜らせず、房を1つずつ振り付ける |
| smear / volt | 本体に結びついた形の変形が動きの方向を伝える | 雲全体を打撃軸へ伸ばし、横方向を圧縮する |
| thunder | 発射、頭、軌跡、補助、終わりを一つの動きにする | 拳・雲・筆線・マークを同じ打撃の結果として動かす |
| kick / scramble | 描く房と脚を増やすこと自体が漫画の動きになる | 汎用ミトンを雲から短く出し、内部の殴り合いを示す |

参考：『トムとジェリー』の乱闘雲、『ルーニー・テューンズ』タズの回転。
回転の参考映像は [WB Kids「Tasmanian Meltdown」](https://www.youtube.com/watch?v=NhJcOYZotiw)。素材の転載はせず、メッシュとマークはコードで作る。

## 振り付け

| 時刻 | 形の変化 |
| --- | --- |
| 0–0.3秒 | 低い小房が内側へ集まる |
| 0.26–0.44秒 | 低い煙から立体の塊へ膨らむ |
| 7 / 12、12 / 12、17 / 12秒 | 交互に拳が出る。同じ方向に雲を伸ばし、脇を圧縮する |
| 1.72–23 / 12秒 | 中心へ縮み、次の破裂を予告する |
| 23 / 12–2.6秒 | 回転を止め、決着のマークと放射状の房に分かれる |
| 2.6–3.25秒 | 小房が縮み、穴が開いて消える。ノードも片付く |

本体と補助の形は12fpsで更新。18房をMultiMeshで描き、雲と輪郭線を共有する。
6本の幅の違う筆線、3つのミトン、4つの非発光マークを使う。Tween、外部の画像素材、頂点ごとの乱数は使わない。
光の色違いではなく、打撃による体積の変化を中心にした。

## 確認

```powershell
& ./tools/godot/Godot_v4.7.2-stable_win64_console.exe --path godot --fixed-fps 60 res://vfx_lab.tscn -- --shots --only=brawl
& ./tools/godot/Godot_v4.7.2-stable_win64_console.exe --headless --path godot --script res://tests/vfxtest.gd
```

`godot/tests/shots/vfx_review/brawl.png` と `brawl_film.png` を確認する。
最初の描画で雲全体の押され方が弱かったため、打撃軸への変形を追加した。
決着の時刻を12fpsのコマ境界へ合わせ、最大のマークが最初のコマで出るよう修正した。
通常・撮影露出の両方で形を読み取れ、最後のコマに演出が残らないことを確認する。
既存のVFX検証へ、生成・停止・全体片付けの確認を追加した。
