# 炎の竜巻（試作・ユーザー未評価）

ユーザーが成功したと説明した多層竜巻の構成を参考にした炎版。
薄い炎の層のすき間から奥の流れを見せ、外側の赤から中心の白熱へ明度を上げる。

| 部位 | 供給・運動 | 供給停止後 |
|---|---|---|
| 本体6層 | 根元から点火が上へ伝わる。共通の軸に沿い、層ごとに回転・上昇・位相が違う炎が交差する | 根元から供給が途切れ、遅れる上部の舌が局所的に細くなり、昇って薄れる |
| 根元2層 | 地面から太く巻き上げ、本体と別の速さで循環する | 赤く冷め、上側から根元へ戻る |
| 地面3層 | 大きさ・腕数・回転方向の違う部分模様を重ね、炎が腕に沿って内側へ流れる | 巻き締まり・周方向の掃き出し・径方向の排出を時間差で行う |

ランダムなノイズ穴による寿命消去は0層。炎の恒常的なすき間と低周波の流路歪みは消去と別の役割。
ノード全体を拡縮して動かす構成や、球・細長い線の火花は使わない。

炎シルエットは `assets/vfx/lelu_noise/firepanningcyl45.png`、歪みは `marblenoise_tiled.png`、地面の部分形は `vfx_spiral07.jpg`。
出典は同フォルダの `SOURCE.md`。この効果の内部でmipmapを作り、共有画像の取り込み設定は変更しない。

```gdscript
const FireTornado = preload("res://vfx/vfx_fire_tornado.gd")
FireTornado.spawn(self, ground_position, 1.0, 2.1) # 大きさ、供給を続ける秒数
```

Lab: `play_vfx.bat --only=fire_tornado`。既定の寿命は4.3秒。
本体・根元・地面を停止後も抜き切ってから自動削除する。Labの一時停止・コマ送りに追従。

描画確認：通常表示・撮影露出・横方向、30fpsで5秒。
初回の細かいちらつきと硬い地面の面を、フィルタ付きの炎と疎な加算層へ修正。
最終的な見た目の評価はユーザーのフィードバックを待つ。
