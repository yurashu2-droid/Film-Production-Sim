# 最初の一本：自社の紹介動画（1日目・遊び方を覚える回）

2026-10-18 にユーザーと決めたこと。作る前の仕様。絵コンテの下書きは `tests/_cm_board.gd`（4場面）。

## 設定

- 新しく立ち上げた映画制作会社。怪しい情報商材「絶対バズる！会社紹介動画メソッド」を **100万コイン** で買ったばかり（払い終わった）。
- 土地（会社の敷地）だけは立派だが、撮影の道具がほとんど無い。お金も無い（100万コインを払ったので）。
- カメラは **三脚なしの本体だけ**。1日目は、段ボールを積んで高さを作り、その上にカメラを載せて撮る。倒れたらハプニング。
- 三脚・移動レール付きのカメラは、「会社を大きくする」で買えるようになる。**2日目以降も、三脚は買うまで無い**（ユーザー了承済み。ほかの依頼の難しさも上がる）。

## 始まり（短いストーリー）

- 始まった瞬間、お金は 1,000,600 コイン（ふだんの始まりの600＋100万）。単位はコインのまま。
- 宅配の箱には請求書が貼ってある。箱を開けると、お金がくるくる減って −1,000,000。「チャリーン……」と鳴り、600 だけ残る。
  お金の表示の場所も、ここで覚える。
- 立派な敷地に、宅配の箱がひとつ置いてある。箱には「絶対バズる！会社紹介動画メソッド（100万コイン）」。
- プレイヤーが自分で箱を開けると、ホログラムの怪しい講師が出てくる（「機材？ 成功者は機材に頼らない！」）。
- ムービーを見せるのではなく、ゲームの中で箱を開けて始まる。読ませる所は短く、すぐ手を動かす。2回目からは飛ばせる。
- 講師は、まず会社の看板を作れと言う（段ボールをたたんで、接着剤でつないで、スプレーで社名を書いて、入口の上の金具に掛ける）。
  そのあと、掲示板で依頼を受けろと言う。

### 箱が落ちてくる所から始まる（2026-11-10）

ユーザー（1日目を遊んで）：「親切さがない」「段ボールを開ける理由が最初ない」「最初に段ボールが落ちてくるところから」「段ボールをガタガタさせるとか」。
前は、箱は事務所の中に最初から黙って置いてあった。今は `features/delivery_box.gd` がこう動く。

- 動けるようになって 2.2 秒後、起きた所の目の前（前と同じ場所）に、箱が空から落ちてくる（事務所は屋根なし）。ほこり・音・画面の小さな揺れ。
  落ちてくるまでは、画面の下の案内に何も出さない（空っぽの事務所を見せる間）。落ちたら「届いた宅配の箱を開けよう」。
- 落ちた箱は、開けるまでガタガタ動く。ふたが少し浮いて、すき間から青い光がもれる。中からこもった声がする（字幕。講師のせりふより小さく、くすんだ色）。
  声は、はじめは「……もしもーし？」から。放っておくと、だんだん間が詰まって必死になる（45 秒でいちばん必死）。そばに人がいると、その人に呼びかける。
- みんなが 4.5m より離れて 3 秒たつと、いちばん近い人のほうへ跳ねてついて来て（1回 1.5m・約1秒おき）、2.2m 手前で止まる（事務所にいる間だけ。壁や物で道がふさがっていれば跳ねない）。
- 開けると、ふたが弾けて青い光があふれる。貯金の数字が画面の真ん中に大きく出て、くるくる減り、そのあと貯金の表示の所へ縮んで飛んでいく（どこに出ているかを覚える）。
- 落とす時・跳ねる先・開けた事は、ホストが決めて全員に送る。ガタガタと声は、各自の画面。あとから入った人には、止まっている所にもう在る形で渡す。
- 一緒に直した物：箱の当たり判定が見た目の2倍の高さだった／送り状の紙が箱の上にはみ出していた（外形に、ふたの破れ目の部品まで数えていた）。
- 確認：`tests/tutorial_box_test.gd`（`TUTBOX_SHOTS=1` で絵）。二人通信では確かめていない。

役目は「なぜ箱が届くのか・なぜお金が無いのか」を先に見せること。操作は教えない。約21秒。怪しい情報商材の広告のパロディ。

| 秒 | 場面 | 中身 |

| 10.5〜15.5 | 値段 | 「通常 300万コイン」に線 →「今なら 100万コイン！」。「※効果には個人差があります。たぶん」 |

- キャラ（講師＝素材06・成功者＝素材01）と段ボール箱は、自分だけの小さな世界（SubViewport）に並べて、画面いっぱいに映す。字と絵は 1280x720 で組み、画面の大きさに合わせる。
- 流すのは、会社を開いた人（ホスト・ひとり遊び）の、ふつうに遊ぶ1日目の始まりだけ。あとから入った人・倒産してやり直すとき・自動確認では流さない。
- 流れている間は動けない。Enter・Space・Esc・クリックで、いつでも飛ばせる。流れている間は、箱は落ちてこない。
- 音は、手元の効果音だけ（曲・声は無い）。字は仮（言い回しは、見て直す）。

### 講師は、一度に1つだけ教える（2026-11-10。`features/day1_guide.gd`）

前は、箱を開けると講師が9つのせりふ（約38秒）で全部の手順を先に言い、あとは画面の下の1行だけだった。
今は、箱の上のあいさつは4つ（「では、ついてきなさい。ひとつずつ、教えます」まで）。そのあとは、案内の講師が紹介動画を納品するまで付きそう。

- 講師（青いホログラム）が、次に使う物・行く場所のそばへ先に行って立つ。目当てには、青い輪・矢印・細い光の柱が出る（映画には映らない）。
- 言うのは、いまやる事を1つだけ（字幕。5.5秒で消える）。30秒進まなければ、同じ事をもう一度言う。画面の下の案内の先頭にも、いまやる事を1枚出す。
- 番の順：掲示板で依頼を受ける → 段ボールを2つ積む → カメラを載せる → 城の板 → 爆炎の書割 → 机の上の台本を撮る場所のそばへ → Y で社長の役に入る → カチンコで本番。
  持っていく物は、手に持つまでは物が目当て、持ったら置く所が目当て。
- 順番を飛ばしても進む（先に済ませた事は済み）。一度済んだ事は、あとで物を動かしても戻さない。
- 本番中は、場面が変わるたびにひとこと。止めると（場転）、次の用意と「台本のそばで 1」を言う。4カット目の前に、看板の作り方（Shift+F でたたむ・スプレー）を言う。
  9秒撮れないままなら、採点が数えている理由（「寄りが足りない…」など）を、そのまま言う（ホストが決めて全員へ）。
- 撮れたら「このテイクを納品」。精算まで行ったら、ひとこと言って消える。2日目からは出ない。
- 教えるのは、操作と流れだけ。何を城に見立てるか・どこに置けばよく映るか、は言わない。
- 会社の前で撮る依頼は、受けるとすぐ撮影の準備に入る（軽トラの所へは行かない）。撮影に使える10分は、受けた時から減る。
- 看板づくりは、箱の直後には急がせない（`company_sign.gd` の `tutorial_step()` は、箱を開けたら ""）。
- 確認：`tests/day1_guide_test.gd`。動画：`output/preview/day1_guide.mp4`（物を運ぶ所は、置き直しで代用して録画した）。
- まだ：人が実際に運んで・撮って、言う事が足りているかは確かめていない（とくに本番中の4カット）。二人通信も未確認。

### 1日目の手順（2026-10-24。看板を先に作らせる形。11-10 に上の形へ替えた）

画面の下の案内に、今やることを1つずつ出す（`features/company_sign.gd` の `tutorial_step()` と `hook_hud`）。

1. 箱を開ける：「届いた宅配の箱を開けよう」（箱のそばでは「F 宅配の箱を開ける」）。掲示板の前でも「F 依頼を見る」は出さない。
2. 看板を作って掛ける：「段ボールで会社の看板を作って、入口の上の金具に掛けよう」。掲示板の前では「… ／ F 依頼を見る」。
3. 掲示板：いつもの「事務所の掲示板で、今日の依頼を選ぼう」。

看板を掛ける前でも、依頼は受けられる（強制しない）。理由：看板づくりは手間がかかり、上手な人もいれば雑な人もいる。
二人以上なら、一人が看板・一人が掲示板と分かれて進めてもよい。紹介動画の準備中にも作れる（4場面目に使う）。
案内と講師の言葉で先に促すだけにした。

## 台本：「バズる黄金の4カット」（情報商材の型）

| 場面 | 中身 | 覚えること |
|---|---|---|
| 1 社員紹介（一人ずつ寄り） | 社長→社員B→C→D を一人ずつ寄りで決めポーズ（ドヤ顔・手を振る・指さす・万歳）。いない役はパネルの寄り | カメラを寄せる・振る（パン）。止めて寄せ直してもいい |
| 2 お城も建てます | 城役の物を背に、社長がドヤ顔 | 物を役に見立てる |
| 3 爆発も、します | 社長の背後で爆発。社長は動じない | 爆発を起こす |
| 4 ぜんぶ、格安で！ | 手描きの看板（会社の名前・電話番号）の前に全員集合して、両手を上げる | 看板を描いて、カメラへ向けて置く。カメラを引く |

- 役者：社長は必ず要る。社員は0〜3人のどれでも撮れる。人数が少ないほどパネルが並ぶ（笑い所）。
- 1人で何役やってもいい・物で代用してもいい（役者は台本ごとに最大4人。全部の台本の原則）。
- 場面の合間に、フィルムを止めて次の用意（場転）をすることも覚える。

### 社員紹介の撮り方（2026-10-18 ユーザーと決めた）

- 静かな場面ばかりにしないため、カメラを動かす場面にした。寄りは、社員が少なくても4回（同じ人が着替えて何役でも。場転の間に Y で役を替えられる）。
- 一人撮れても、フィルムは止まらない。止めずにカメラを振って次の人へ寄れば、そのまま続きが撮れる。止めずに撮り切ると「撮影技術」の加算（+60）。
- 頭が画面から切れていても（見切れ）撮れたことにして、一人ごとに少し引く（−10）。`features/camera_craft.gd`。
- 判定は `production_beats.gd` の "roll"（その人の身長が画面の高さの 0.55 以上）。

### 看板づくり（2026-10-18 ユーザーと決めた。2026-10-24 に会社の名前の決め方を変えた）

- カンペの代わりに、段ボールで看板を作る（準備で工作を覚える）。空の段ボール箱を Shift+F でたたむと板になる。立てるときは接着剤で箱馬などに貼る。
- スプレー缶（黒・赤）を持って F を押している間、狙った板に色を吹く。字は手描き（ガタガタになるのが笑い所）。名前は打ち込まない。
- 板は何枚でも接着剤でつないでよい。上下・左右をぴったり合わせる必要は無い（きれいにやる人はやる。雑なら、それも味）。
- 仕組みは `features/spray_sign.gd`、板は `cardboard_sheet.gd`、缶は `spray_can.gd`。

### 会社の看板と、会社の名前（2026-10-24 ユーザーの要望）

- 事務所の入口の上に、看板を掛ける金具（壁から出た鉄のフック2つ）がある。はじめは空。書割の社屋の大きな看板（赤い板）には、文字は出さない。
- 描いた板を持って金具の下で F：その板と、接着剤でつないだ板が、まとめて1枚の看板として掛かって止まる（吊り紐つき）。
  持っていた板がフックの下にまっすぐ掛かり、ほかの板は、つないだ点を支点に面だけ正面へそろう。面の中のずれ・傾き・重なりは、つないだときのまま。
- 掛かった看板を左クリックすると、外れて手に持つ（つないだ板もいっしょ。依頼を受けると接着剤の点は片づけられるが、看板の板どうしは付け直す）。掛け直せる。
- 掛けた看板を、正面から正射影のカメラで撮る（看板の板だけを映す・背景は透明）。この絵が **会社の名前**。描き足したり、掛け直したりすると撮り直す。
  絵は各自の画面で撮る（板の絵と置き場所は、ほかの物と同じに全員へ届く）。
- 会社が呼ばれる文には「{会社}」と書き（`production_flow.gd` の `COMPANY`）、表示する側が看板の絵を文の中に小さく埋め込む（`ui/company_logo.gd` の `show_in`）。
  使っている所：お知らせ（ランプ部長の電話・エンディング）・精算のコメント欄・動画サイトに投稿の題（「{会社} 紹介動画」）・試写会の札（「{会社}　作品」）・看板への反応（「おっ、{会社}の看板！」）。
  文字しか出せない所（ウィンドウの題など）は `company_name()`（決まった名前）のまま。
- 看板がまだ無いとき（掛ける前・倒産して新しい会社になった直後）は「名無しの会社」と呼ばれる。倒産すると看板は外れ、金具は空に戻る。
- 帰社しても、掛けた看板は片づけない（掛かったまま）。1日目の段取り（`tutorial_day.gd`）が出す段ボール板にも使わない。
- 紹介動画の4場面目（看板の前に全員集合）は、掛けたままの看板の前で撮れる（`features/signboard.gd` の判定が通る）。外して持って行ってもよい。
- 確認：`tests/company_sign_test.gd`。

## 教え方：青いホログラムのガイド（教材のおまけ。1日目だけ）

- カメラの位置・段ボールを積む所・役者の印・城を置く所に、青い影が出る。合わせると色が変わる。
- 画面の説明文ではなく、教材に付いてきた投影機（ゲームの中の物）として出す。
- 1か所だけ明らかに変なガイドを混ぜると笑えるが、迷わせない程度にする（入れるかは作って見てから）。

## 1日目の場所と道具

- 事務所の前で撮る。廃材置き場には行かない（門は閉まったまま。2日目から開く）。
- 事務所の前に、使いそうな物を雑に積んでおく：城に見立てられる板・爆炎の書割・等身大パネル・看板に描ける板・段ボール。

## 撮ったあと：ネットに上げる（試写会のかわり）
