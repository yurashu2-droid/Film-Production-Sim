# 追加注文の札

2026-11-10。ユーザーの懸念「単調になりそう」への手のひとつ。台本（30本）とは別の束から、依頼ごとに何枚か引く。
同じ台本でも、毎回ちがう縛りで撮ることになる。仕組みは `scripts/features/order_cards.gd`、確認は `tests/order_cards_test.gd`。

## 決まり

- 依頼を受けると、依頼主から FAX で届く。枚数は依頼の格で決まる（格1・2＝1枚、格3＝2枚、格4＝3枚）。会社の紹介動画（1日目）には来ない。
- 2枚以上のときは、最後の1枚が「当日の差し込み」：現場に着いてから届く。
- 守れたら、ギャラに上乗せ。守れなくても、引かれない（失格にしない）。1場面も撮れていなければ、上乗せは無い。
- 届いた札は、画面の左下の FAX の紙に並ぶ（事務所での準備から、撮影が終わるまで）。
- いっしょに引かない組：「予算半分」と「借り物なし」。逆向きの注文も出さない（「映り込み0.5秒以内」の依頼に「スタッフも出して」）。
- 今までの追加注文（依頼ごとに1つ。一発OK・映り込み0.5秒以内・月を2秒）は、そのまま残してある。

## 決めていない事

- 上乗せの額（100〜200）と、枚数（格4で3枚）。遊んで決める。
- 札を、画面の紙ではなく、事務所の FAX から出てくる紙（物）として見せるか。
- 守れなかったときに、評判を下げる札を混ぜるか（今は、どれも上乗せだけ）。
