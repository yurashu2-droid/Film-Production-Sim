# 最初の一本

起動画面でひとりプレイか、友達の会社への参加を選ぶ。会社を開いた人のIPを同じネットワークの友達へ伝える。最大4人。キャラクターは事務所のCから選べる。

## 準備と役割分担

最初は倉庫の依頼がおすすめ。たとえばバルコニー一式360・台車80・固定用品60の計500コイン。効果機を借りない分、廃材置き場の「爆炎の書割」を運ぶ。購入しなくても、無料の足場・廃板・書割で撮れる。

カメラとカチンコは会社の道具。ライト2台、借りたバルコニーと窓、爆炎の書割を忘れずに軽トラへ。近くで持ったままFを押すと積める。積載一覧を見て、全員が車のそばに集まって出発する。

友達と役割を分けるなら、カメラ担当・セット担当・照明担当・カチンコと合図担当。役割は途中で自由に交代できる。カチンコを取られても誰かが持っていれば撮影できる。Vか中クリックの「ここ！」で置く場所を伝えられる。

## 現場で撮る

到着から10分。バルコニーと窓を城に見える向きへ置き、役者Aの印を高い台の上、役者Bの印を手前の地面へ置く。廃板は城の絵のある面をカメラへ向ける。Bで役者を印へ戻せる。

カメラを置き、Fで操作して構図を合わせる。ライトもFで操作して役者を照らす。右上の撮影映像と黄色い指摘を見ながら調整する。爆炎の書割は二人より奥、カメラに映る場所へ置く。固定用品を借りたならGでセットを固定できる。

カチンコを持ってFで本番。1で告白し、左上の最初の場面が成立してから2で爆発、次の場面が成立してから3で再会の合図。早すぎる爆発やスタッフの映り込みは、NG日誌の思い出になる。Tでカットできる。

## 撮った映画を持ち帰る

結果でRを押すと全員で見返せる。撮り直しはSpace、納品はEnter。期限が来ても撮れたテイクを納品でき、失敗作も150コインになる。納品後に事務所へ帰ると残金で次の仕事を選べる。会社を閉じると現在の財布と撮影は終了する。

Pで見返しながら映画の8コマを保存し、Oで保存フォルダを開く。これは各自のパソコンへ保存する画像なので、面白い一本が撮れたら友達へ渡せる。
