# スロー光線

2026-11-10。ユーザーの案：「単純にカメラでスローにするより、撮影のときにスロー光線を浴びせたらスローになる方が、パーティーゲーム感がある」
「光線自体は映らずに、影響を受けているものや人にエフェクトがぼんやり見える」。
仕組みは `scripts/features/slow_ray.gd`、確認は `tests/slow_ray_test.gd`、動画は `output/preview/slow_ray.mp4`。

## 決まり

- 会社の備品（懐中電灯の形。素材 P016）。持って F で、出す・止める。置いたままでも出続ける（懐中電灯の頭のほうへ）。
- 届くのは 9m、広がりは約10度。出している間は、懐中電灯の頭が光る。

## いまの見た目：「光線の中だけ、空気が水あめになる」（2026-11-10。既定の型 `syrup`）

時計の型・超能力の型を見せたあと、ユーザー：「そのまま超能力のにしてほしいわけではない。どういう表現が適切か、いったん考えてみて」。
考え直した事：前の版は、どれも浴びた物のほうを飾っていた（光の玉＝飾り、時計＝記号、輪郭が沸く＝物をつかむ力）。
スローで特別なのは物ではなく、物が入っている「場」。映画のスローが遅く見えるのは、ふだんの速さを知っている物（土ぼこりなど）がゆっくり動くから。
方針をユーザーに見せて「やってみて」をもらってから作った。

- **場**（制作班だけ）：円すいを通して見える景色が、濃い液体ごしのように、大きくのろくたわむ（細かく震えない・色ずれなし。`slow_warp.gdshader` の pace・grain・chroma）。
  中のほこりは流れず、ほぼ止まって、ゆっくり沈む。床の扇形は、あめ色。
- **入る・出る**：境目を越えた瞬間に、輪郭の形の波紋が1つ立つ（制作班だけ）。物の見た目が、ぷるんと縮んで（出る時は伸びて）揺れながら戻る（0.6秒・1割）。
- **中にいる間**（制作班だけ）：輪郭にまとわりつく、うすいあめ色の膜（沸かない。念力のオーラの部品を、静かな設定で使う）。動くと、後ろへ膜が伸びる（引き波）。
- **着地**：スローの中で着地すると、土ぼこりがゆっくり広がって、2秒あまり舞う（ふつうは0.7秒）。これはフィルムにも映る。
- **音**：光線の中で鳴った音は、高さ 0.55 倍（低く、間延びする）。`scripts/sfx.gd` の `pitch_zone` に、場所ごとの倍率を返す関数を入れてある。
- **浴びた人の画面**（その人だけ）：画面のふちが、あめ色にたわむ。効果音がこもる（低い音だけ通す）。通信の遅れと見分けるため。
- **フィルムに映る物**：物の小さなぷるんと、ゆっくり舞う土ぼこりだけ。膜・波紋・場のゆがみ・ほこり・床の扇形は映らない
  （スロー光線は「安くスローモーションを撮る道具」なので、撮りたい絵に光や波紋を足さない。前の「うすく映る」は取り下げた）。
- 終わり：膜は、懐中電灯に近い側からぬぐわれる。波紋は進み切って細る。場は、根元から先へ消える。ほこりは、沈みながら見えなくなる。
- 見たコマ：出し始め・物が入った時から着地まで（0.07〜0.6秒おき）・止めた後・自分が浴びた時。直しは1回（膜が濃かったので、薄くした）。
- 確かめていない事：音の低さを耳で（動画には入っている）／場のゆがみは、背景が単色の所では見えにくいはず／人には、ぷるんが無い。
- 動画：`output/preview/slow_ray_syrup.mp4`。
- 前の2つの型も残してある（`vfx/slow_ray_style` を `clock`・`psychic` に。起動の引数 `-- --slow-style=…` でも）。要らなければ消す。

## 前の型：時計（`vfx/vfx_slow_field.gd` と `vfx/shaders/slow_*.gdshader`）

ユーザー：「使う時は範囲が見えるとかは？」「スロー中のVFX、もう少しいろいろ考えて凝ってほしい」。
最初の版（うすい紫の光の玉で包む）は、題材と関係のない光る泡だったのでやめた。「時間が遅れる」ことそのものを見せる形にした。
参考：映画の連続写真（1枚に何コマも重ねて写す）・『ビューティフル ジョー』のスロー（残像）・『ベヨネッタ』のウィッチタイム（文字盤）・映写機の光の中のほこり。

浴びている物と人（フィルムにも映る）：
- **時計の目盛りと針**：まわりに、白い目盛りが12本（3本おきに長い。長さと太さは不揃い）。上から時計回りに1本ずつ現れる（0.3秒）。
  濃い紫の針が、0.5秒ごとにカチッと1目盛り進む（12コマ/秒のコマ送り）。光らせない（白い芯＋濃いふち。明るい背景でも暗い背景でも読める）。
- **少し前の姿のコマ（残像）**：物だけ。0.07秒おきに姿を控えて、後ろに4枚まで並べる。紫の網点で、古いコマほど粗い。
  少し小さく描くので、物に重なっている所は隠れ、はみ出した所だけ見える。止まっている物には出ない。
- **浮くほこり**：小さなきらめきが6つ、まわりに浮いて、少しずつ昇る。2〜3秒ごとに別の場所に生まれ直す。

届く範囲（制作班にだけ見える。フィルムには映らない）：
- **うすい円すい**：懐中電灯の頭から先へ。面に、根元から先へゆっくり流れる筋。先へ行くほどまばらになって、端の手前で無くなる。
- **床に映る扇形**：上から見た範囲。両わきは、先へゆっくり送られる破線。内側は、うすい塗りと、先へ進む弧。
- **光の中のほこり**：円すいの中を、根元から先へゆっくり流れ続ける（大きいかけらは遅く、小さいかけらは速く）。
- 持っているだけ（まだ出していない）の間も、円すいと扇形がうすく出る（どこへ向いているかの下見）。ほこりは流れない。

終わり方（部品ごとに別）：
- 目盛り：針が早回りで1周して、通った所から1本ずつぬぐわれる（時間が元に戻る）。0.36秒。
- コマ：新しいコマが足されなくなり、古いほうから1枚ずつ抜けて、物に追いつく。
- ほこり：上へ細く伸びて抜ける。
- 範囲：出どころが止まるので、根元から先へ消える（0.45秒）。中のほこりは、流れ切る。

確かめた事：出し始め・物が入った時・動いている時・止めた後（0.03〜0.2秒おきのコマ）・人が浴びた時、を画像で見た。直したのは3回
（1回目：目盛りが丸い点に見えた・残像が白い網点で物を覆った・範囲が薄い → 2回目：目盛りを細長く、残像を紫に小さく、床の扇形を足した → 3回目：針を時計の針の形に）。
残っている事：人には残像が出ない（骨格のある見た目の写しが要る）。VFX のラボ（`vfx_lab.gd`）と `vfxtest.gd` には未登録（ほかの作業の未コミットの変更があるため）。
- 物（落ちる物・転がる岩・爆風で飛ぶ物・投げた物）：浴びた瞬間に速さが 0.3 倍になり、落ち方も同じ見え方でゆっくりになる（重力を 0.09 倍）。
  光線から出ると、元の速さに戻る。浴びている間に爆風などで急に速くなった分も、ゆっくりにする。
- 人（制作班・雇った役者）：動いた分が 0.3 倍になり、体の動きもゆっくりになる。
- 効かない物：持っている人自身・誰かが持っている物・固定した物。
- 誰が浴びているかは、ホストが決めて全員へ送る。本番中は記録に残り、見返しでも光が出る。

## もう1つの型：超能力・空間のゆがみ（2026-11-10）

ユーザー：「それよりも、超能力っぽい感じとか空間のゆがみとかで表現するパターンも見てみたい」。上の型（時計）と切り替えて比べられるようにした。
切り替え：`project.godot` の `vfx/slow_ray_style` を `psychic` に（無ければ `clock`）。起動の引数 `-- --slow-style=psychic` でも替わる。

- 浴びている物・人：輪郭そのものが膜になって、ゆっくり沸く（念力のオーラ `vfx/esper/esper_aura.gd` の、ゆらぎの型。物は見た目の外形に沿い、人は頭と足をつないだ丸い形）。
  まわりの景色がゆがみ、色が少しずれる。輪郭と同じ形の、所々切れた波紋が、1.15秒ごとに、のろのろ広がる（遅い鼓動）。
  目盛り・残像・ほこりは出さない。
- 届く範囲：円すいを通して見える景色が、ゆっくり波打つ（`shaders/slow_warp.gdshader`。光る筋や粒は出さない）。床の扇形は同じ。
- 出る時：懐中電灯に近い側から、膜が物をなめるように広がる（0.35秒）。
- 終わる時：同じ側から、ぬぐわれるように消える（0.5秒）。波紋は、進み切って細って消える。範囲は、根元から先へ消える。
- 見たコマ：物が入った時・止めた後（0.07〜0.2秒おき）・人が浴びた時。直しは無し（1回目でそのまま）。
- 動画：`output/preview/slow_ray_psychic.mp4`、2つを左右に並べた物が `slow_ray_compare.mp4`（左＝時計、右＝超能力）。
- この型も、そのままは採らない（ユーザー）。既定は、上の「水あめ」の型。

## 起きそうな事（ねらい）

- 狙いがずれて、役者だけ遅くなり、物は普通の速さで来る。
- 仲間やカメラ係が光線に入って、遅くなる。
- 投げた物だけ遅くして、役者がよける（弾をよける場面）。落ちてくる物の下を、歩いて抜ける。

## まだ・決めていない事

- **目盛り・コマ・ほこりは、フィルムにも映る**（私の案。映らないほうがよければ、制作班だけに見える層へ移す）。範囲の円すいと扇形は、映らない。
- 導火線の燃える速さには、まだ効かない。
- キャラの特技「止まれ！」（動く物を2秒止める）との住み分け。
- 光線は、物や壁の裏にも届く（さえぎらない）。
- 借り物にするか、会社の備品のままか。値段。
- これを使う台本・追加注文の札（「どこか1か所、スローで」）は、まだ無い。
- 早送り光線（同じ作りで、倍率を 1 より大きくする）。
