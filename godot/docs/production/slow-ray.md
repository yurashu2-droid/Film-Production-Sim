# スロー光線

2026-11-10。ユーザーの案：「単純にカメラでスローにするより、撮影のときにスロー光線を浴びせたらスローになる方が、パーティーゲーム感がある」
「光線自体は映らずに、影響を受けているものや人にエフェクトがぼんやり見える」。
仕組みは `scripts/features/slow_ray.gd`、確認は `tests/slow_ray_test.gd`、動画は `output/preview/slow_ray.mp4`。

## 決まり

- 会社の備品（懐中電灯の形。素材 P016）。持って F で、出す・止める。置いたままでも出続ける（懐中電灯の頭のほうへ）。
- 届くのは 9m、広がりは約10度。出している間は、懐中電灯の頭が光る。

## いまの見た目：蜃気楼（2026-11-10。既定の型 `mirage`）

ここまでの流れ：光の玉 → 時計の目盛りと針 → 超能力（念力のオーラ）→「水あめの空気」（場を見せる。ただし浴びた物には、念力のオーラの部品を静かな設定で使っていた）。
ユーザー：「超能力の時のエフェクトそのまま使っていない？あれはなくそう。超能力で持ち上げているのかどっちかわかりづらい」
「光の速度も遅くて、歪んで見えるとかぐらいでいい気がしている」「物体の真ん中と外側で追従速度が違うとかにしたら、いい感じにゆがませれないかね」「蜃気楼的な」。

- そのあと：「ほんのり紫の煙か、色を変えるだけか、何かあるといいな」（ゆがみだけだと、手がかりが足りなかった）。
  → 像のゆがみの上に、**ほんのり紫のもや**を足した。色も、あめ色から紫にそろえた（場のふち・床の扇形・浴びた人の画面のふち）。
  動画を見て「いいね」（濃さはこのまま。2026-11-10）。
  - もや：ゆがみと同じ板の中で、全体をうすく紫に染め、その上を、うすい煙の塊がゆっくり昇る（大きい塊は遅く、小さい塊は少し速く）。線・輪郭・光は足さない。
  - 板のふちへ向かって薄くなる。出入りは、像のゆがみと同じ強さ（`gain`）で濃くなり、薄くなる。
  - 濃さは `slow_lens.gdshader` の `amount` の式（全体 0.14・煙 0.46）と、材質の `haze`（0 で、もや無し）・`haze_tint`（色）。
  - 念力のオーラ（輪郭の膜・波紋。橙など持つ人の色）とは、形も色も別（輪郭をなぞらない、ふちの無いもや）。
- **浴びた物・人**：線や輪郭は足さない。その物の「像」をゆがめ、ほんのり紫のもやを重ねる（カメラを向く板で、画面の絵をずらして描き直す。`shaders/slow_lens.gdshader`）。
  - 真ん中の像は遅れない。外側の像は、ばねで遅れて追う（行きすぎて、揺れて、追いつく）。動いている間は、外側が後ろへ引きずられて見える。
  - 入った瞬間は、外側の像が、前の速さのまま少し行きすぎてから戻る。
  - 止まっている間も、横に長い帯ごとに、像が左右にゆっくりゆれる（蜃気楼）。
  - 強さは `vfx_slow_field.gd` の `LENS_SPRING`（追う速さ）・`LENS_DAMP`（揺れの収まり）・`LENS_KICK`（入った瞬間の行きすぎ）・`LENS_REACH`（遅れる長さの上限）。
- **場**：円すいを通して見える景色が、ゆっくりたわみ、横に長い帯ごとに上下に伸び縮みする（`slow_warp.gdshader`）。中のほこりは、ほぼ止まって、ゆっくり沈む。床の扇形。
- **着地**：スローの中で着地すると、土ぼこりがゆっくり広がって、2秒あまり舞う。
- **音**：光線の中で鳴った音は、高さ 0.55 倍（`scripts/sfx.gd` の `pitch_zone`）。
- **浴びた人の画面**（その人だけ）：画面のふちがたわみ、効果音がこもる。
- **フィルムに映る物**：ゆっくり舞う土ぼこりだけ。像のゆがみ・紫のもや・場のゆがみ・ほこり・床の扇形は、制作班にだけ見える。
- 終わり：像のゆがみは、ばねの揺れのまま収まっていく（像が本当の場所に追いつく。0.5秒）。場は、根元から先へ消える。
- 外した物：念力のオーラ（輪郭の膜・輪郭の形の波紋）・超能力の型・床の波紋・物の大きさを変える「ぷるん」（像の遅れの揺れが、その代わり）。
- 見たコマ：入った瞬間から着地まで（0.03〜0.4秒おき）・横へ動かした時・止めた後・自分が浴びた時。直しは2回（ゆがむ範囲を物のまわりに絞った・遅れの長さを控えめにした）。
- もやで見たコマ：物が入った瞬間・落ちている間・着地の土ぼこりと重なった時・止めた後・人が浴びた時（拡大して）。直しは1回（最初の濃さでは、拡大しても見えなかったので、約2倍に）。
- 確かめていない事：通常の速さで見た時の強さ（静止画では、箱がかなり崩れて見えるコマがあった）／音を耳で／背景が単色の所での見え方／もやの濃さが「ほんのり」に合っているか（暗い背景・紫に近い色の物の上では、見えにくいはず）。
- 動画：`output/preview/slow_ray_mirage.mp4`。
- 時計の型は残してある（`vfx/slow_ray_style` を `clock` に。起動の引数 `-- --slow-style=clock` でも）。要らなければ消す。

## 前の型：時計（`vfx/vfx_slow_field.gd` と `vfx/shaders/slow_*.gdshader`）

ユーザー：「使う時は範囲が見えるとかは？」「スロー中のVFX、もう少しいろいろ考えて凝ってほしい」。
最初の版（うすい紫の光の玉で包む）は、題材と関係のない光る泡だったのでやめた。「時間が遅れる」ことそのものを見せる形にした。
参考：映画の連続写真（1枚に何コマも重ねて写す）・『ビューティフル ジョー』のスロー（残像）・『ベヨネッタ』のウィッチタイム（文字盤）・映写機の光の中のほこり。

浴びている物と人（フィルムにも映る）：
- **時計の目盛りと針**：まわりに、白い目盛りが12本（3本おきに長い。長さと太さは不揃い）。上から時計回りに1本ずつ現れる（0.3秒）。
  濃い紫の針が、0.5秒ごとにカチッと1目盛り進む（12コマ/秒のコマ送り）。光らせない（白い芯＋濃いふち。明るい背景でも暗い背景でも読める）。
- **少し前の姿のコマ（残像）**：物だけ。0.07秒おきに姿を控えて、後ろに4枚まで並べる。紫の網点で、古いコマほど粗い。
  少し小さく描くので、物に重なっている所は隠れ、はみ出した所だけ見える。止まっている物には出ない。
- **浮くほこり**：小さなきらめきが6つ、まわりに浮いて、少しずつ昇る。2〜3秒ごとに別の場所に生まれ直す。

届く範囲（制作班にだけ見える。フィルムには映らない）：
- **うすい円すい**：懐中電灯の頭から先へ。面に、根元から先へゆっくり流れる筋。先へ行くほどまばらになって、端の手前で無くなる。
- **床に映る扇形**：上から見た範囲。両わきは、先へゆっくり送られる破線。内側は、うすい塗りと、先へ進む弧。
- **光の中のほこり**：円すいの中を、根元から先へゆっくり流れ続ける（大きいかけらは遅く、小さいかけらは速く）。
- 持っているだけ（まだ出していない）の間も、円すいと扇形がうすく出る（どこへ向いているかの下見）。ほこりは流れない。

終わり方（部品ごとに別）：
- 目盛り：針が早回りで1周して、通った所から1本ずつぬぐわれる（時間が元に戻る）。0.36秒。
- コマ：新しいコマが足されなくなり、古いほうから1枚ずつ抜けて、物に追いつく。
- ほこり：上へ細く伸びて抜ける。
- 範囲：出どころが止まるので、根元から先へ消える（0.45秒）。中のほこりは、流れ切る。

確かめた事：出し始め・物が入った時・動いている時・止めた後（0.03〜0.2秒おきのコマ）・人が浴びた時、を画像で見た。直したのは3回
（1回目：目盛りが丸い点に見えた・残像が白い網点で物を覆った・範囲が薄い → 2回目：目盛りを細長く、残像を紫に小さく、床の扇形を足した → 3回目：針を時計の針の形に）。
残っている事：人には残像が出ない（骨格のある見た目の写しが要る）。VFX のラボ（`vfx_lab.gd`）と `vfxtest.gd` には未登録（ほかの作業の未コミットの変更があるため）。
- 物（落ちる物・転がる岩・爆風で飛ぶ物・投げた物）：浴びた瞬間に速さが 0.3 倍になり、落ち方も同じ見え方でゆっくりになる（重力を 0.09 倍）。
  光線から出ると、元の速さに戻る。浴びている間に爆風などで急に速くなった分も、ゆっくりにする。
- 人（制作班・雇った役者）：動いた分が 0.3 倍になり、体の動きもゆっくりになる。
- 効かない物：持っている人自身・誰かが持っている物・固定した物。
- 誰が浴びているかは、ホストが決めて全員へ送る。本番中は記録に残り、見返しでも光が出る。

## 起きそうな事（ねらい）

- 狙いがずれて、役者だけ遅くなり、物は普通の速さで来る。
- 仲間やカメラ係が光線に入って、遅くなる。
- 投げた物だけ遅くして、役者がよける（弾をよける場面）。落ちてくる物の下を、歩いて抜ける。

## まだ・決めていない事

- **目盛り・コマ・ほこりは、フィルムにも映る**（私の案。映らないほうがよければ、制作班だけに見える層へ移す）。範囲の円すいと扇形は、映らない。
- 導火線の燃える速さには、まだ効かない。
- キャラの特技「止まれ！」（動く物を2秒止める）との住み分け。
- 光線は、物や壁の裏にも届く（さえぎらない）。
- 借り物にするか、会社の備品のままか。値段。
- これを使う台本・追加注文の札（「どこか1か所、スローで」）は、まだ無い。
- 早送り光線（同じ作りで、倍率を 1 より大きくする）。
