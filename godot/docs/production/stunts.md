# スタント

2026-11-10。ユーザーの希望：「アクション映画要素を出したい。スタント的なのが入ってくると一気に難易度の高い依頼にもなって、
レベルアップして撮影はしやすいが、撮影難易度自体は上がるような構造にできる」。
これまでは、高い所から落ちても、爆風で吹き飛んでも、何も起きなかった（だから飛び降りるだけなら誰でもできて、スタントにならなかった）。

仕組みは `scripts/features/stunts.gd`、確認は `tests/stunts_test.gd`・`tests/stunt_shots_test.gd`、
動画は `output/preview/stunt_base.mp4`（土台）・`output/preview/stunt_shots.mp4`（雇った役者・役に入った人の飛び降り）。

## 土台の決まり（できている）

- **強くぶつかると、のびる**。床でも壁でも、速さ 9.5 m/秒 以上（落ちる高さで、およそ 2.8m から）。
  - 跳ぶだけ（1m）・低い段差・走って壁に当たる（5.8 m/秒）では、何も起きない。
  - 見た目は漫画の理屈：ぺちゃんこになる（床なら床に広がる。壁なら、壁に背中を付けてうすく貼りつく）。土ぼこり。頭の上を星が3つ回る。
    数秒で、ぽんと元に戻る。けがはしない。体力の数字は無い。雇った役者が大岩につぶされる形（`actor.gd`）と同じ。
  - のびる時間：2.4秒〜5秒（強くぶつかるほど長い）。
  - のびている間：歩けない・跳べない・物を持てない（持っていた物は落とす）。見回すことはできる。
- **やわらかい物が受け止める**。体のそば（足元から頭までの、どこかから 0.3m 以内）にある分を足して、ぶつかった速さから引く。
  残りが 9.5 より小さければ、のびない。足りなければ、のびる（箱が足りない・ずれている）。

  | 物 | 受け止められる速さ |
  |---|---|
  | 段ボール箱 | 3.0 |
  | ゴミ袋 | 3.5 |
  | ブルーシートの包み・一人がけの肘掛け椅子 | 5.0 |
  | 二人がけのソファ | 6.5 |
  | ベッド・病院のベッド | 7.5 |

  | 落ちる高さ | ぶつかる速さ | 要る物（例） |
  |---|---|---|
  | 2.8m まで | 9.5 まで | 何も要らない |
  | 5m | 12.6 | 段ボール箱2つ（ゴミ袋なら1つ） |
  | 7m | 15.0 | 段ボール箱2つ |
  | 9m | 17.0 | 段ボール箱3つ（ソファと箱1つでも） |
  | 12m | 19.6 | 段ボール箱4つ |

  - 受け止めた物は、はじかれて散らばる（積み直すのが、裏方の仕事）。ぽよんと揺れる。人は少しはずむ。
  - 自分で持っている物は数えない。ほかの人が持っている箱は数える（箱を持って、落ちてくる仲間を受け止められる）。
- **爆風**：火薬を多くすると、高く・速く飛ばされるので、落ちた所・ぶつかった壁で、のびる（入れすぎの失敗）。
- **スロー光線**：浴びている人は、ゆっくり降りるので、弱くぶつかる（速さを 0.3 倍で数える。5m から降りても平気）。
- 準備中も本番中も同じ。本番中は記録に残り、見返しにも載る。失格にはしない。
- **フィルムに映る物**：ぺちゃんこの体・土ぼこり。星は、制作班にだけ見える。
- はじめの2回だけ、「強くぶつかって、のびた。段ボール箱など、やわらかい物が受け止めてくれる」と知らせる。

## スタントを撮る（できている。2026-11-10 夜）

「体を張った場面」を、ギャラと追加注文の札につないだ。どの台本でも使える（台本に書いていなくても、入れれば上乗せ）。

- **決まったスタント**：本番中に、役者（役に入った人・雇った役者）が
  ① 飛んでいる・落ちている所が撮影カメラに映り（ぶつかる前の 2.5 秒のうち、速く動いている所が 0.1 秒）、
  ② 強くぶつかって（のびる速さ以上）、③ のびずに済んだ（やわらかい物・受け身）。
  - 上乗せ：120（のびる速さちょうど）〜 300。1 m/秒 強いごとに +20。5m で 180、7m で 230、10m で 300。
  - 種類は2つ：「飛び降り」と「吹っ飛び」（爆風で飛ばされてから4秒のうちの着地）。1テイクにつき、種類ごとに、いちばん強い1回だけ数える。
  - **受け止める物が映らなかった**：+60（着地を画面の外にする・物の陰にする。画面の外に積むのが、裏方の仕事）。
- **のびた姿が映った**：−40（1テイクに1回まで）。失格にはしない。精算の文には「-40 コイン」と出る。
- 数えない物：準備中／フィルムを止めている間／役に入っていない人（映れば、今までどおり「映り込み」）／等身大パネル／
  スロー光線でゆっくり降りたとき（ぶつかっていないので。安全だが、スタントの上乗せは付かない）。
- 1場面も撮れていないテイクには、上乗せも引く分も付かない。
- **試写会**：決まったスタントで、依頼主が「おおっ、体を張ってる！」。のびた姿で「……いまの人、大丈夫？」。
- **追加注文の札「どこかで1回、体を張って」**（+200。格2の依頼から出る）：決まったスタントが1つあれば、守れる（`order-cards.md`）。

### 受け身（演者の腕）

- 制作班スキルの「演者」が1つ上がるごとに、のびずに済む速さが 0.8 m/秒 上がる。
  腕1＝9.5（2.8m）／腕2＝10.3（3.3m）／腕3＝11.1（3.9m）／腕4＝11.9（4.4m）／腕5＝12.7（5.0m）。
- 箱が無くても受け身で済んだ着地は、スタントに数える（受け止める物が無いので、「映らなかった」の +60 も付く）。

### 雇った役者

- 雇った役者も、同じ決まりで、のびる・受け止められる（爆風で高く飛ばされて、硬い所に落ちたとき）。
  のびている間は芝居が止まるので、場面が撮れなくなる。火薬の入れすぎの失敗が、役者にも効く。
- ベテランは受け身がうまい（のびずに済む速さ 11.1。新人は 9.5 のまま）。
- 見た目は、大岩につぶされた時と同じ（ぺちゃんこ）＋頭の上の星。数秒で、ぽんと戻って、続きを演じる。
- 雇った役者を爆風で飛ばして、箱で受ける、も「決まったスタント」に数える。

## 作り

- ぶつかった強さは、自分の画面で測る（`player.gd` の `impact`：動く前の速さのうち、当たった面へ向かっていた分。
  着地のときは、落ちてきた速さ。箱の角に降りても、弱く数えない）。
- 雇った役者は、ホストが測る（`stunts.gd` の `_watch_actors`：前のコマの速さと、当たった面）。
- スタントの記録は、ホストが、ぶつかった瞬間に控える（`shots`）。カットのときに、テイクごとに写す。
- しきい値を超えたら、ホストへ頼む（`h_impact`）。ホストが、そばのやわらかい物を数えて、のびるか・受け止めたかを決め、全員へ知らせる
  （`stunt_down`・`stunt_soft`）。箱をはじくのも、ホスト。
- 星は `vfx/vfx_dizzy_stars.gd`（紙の切り抜きの星。12コマ/秒。頭から飛び出して輪に乗る → 回る → 起き上がる時に、そのときの向きへ飛んで床に落ちる）。

## 見たコマ（`output/preview/stunt_base.mp4`）

- 爆風で飛ばされて、硬い床へ：着地の瞬間から戻るまで（0.07秒おき）。ぺちゃんこ・土ぼこり・星の出入りを拡大して見た。
- 同じ爆風で、箱を3つ置いた所へ：箱の上に落ちて、のびない。箱が散らばる。
- コンテナのすぐ前で、多めの火薬：壁に貼りつく・星・戻る。
- 直し：星が小さくて点に見えたので、1.3 倍にした。

- 2026-11-10 夜（`output/preview/stunt_shots.mp4`）：雇った役者2人の足もとで爆発。硬い床に落ちた方は、ぺちゃんこ・星・戻る。
  箱のそばに落ちた方は、のびない。役に入った人（たすき）が、箱の上へ 6m から飛び降りる。拡大して見た。

## 確かめていない事

- 人が撮ったときに、「飛んでいる所が映った」の判定が、甘すぎないか・厳しすぎないか（自動確認では、置いたカメラの前で落としただけ）。
- 上乗せの額（120〜300・+60・−40）が、ほかの上乗せ（札 100〜200・コンボ）と釣り合うか。
- 二人で遊んだ時の、スタントの記録（相手が飛び降りたとき。相手の場所は、ホストの画面では少し遅れて届く）。

- 人が遊んだ時の、高さの感じ（2.8m が低すぎないか・高すぎないか）・のびる時間の長さ。
- 二人で遊んだ時（相手の画面での見え方・相手が持っている箱で受け止める）。
- 音を耳で（既にある「thump」「land」「drop」「bump」を重ねただけ）。
- 一人称の視点で、のびた時の見え方（視点は下がらない）。
