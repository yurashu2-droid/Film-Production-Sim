# 貧乏映画制作の一周

目的: 友達と笑いながら物理小道具で映画を撮る。会社の貧乏さが制約と代用の楽しさを生む。

事務所 → 依頼選択 → 600コインまでの道具選び → 廃材置き場・荷積み → 全員が軽トラ付近で出発 → 8秒の道中 → 現場の10分レンタル → 3テイクの撮影・確認・納品 → 売上を持って事務所へ。

現場: 最初は倉庫。続いてDownloadsの室内スタジオ部品と野外会場を既存の撮影条件へ組み合わせる。脚本は現時点では『告白・背後の爆発・再会』を共通とし、現場と作り方に差を付ける。

荷積み: カメラとカチンコは会社の基本道具。購入物は費用を払い、廃材は無料。トラックに載せたもの、乗員が持っている物だけ現場へ運ぶ。置き忘れは出発前の一覧で分かる。必須機材がなければ出発を止める。

制約: レンタルは到着から600秒。仕込み・本番・確認中に進む。残り時間を常に表示し、120/60/30秒で知らせる。時間切れは本番をカットし、撮れたテイクから納品可能。何も撮れていない場合は空の失敗テイクを用意しソフトロックを防ぐ。

経済: 会社資金600から購入額を支払う。購入限度はmin(600,会社資金)。失敗作でも納品料150、条件達成ごと250、全条件達成なら300の追加報酬 (計1200)。借金を強制せず、無料の廃材で再挑戦できる。保存機能は今回範囲外。

笑い: 物理で崩れるセット・怪しい代用品・荷積み相談・カチンコの奪い合い・撮り直し・出来の悪い映像を一緒に見返す。操作妨害の罰や突然の無理な失敗は増やさない。

追加注文: 倉庫で一発OK、室内でスタッフ映り込み0.5秒以内、野外で月を2秒映す。基本3条件と併せて成立すると150追加。選んだ納品テイクの実測で精算し、NG日誌に映り込みと早すぎた爆発を残す。
