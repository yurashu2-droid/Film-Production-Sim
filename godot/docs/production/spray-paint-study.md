# スプレー缶の見え方（作る前の調べ物と設計）

2026-10-18。看板づくり（`features/spray_sign.gd`）のスプレーが「スプレーっぽくない」と言われたので、本物の吹き付け塗装と、ゲームでの表し方を調べてから作り直す。

## 調べたこと

- 距離で線の太さが変わる。近いほど細く濃い線、離すほど太く柔らかい線（Montana のノズルの説明：Standard Cap 約1.2cm、Skinny Cap 約1cm で柔らかい）。
- 近くで吹きすぎると、塗料が溜まって下へ垂れる（キャップの販売店の注意書き）。
- 縁は柔らかく、周りに細かい粒（オーバースプレー）が散る。重ねて吹くほど濃くなる。
- ゲームの例（GTA V の落書き MOD）：素早く動かしても点が飛び飛びにならないよう、点と点の間を埋める。広がりは「手（缶の口）から面まで」の距離で決める（体の根元から測ると、近い所が太すぎた）。
- 数値（距離・角度・飛び散りの割合）は、元の資料で確かめられなかったので使わない。見て合わせる。

## 設計（VFX の手順書 PLAYBOOK の2章の形）

```
素材：        霧状の塗料（液体の細かい粒）。缶の色（黒・赤）
どこから来る： 手に持った缶の口（ノズル）から、狙った所へ円すい形に吹き出す
先に動く部分： 霧の先端（板に当たる所）。当たった粒が板の絵になる
遅れて追う部分：当たり損ねた細かい霧（宙に漂って、ゆっくり広がりながら下へ沈む）
形の変化：     0.0秒 口から細い筋で出る → 0.1秒 円すいに開いて板に届く（近いと細い・遠いと太い）
               → 0.3秒 板の手前でふわっと広がる → 0.6秒以降 漂う霧が下へ沈みながら薄く広がる
終わり：       霧の粒：板に当たった物は止まって「跡」になる（絵へ移る）
               漂う霧：広がりながら下へ沈み、地面の手前で薄く散る（縮んで消えない）
               板の跡：残る。溜まりすぎた所は、下へ垂れ（ドリップ）が伸びて、先に小さな玉ができて止まる
```

## 板の跡の描き方

- 1回の吹き（点）＝ガウス分布でばらまく細かい粒の集まり。真ん中は詰まって濃く、外は粒がまばら（柔らかい縁と飛び散りが、同じ仕組みで出る）。
- 広がり（粒をまく半径）：缶の口から板までの距離で決める。近い（0.2m）＝細く濃い、遠い（1.5m 以上）＝太く薄い。
- 点と点の間は、広がりの3割ごとに埋める（素早く動かしても線になる）。
- 同じ所に溜まると、垂れが出る（板を粗い升目に分けて、溜まった量を数える）。
- 粒のまき方は、ホストが決めた種（seed）で全員の画面が同じに描く（絵がずれない）。
