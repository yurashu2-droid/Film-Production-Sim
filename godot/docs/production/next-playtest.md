# 次の友達プレイで確かめたいこと

2026-10-15 の版。1日目は「会社のCM」から始まり、カット割り（場面ごとにフィルムを止めて場転）と、
納品前の試写会、危ない撮り方が報われる「見ごたえ」が入った。自動確認は配置や合図を代わりに行っているので、
通った確認だけで初見の楽しさまで確かめたとは扱わない。下の観察は、人が遊んで確かめる。

## 1日目の流れ（新しい）

1. 事務所の依頼ボードに来ているのは「わが社のCM（深夜枠・30秒）」だけ。依頼主はテレビ局のランプ部長。
2. 制作費は 300。爆弾（360）は借りられないので、2カット目は廃材置き場の「爆炎の書割」で撮る想定（爆弾を使ってもいい）。
3. 撮るのは会社の前（事務所の正面。店構えと「格安映画制作会社」の看板が背景になる）。軽トラで出発せず、積み込み確認の「ここで撮影を始める」で本番の準備に入る。突風は吹かない。廃材置き場も機材置き場もすぐそば。
4. 3カット：城に見立てた物の前の二人 → 二人の背後で爆発 → 寄りで決めポーズ。
   場面が撮れるとフィルムが止まる（場転）。止まっている間に次の場面を用意して、台本を読める人が 1 で回す。
5. 「このテイクを納品」で放送（試写会）。全員が事務所の奥のスクリーンの前に集まり、見ている間も歩ける（カメラはスクリーンの方に固定）。
   「このあとは コマーシャル」の札 → 映画（場面の見出し・依頼主の反応。点数は出ない）→「提供」の札 →
   フィルムが右から左へ流れ、窓を通ったコマの下に良かった点・だめだった点が出る → 合計。全部の場面が撮れていれば拍手（仮の合成音）。
6. ランプ部長は「会社の名前も、どこかに映っているといいですね」とだけ言う。カンペや等身大パネルに描いて、表をカメラへ向けて1秒以上映すと +100。
7. 帰社すると、机の黒電話が鳴って震える（CMを見た人からの電話）。2日目からは、CM以外の依頼が全部来る。

## 2日目以降の新しい依頼

- 「怪獣ドラマ 第1話」（カット割り 5）：完全版（長回し 5）と同じ5場面を、場面ごとに止めて撮る。
- 「旅する二人」（カット割り 4）：城の門 → 月夜の丘 → 爆発 → 寄り。丘の場面に城が映っていると撮れない（場所が変わったように見えない）。
  場転で、城を片づける・月の役の物を出す・書割を立てる・カメラを寄せる・ライトを向け直す。

## 観察すること（優先順）

1. **最初の一本で、何をすればいいか分かるか。** 打ち合わせの絵コンテと台本のメモだけで、
   アーチなどを城の役にする（物を見て Y）・書割を奥に立てる・ライトを向け直す、に気づけるか。
   つまずいた所（何秒迷ったか・何を聞いたか）を書き留める。答えを画面に出しすぎない方針は守る。
2. **場転が「慌ただしい楽しさ」になっているか。** 止まっている間に、誰が何をしているか。
   全員が動いているか、一人が全部やって残りが待っていないか。止まっている時間の長さ。
3. **試写会で笑いが起きるか。** 失敗したテイクでも見返したくなるか。とばされていないか（Enter・Esc）。
   依頼主の反応（驚く・首をかしげる）が、映像の出来事と合っているか。顔とひとことから、点数を予想しているか。
   見ている間に歩き回るか（スクリーンの前に立って邪魔をする・跳ぶ）。フィルムの採点で、どのコマで点が入ったか分かるか。速さは合っているか。
4. **見ごたえが、危ない撮り方を誘うか。** 「画面いっぱいの爆発 +80」「間一髪 +60」を狙って、
   カメラを寄せる・役者の近くで爆ぜさせる、を試すか。狙いすぎて場面が撮れなくなるなら、上乗せの額を見直す。
5. **長回し（完全版）とカット割り（怪獣ドラマ）の違いが、遊んで分かるか。** 2日目以降に両方を遊んで、どちらが楽しいか。
6. **「場所が変わる」が、片づけの仕事として楽しいか。** 旅する二人で、城を片づける・月を出す作業が、慌ただしさになっているか、面倒なだけか。
7. **手描きの看板で遊ぶか。** CMで会社の名前を描いてみる人がいるか。描いた絵が試写会で笑いになるか。

## 役者は自分たちで、仕掛けは自由に（2026-10-16 から）

- **役に入る（兼任）。** 準備中に、何も持たず何も見ずに Y で、自分が役者 A → B → やめる。等身大パネルを見て Y でも、パネルが役者になる。
  役に入った人には役の色のたすきが掛かり、印に着いたか・歩いているかは、その人の動きで数える（映り込みには数えない）。
- **役者を雇う。** 誰も入らない役は、電話の発注で雇った役者が演じる：ベテラン（150。確実）／劇団の新人（50。出遅れる・通り過ぎる・転ぶ・せりふで固まる）。
  雇わなければ、その役は空のまま（自分たちで演じれば、タダ）。
- **仕掛けの部品（会社の備品。はさみの隣）**：滑車2・押しボタン（呼び鈴）2・点火トーチ2・目覚まし時計1。
  - ロープの束を持って、物・壁・柱を見て F で端を結ぶ → もう一方を見て F で張る。途中で滑車を見て F なら、滑車に掛かる。
  - 手ぶらで、張ったロープを見て F で火を付けると、少しして焼き切れる。燃えている導火線・燃えているロープ・トーチの炎・爆発でも切れる。
  - 滑車は、持って壁や物を見て F で留める。押しボタンは、物が載る・落ちる・人が踏む・F で鳴り、ケーブルでつないだトーチ（炎）や爆弾が動く。
  - 目覚まし時計は、手ぶらで F を押すたびにねじを巻く（1回5秒・赤い針が残りを指す）。鳴ると、ボタンと同じくケーブルの先が動く（役を演じながら仕掛けを動かせる）。
  - 試写会：撮影中に班の誰かが映り込むと、その瞬間に依頼主が気づき、フィルムの採点ではそのコマに「〜秒出演」の行が付く。
  - 例：「火を付ける → 重りがボタンに落ちる → トーチの炎で支えが焼き切れる → 重りが落ちて、滑車のロープがカメラを載せた台車を引く」。
- **新しい依頼「転がる大岩・予告編」**（2日目から。ベレー帽先生。倉庫。4カットのカット割り。冒険映画の有名な冒頭のパロディ）：
  忍び足の二人を、動くカメラで追う（0.8m以上）→ 秘宝をすり替えると、上から物が落ちる（1m以上）→ 転がる大岩に追われて逃げる → 寄りで決め。
  大岩は、逃げる二人の「後ろ」から転がって迫ること（前を転がってもだめ）。張りぼての大岩（直径1.7m・7kg）は電話で借りられる（120）。
  押す人・落とす人が映るとだめ。二人とも役に入ると手が空かないので、仕掛けに任せるか、役者を雇うか、を選ぶ。
- 観察すること：
  1. 裏方と役者を掛け持ちして、慌ただしくて楽しいか（間に合わない・映り込む、の笑いが出るか）。新人を雇ったときのハプニングが笑えるか、腹が立つだけか。
  2. 仕掛けを考えるのが、準備の楽しみになるか。教えなくても、ロープ・滑車・ボタンをつないでみるか。火が隣のロープに移る（思った通りに動かない）のが、笑いになるか。
  3. 1人で遊ぶとき、役者代を払う余裕があるか（1人用にお金を多くするか、まだ決めていない）。

- **夜用フィルター**（青いゲル。仕掛けの道具の隣）：持って撮影カメラを見て F で付ける・外す。付けたカメラの映像だけが、青く暗い夜になる
  （映画の擬似夜景。目で見ている現場は昼のまま）。月夜の場面（月夜の自転車・月夜の城）を夜らしく撮るのに使う。見返し・試写会でも夜に映る。
- **背景フィルム缶**（城・宇宙・海。夜用フィルターの隣）：持って撮影カメラを見て F で入れる（同じ缶でもう一度 F で外す。別の缶なら入れ替え）。
  そのカメラは、映像の**緑の所**を缶の背景に置き換えて写す（グリーンバックの合成）。グリーンバックの布の前で撮ると、背景が城・宇宙・海になる。
  緑の濃い物も透ける（本物の合成の事故と同じ）。いまは見た目だけで、採点には数えない。見てほしい所：布を置く手間に見合う面白さか・背景の絵はこれで読めるか。
- **送風機**（廃材置き場の大型送風機）が装置になった：手ぶらで F で回す・止める。押しボタン・目覚まし時計とケーブルでつなぐと、鳴ったときに12秒回る。正面の軽い物を押し、風の筋が見える。
- 依頼主が用意する物（送風機・バスの正面）は、その日の廃材置き場にしまってあっても、依頼を受けると出てくる（`features/job_props.gd`）。
- 雇った役者（NPC）は、上の印へ向かう途中なら、0.65m までの段（箱・台・階段）に跳び乗る（平らな道の障害物では、今までどおり立ち止まる）。
  1m の頂上へは、0.5m の段を1つはさめば上れる（確かめ済み）。月の前を横切る場面は、月が遠いと小さく高く映って重ならない（カメラを低く・月を役者のすぐ後ろへ）。
