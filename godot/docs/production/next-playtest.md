# 次の友達プレイで確かめたいこと

2026-10-08の版は「受注・代用品を探す・積む・10分で撮る・見返す・納品・帰社」を一周できる段階。自動確認の配置や合図は制作班の判断を代わりに行っているため、四人の通信成功だけで初見の楽しさまで確認できたとは扱わない。

## 現在の遊びの核

手元の物を映画の中で別の物に見せる。無料の廃板と足場が城になり、小さな怪獣を手前へ置けば巨大に見える。竜の口や昇降台は担当者がFで動かせる。カメラ担当とセット担当が相談する理由を、予算と構図が作る。

物理事故は本番にも残る。セット崩れ・スタッフの映り込み・早すぎた爆発を、その場の失敗だけで終わらせず、一緒の見返し・NG日誌・8コマ画像へつなぐ。失敗作も150コインになり、残金0でも無料廃材で再出発できる。

焦りは現場の10分と3テイクに集めた。倉庫の一発OK、室内の映り込み、野外の月は追加報酬なので、難しい注文に失敗しても本編の報酬を失わない。役割を固定せず、全員が持つ・置く・撮る・カチンコを取る操作に参加できる。

## 優先順

1. **初見の設営を観察する。** 四人が説明だけでカメラ・ライト・役者の印・爆炎書割を使えるか。特に「高い足場の上へ役者の印を置く」と「二人の奥へ爆発を置く」のつまずきを記録する。困っている箇所へ実測した案内を足す。
2. **全員に出番があるか。** 一人がカメラと合図を抱え、残り三人が待つ状態になっていないか。手伝っている人の自然な失敗や工夫が、映像と見返しで笑いになるか。強制的な妨害・罰の追加より、触れる小道具と撮り方で出番を増やす。
3. **同じ脚本の三現場の差を見る。** 現在は場所と追加注文の差。続けて二本遊びたくなる差が足りなければ、次の機能単位を新しい短い脚本にする。怪獣映画の手前/奥の配置や、室内の小さな出来事から検討する。
4. **10分と売上を調整する。** 説明が分からず時間を失うストレスと、間に合うように協力する焦りを分ける。初見の準備時間・最初の成立までの時間・待ち時間・撮り直し回数を見てから制限を変える。

インターネット越しの参加、会社資金の永続保存、物理運転は現在の版には含まれない。次の遊びの観察結果と分けて、必要になった機能単位で設計する。
