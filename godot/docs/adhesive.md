# 重りと接着剤

荷台の荷物は、床との衝突・摩擦・重力で載る。Gによる固定は廃止。

- 重り：レンタルのサンドバッグ3個。各12kg。軽い物の足元や上へ置くか、接着して支える。固定数や積載容量のボーナスはない。
- 接着剤：会社にあるスプレー接着剤を持ち、Fで塗る操作へ。物同士の接触付近を狙うと、18cm以内の相手を探す。相手が1つで12cm以内なら、水色の2点と線、相手の名前が出る。左クリックで表示した2点を接着する。近くに置いただけでは接着しない。
- 相手が複数ある場合は、橙色の点と「相手が複数」の案内を表示する。左クリックで1点目を付け、次に接着したい別の物を狙ってクリックする。その相手の近い表面へ2点目を合わせる。壁越し、不在の物、操作中の機材は候補にしない。
- 近接候補がない場合も、照準を物の表面へ合わせ、左クリックで1点目、別の物に左クリックで2点目を付ける従来の操作を使える。18cmは候補の探索範囲で、接着する距離は12cmのまま。
- 黄色い点は接着待ち。Fで塗る操作を終了し、接着剤を置き、物を動かして2点を近づける。12cm以内で点同士が接着し、緑色になる。
- 右クリックは、まだ組になっていない1点目を取り消す。
- 同じ2点への連打で接着は増えない（4cm以内は同じ点として扱う）。別の位置へは何点でも留められる。
- 接着状態は参加者・途中参加・撮り直しへ同期する。次の依頼では初期配置へ戻して接着を消す。

モデルの出典は `assets/props/ADHESIVE_MODEL.md`。

## 接着した点は「支点」

留めた点では2つの物が離れない。けれど、その点のまわりには自由に回る。点以外の所は、くっついていないのと同じで、ふつうにぶつかるだけ。接着した時の向きへ戻そうとする力は無い。

| 留め方 | 動き |
|---|---|
| 1点だけ | 点を支点に、ぶら下がる・倒れる・回る |
| 離れた2点 | 2点を結ぶ線を軸にした蝶番。その線のまわりにだけ回る |
| 一直線でない3点 | ほぼ固まる |
| 一直線に並べた3点 | 蝶番のまま（線のまわりに回る） |

- 離れた所を留めるほど、しっかりする。すぐ近くにまとめて打った3点は、重さで垂れる（1辺60cmの箱を横へ突き出して3点で留めたとき、点の間隔が約2cmなら約16度垂れ、約10cmで0.4度、約20cm以上でほぼ垂れない）。「1点だとぶらぶらする。だからもう1点、離して留める」という工夫が狙い。
- 留めた物どうしも、点以外の所ではぶつかる。面と面がぴったり付いていれば、その当たりも支えになる（箱の横の面に板を当てて角を1点留めると、板は面に沿って時計の針のように回り、ぶら下がる。面と面を付けた箱どうしは、面のまん中の1点でも、面がつっかえて垂れない）。
- 回り続けて止まらないのを防ぐため、留めた2つの物が互いに回る勢いは、少しずつ弱まる。ぶら下げた物は数回揺れて、3〜4秒で落ち着く。重さによらず同じ速さで落ち着く。
- 接着した物も重力を受け、持って動かせる。車体に接着すれば車体から離れず、重りに接着すればその重さで支えられる。荷台の荷物も、1点だけでは向きが変わる。走っても動かしたくない物は、離れた3点で留める。
- 選んだ2点が少し離れていても（12cm以内）、物を置き直さない。物理が点どうしを寄せる。

画面つきの確認は `tests/adhesive_shot.gd`（画像は `tests/shots/adhesive/`）。

## 持って運ぶとき

持つ処理（`prop.gd`）が手でいっしょに動かすのは、持った物と「固く留まっている仲間」だけ。固く＝同じ2つの物を、一直線でない3点以上で留めてある（3点目が、いちばん離れた2点を結ぶ線から5cm以上外れている）。

- 固く留めた相手：持った物といっしょに動く。重さも手が支える（`tests/shots/adhesive/06_carried_rigid.png`）。
- 点で留めただけの相手（1点・2点・一直線の3点・すぐ近くにまとめた3点）：手は動かさない。重力を受けたまま、留めた点からぶら下がる・回る（`05_carried_dangling.png`）。
- 持った物そのものは、目標の位置と向きに付いてくる。ぶら下がった相手に振り回されないよう、持っている間だけ次の3つをする。
  1. ぶら下がった物の重さを、留めた点で上向きに支える（`_support_hanging()`）。
  2. ぶら下がった物の重さが留めた点に付いたとみて、持った物を回りにくくする（慣性を上げる。`_brace_for_hanging()`。離すと元の値に戻る）。
  3. ぶら下がった物に引かれて変わった進む速さを、その重さの3倍（`HANG_GRIP`）で説明できる大きさまで取り除く。それより大きな勢い（衝突・爆発）は残す。
- 実測：箱馬（5kg）を持ち、横の面の下の縁に重り（12kg）を1点留めて1.5m持ち上げると、重りは約110度回ってぶら下がる。落ち着いたときの箱馬の目標からのずれは、位置0.8cm・向き0.4度。2m歩いて向きを変えても同じ。足場（24kg）をぶら下げても、位置0.3cm・向き0.5度。軽い板（カンペ0.5kg）の縁に同じ重りをぶら下げても、位置1.8cm・向き0.4度。
- 勢いよく持ち上げたり振り回したりすると、ぶら下がった物は大きく振られる（上へ回り込むこともある）。揺れは数秒で落ち着く。
- 面がつっかえる場所で留めると、1点でも垂れない（箱馬の底のまん中に板を留めて持ち上げる：`04_carried_now.png`）。ぶら下げたいときは、縁や角を留める。
- 固めてある物（車体など）に点で留めた物は、持てる。留めた点は外れないので、その点のまわりにだけ動かせる。固く留めた物は、これまでどおり持っても動かない。
- 人が乗っている物と、それに接着でつながった物は、これまでどおり持ち上がらない（床の上を引きずるだけ）。
- 持ち上げずに床を転がす物（台車）は、ぶら下がりを支えない。

## 実装

`adhesive.gd` は、接着の1組ごとに Jolt の点留め（`PinJoint3D`）を1つ作る。計算するのはホストだけ。留める位置は、それぞれの物の上の点（`pa` / `pb`。その物から見た位置）。向きは縛らない。留めた2つの物の当たり判定も切らない（`exclude_nodes_from_collision = false`）。

回る勢いを弱める処理（`_calm_swing()`）は、2つの物の回る速さの差に比例した、同じ大きさで逆向きの回す力を、毎コマ両方へ加える。

- `SWING_DAMP = 1.5`（毎秒）：勢いの弱まる速さ。1秒で約5分の1になる。大きくすると早く止まり、0 にすると止まらない。
- `SWING_REST = 0.05`（rad/秒）：これより遅い回り方には何もしない（止まりかけの物を起こし続けない）。
- 留めた点のまわりの慣性で割るので、軽い物も重い物も同じ速さで落ち着く。
- 留めた点ごとにかかる。同じ2つの物を2点で留めた蝶番は、1点のときより重く動く。

塗布・取消・通常の同期では同じ留め具を保つ。配置の復元（撮り直し）や全体の場面移動（現場へ着く）では `rebuild()` で作り直す。見返しの間は留め具だけ外し（`drop_joints()`）、終わったら覚えた内容から作り直す。全体の位置・姿勢を直接置き直す処理は使わない。

以前の作り（各軸±5度の回転の制限、接着した時の姿勢へ戻すばね、上限を越えそうな回転を打ち消す処理、接着した時の向き `frame_a` / `frame_b`）は無くした。

ほかのスクリプトから使う問い合わせ：

- `connected_ids(pid) -> Array[int]`：起点自身を含む、接着でつながった物のID。現場に無い物を除き、各IDを一度だけ返す。固定の車体も含むので、持つ側は、つながりの中に固定物がある場合を考える。
- `connected_to(pid, carrier) -> bool`：2つの物が接着でつながっているか（間に別の物を挟んでいてもよい）。
- `bond_metrics() -> Array[Dictionary]`：留めてある組ごとの `a`、`b`、`gap`（2つの点の離れぐあい、m）。以前あった `angle` は、接着した時の向きを覚えなくなったので無い。
- `rigid_ids(pid) -> Array[int]`：起点自身を含む、固く留まっている物のID（一直線でない3点以上で留めた相手を、順にたどる）。持つ処理が、手でいっしょに動かす仲間を決めるのに使う。「一直線でない」の線引きは `RIGID_SPREAD = 0.05`（m）。
- `hanging_groups(held) -> Array[Dictionary]`：手で動かしている仲間（`held`、IDの配列）に、点で留まってぶら下がっている物のまとまり。1つのまとまりは `{"bodies": [ぶら下がっている物のID…], "points": [[仲間のID, 留めた点（その仲間から見た位置）]…]}`。固めてある物（車体など）につながるまとまりは、ぶら下がっていないので返さない。

## 確認

- `tests/adhesive_compliance_test.gd`：本物の Jolt の箱だけを使う試験（モデル・ゲームの起動・通信は使わない）。1点留めはどの向きにも大きく回れて元の向きへ戻らない、2点留めは2点を結ぶ線のまわりだけ回る、一直線でない3点はほぼ動かない、すぐ近くにまとめた3点は重さで垂れる、留めた物どうしもぶつかる、ぶら下げた物は揺れて落ち着く、重さの違う物どうしでも暴れない、撮り直し・場面移動のあとも接着が残る、固く留まった仲間・ぶら下がっているまとまりの数え方、近くの相手を選ぶ操作。
- `tests/cargo_adhesive_test.gd`：荷台の箱を離れた3点で車体に留めると、留めていない箱が飛ばされる衝撃でも落ちず、ずれない。離れた点は物を引き寄せない、近づけると留まる、持ったまま留まる、覚えた内容から戻せる、撮り直しと同じ手順（物を覚えた配置へ戻してから接着を戻す）でも接着が残り、弾けない。
- `tests/handling_physics_test.gd`：持って運ぶ確認。木箱の面に板を1点留めて持ち上げると板がぶら下がる、離れた3点で留めた板はいっしょに動く、箱馬に12kgの重りを1点でぶら下げても箱馬は目標から大きくずれない（歩いて向きを変えても）、0.5kgの板に12kgをぶら下げても同じ、離すと回りにくさが元に戻る。
- `tests/adhesive_net_test.tscn`（ホストと参加者の2つを起動）：接着の内容が途中参加・復元で届く。留め具を作って計算するのはホストだけ。
- 参加者は従来どおりホストの物体姿勢を受信する。
