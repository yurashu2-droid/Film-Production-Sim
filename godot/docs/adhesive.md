# 重りと接着剤

荷台の荷物は、床との衝突・摩擦・重力で載る。Gによる固定は廃止。

- 重り：レンタルのサンドバッグ3個。各12kg。軽い物の足元や上へ置くか、接着して支える。固定数や積載容量のボーナスはない。
- 接着剤：会社にあるスプレー接着剤を持ち、Fで塗る操作へ。照準を物の表面へ合わせ、左クリックで1点目、別の物に左クリックで2点目を付ける。
- 黄色い点は接着待ち。Fで塗る操作を終了し、接着剤を置き、物を動かして2点を近づける。12cm以内で点同士が接着し、緑色になる。
- 右クリックは、まだ組になっていない1点目を取り消す。
- 接着した物も重力を受け、持って動かせる。車体に接着すれば車体へ留まり、重りに接着すればその重さで支えられる。
- 接着状態は参加者・途中参加・撮り直しへ同期する。次の依頼では初期配置へ戻して接着を消す。

モデルの出典は `assets/props/ADHESIVE_MODEL.md`。
