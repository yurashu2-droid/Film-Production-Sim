# BGM の音作り・盛り上げの技の辞書（ボカロ・J-POP・EDM でよく使われる物）

リリースカットピアノのような「名前の付いた技」を集めた（2026-10-17 に調べた）。曲を作る・直す前に、使えそうな物をここから探す。
基本の理論・ループの作り方・曲の計画は `BGM_NOTES.md`。書き出しの仕組みは `tools/bgm/bgm.py`（楽譜は `tools/bgm/songs/`）。

各項目の「この仕組みで」の印：
- **済** … `bgm.py` に入っていて、楽譜から使える
- **すぐ** … 書き出した音（numpy の配列）を加工するだけで作れる。まだ書いていない
- **要登録** … 合う UVI の音色を登録すれば作れる
- **注意** … ループ曲では置き場所に気を付ける

## 1. 音そのものを加工する技

### 1-1. リリースカット【済】
- 何をする：音の余韻（リリース）をバッサリ切る。鍵盤を離した瞬間に消える、硬く速い「パキッ」とした音。
- 効く場面：速い曲の刻み、分散和音の「タラララッ」、16分の同音連打（人が弾きにくい機械的なフレーズ）。ピアノとスネアに合う。
- やり方：Release をほぼ0（0だとプツッと鳴るので少しだけ残す）、リバーブ無し、強さは最大でそろえ、コンプで立ち上がりを硬く。
  16分の位置から鳴らし、32分は連打だけ。細かく休符を入れる。サビはオクターブでリードのように。
- この仕組みで：`Part(release_cut=0.006, punch=True, reverb=0.0, vel_jitter=0)`。例は `songs/neon.py`。

### 1-2. サイドチェイン／ダッキング（ポンピング）【済】
- 何をする：バスドラムが鳴るたびに、ベースや和音の音量を一瞬下げて、すぐ戻す。低音の濁りが取れ、曲全体が「呼吸する」。
- 効く場面：4つ打ち（ハウス・EDM）では深めに下げて派手に揺らす。ポップス・ロックは聞いて分からない程度に控えめ。
  ベースは軽く、和音（パッド）は深めで戻りをゆっくり。
- やり方：コンプの入力をバスドラムにする（アタック最速、戻りは次のバスドラムまでに戻り切る長さ）。
  または音量の曲線を描く（4分ごとに、急に落ちて緩やかに戻る形）。かけすぎると全体が不自然に揺れる。
- この仕組みで：曲のファイルに `SIDECHAIN = {'trigger': ('drums', 36), 'parts': {'bass': 8, 'strings': 12}, 'release': {'bass': .5, 'strings': 1.0}}`
  と書く（下げる量[dB]と戻る長さ[拍]）。楽譜のバスドラムの時刻から音量の曲線を作り、書き出した役に掛ける（`sidechain_envelope`）。
  深さの目安：アクション・ハウス（4つ打ち）＝ベース8・弦12、ネオン・ラン＝ベース6・弦10、ポップ＝ベース5・弦8（ポップスは控えめ）。

### 1-3. リバース（逆再生）【済】
- 何をする：音を逆に鳴らす。「スゥーッ」と吸い込んで、次の頭でピタッと止まる。
- 効く場面：シンバルの逆再生をサビの直前に置くと、サビへの期待が高まる（盛り上げの定番）。ピアノの1音ずつの逆再生は、時を戻るような独特の雰囲気。
- やり方：鳴らした音を書き出して、前後を逆にし、終わりが次の拍の頭にそろうように置く。
- この仕組みで：`Part('rev_cymbal', キット, reverse=1.6)` に、終わらせたい拍で音を1つ書く（`revcym.add(サビの頭の拍, 1, 49, 100)`）。
  1回鳴らした音を逆にし、書いた拍でちょうど終わるように貼る（`reversed_hits`）。Hot Rod のシンバルは元の音量が小さいので +3dB 前後。

### 1-4. テープストップ【すぐ／注意】
- 何をする：テープやレコードを止めた時のように、音の高さと速さが一緒に落ちて止まる。
- 効く場面：曲の終わり、キメの直前、フレーズの終わり際をおしゃれに切る。サビで和音が変わるたびに掛ける使い方もある。
- やり方：専用のプラグイン（無料の Kilohearts Tape Stop など）。掛かりを速くすると、フレーズの終わりが締まる。
- この仕組みで：最後の1〜2拍を、だんだん遅く読み出す（時間とともに再生速度を1→0へ）だけ。
  ループ曲では、継ぎ目をまたがない場所（キメの拍など）に限る。

### 1-5. フィルタースイープ【すぐ】
- 何をする：高い音を削るフィルター（ローパス）を、だんだん開く／閉じる。こもった音から明るい音へ、またはその逆。
- 効く場面：イントロ（こもった音から始めて開く）、盛り上げ（低音と高音を少しずつ削って、サビで全部戻す）、
  ラジオや電話の声のような細い音（低音と高音を両方削る）。
- やり方：フィルターの効き目（カットオフ）を、時間とともに動かす。
- この仕組みで：書き出した音を短い区間ごとに区切り、区間ごとに効き目を変えて `pedalboard` のフィルターを掛ける。

### 1-6. スタッター／グリッチ（細かいリピート）【すぐ】
- 何をする：音の短い断片を切り取って、16分や32分で何度も繰り返す。「ダダダダッ」と機械が引っかかったような効果。
- 効く場面：フィルイン、ブレイク、サビ前。時間系（繰り返し・入れ替え・逆再生・テープストップ）と、変調系（音を荒くする・フィルター・ディレイ）がある。
- やり方：専用のプラグイン（iZotope Stutter Edit、Gross Beat など）。自分で組むなら、1〜2拍を切り出し、細かく分けて繰り返し、
  音量に強弱を付け、最後だけフィルターや音の高さの変化を足す。
- この仕組みで：混ぜ終わった音の、フィル小節の手前の断片を、配列で繰り返して貼る。

### 1-7. ゲート（トランスゲート・刻む和音）【すぐ】
- 何をする：伸ばした和音の音量を、16分などのリズムでオン・オフする。伸ばす音が刻む音に変わる。
- 効く場面：盛り上げの和音、段々に上る上昇音（すき間ができて、ほかの音が聞こえる）。
- この仕組みで：`gate_envelope` と同じ考えで、決まった刻みの音量の型を掛ける。

### 1-8. ゲーテッドリバーブ【すぐ】
- 何をする：スネアに大きな残響を付け、その残響を途中でバッサリ切る（80年代の太いスネア）。
- やり方：残響にゲートを掛け、スネアに反応させる。
- この仕組みで：スネアだけ別の役に分け、残響の後に `release_envelope` のような切り方をする。

### 1-9. スーパーソウ／ユニゾン（音の厚み）【要登録／すぐ】
- 何をする：少しずつ音程をずらしたノコギリ波を何本も重ねる（元は 1997 年の Roland JP-8000、7本）。大きく明るい和音とリード。
- 効く場面：EDM のサビ、大きな和音、トランス系のブレイク（余韻を長くして和音で）。
- やり方：ずらしは「別々の音が聞こえ始める」少し手前まで。ずらしすぎると力が無くなる。高い所に厚みを出したいなら低音を削る。
- この仕組みで：スーパーソウの音色を登録する（Prisma の Synth から）。または同じ役を2回書き出し、片方の音程を少し（数セント）ずらして左右に分ける。

### 1-10. ポルタメント・ピッチベンド（音の高さを滑らせる）【済】
- 何をする：音から音へ、高さを滑らせてつなぐ。リードを1オクターブ上の音と重ね、滑らせて残響を付けると、多くのリードの土台になる。
- この仕組みで：`part.fall(拍, 長さ, -3)`（音の終わりをずり落とす「パァ〜↓」＝フォール。ジャズの金管の定番で、とぼけた感じも出る）、
  `part.wah(拍, 長さ, depth, times, drop)`（音程をゆらゆら揺らしながら少し下げる「ワ〜ン」）。10ms ごとにピッチベンドを送り、終わったら戻す。
  ベンドの幅は音色ごとに違う：MPE の音色（City Brass・Saxologie）は上下48半音、ほか（OS Brass Orchestra・UVX-3P Smooth Brass）は上下2半音
  （2026-10-18 に測った）。MPE は自動で48にする。例：`songs/lazy_brass.py`。
- MPE の音色は、押し込みの強さ（チャンネル・アフタータッチ）で音量が決まる。押す・離すだけだとほぼ無音なので、自動で押し込みと CC74 を送る。

### 1-11. ボーカルチョップ【要登録】
- 何をする：声を数十〜数百ミリ秒で細かく切り、音階に合わせて並べ替え、シンセのように鳴らす。言葉の意味が分からなくなった声の楽器。
- 効く場面：イントロ（おしゃれ感）、間奏（飛ばされやすい所を聞いてもらえる）。EDM 寄りのボカロ曲で増えている。
- やり方：母音のはっきりした所を切り出して鍵盤に割り当てる。切り口に短いフェード。休符で間を作る。
- この仕組みで：Prisma の「Vocal」の音色を登録すれば、声の楽器として近いことができる。

### 1-12. 環境音・効果音を入れる【すぐ】
- 何をする：踏切・雨・波・カセットテープ・銃声・ガラスが割れる音などを、ずっと流すか、ここぞという所で1回鳴らす。
- 効く場面：世界観を出す。ブレイクのワンショット。このゲームなら、カチンコ・爆発・「カット！」の声などが合う。
- この仕組みで：ゲームの効果音（`godot/assets/audio/`）を書き出しで重ねる。ただし効果音ラボの音から作った物は再配布できない
  （`sfx_local`）ので、曲に混ぜた物も公開リポジトリに入れない。

### 1-13. 古いレコード加工（ローファイ）【済】
- 何をする：回転の揺れで音程をゆっくりうねらせ（ワウ・フラッター）、高音を削ってこもらせ、少し歪ませ、針のプチプチとシャー音を足す。
- 効く場面：古い映画・古いレコードの雰囲気、ホラーの不気味さ（R.E.P.O. のタイトル曲がこの音。BGM_NOTES 11章）。
  このゲームなら、古い映写機・白黒映画のパロディの場面に合いそう。
- この仕組みで：曲のファイルに `LOFI = {'wow_cents': 20, 'wow_hz': .5, 'flutter_cents': 3, 'flutter_hz': 6, 'lowpass': 2200,
  'low_shelf_db': 6, 'drive_db': 6, 'crackle_per_sec': 25, 'crackle_db': -16, 'hiss_db': -32}`。揺れの周期はループの長さに
  ぴったり合わせるので、継ぎ目でずれない（`lofi`）。例：`songs/repo_lofi.py`。

## 2. 盛り上げ・構成の技

### 2-1. キメ【済】
- 盛り上げの最後の拍で全員が止まり、メロディの拾い上げだけが残る。キメの直前にロングトーンを入れると緩急が付く。例：`neon.py` の16小節目。

### 2-2. ブレイク・無音（間）【済／注意】
- 激しい所の直前か直後に、無音や大きな途切れを入れる。使いすぎない。例：`neon.py` の8小節目（ピアノが駆け上がって途切れる）。
- ループ曲では、継ぎ目の直前に無音を置くと、ゲームで止まったように聞こえやすい。

### 2-3. ビルドアップ（サビ前の盛り上げ）【済】
- 低音（ベースとバスドラムの低い所）を抜く・フィルターで削ると、サビで低音が戻った時に、同じ音量でも大きく感じる。
- 上昇音（白い雑音にフィルターを掛けて開いていく物が基本）、スネアを4分→8分→16分と細かくする、逆再生のシンバル。
- この仕組みで：曲のファイルに `BUILDS = [(56, 64)]`（ループの拍）と書くと、その区間で曲全体の低音をだんだん削り（420Hz の
  ハイパスへ少しずつ移る）、区間の終わり＝サビの頭で一気に戻す（`build_lowcut`）。あわせて楽譜で、サビ直前の1小節のベースと
  バスドラムを抜く。アクション・ハウスでは、サビ直前の1小節の低音が約11dB下がり、サビの頭で戻った（2026-10-17 に測った）。

### 2-4. サビ頭のインパクトと、残響を切る【一部済】
- サビの頭に短い衝撃音（オーケストラヒット、低い「ドーン」、金属のクラッシュ）。盛り上げの残響をサビの頭でバッサリ切ると、サビが締まって聞こえる。
- 例：`action.py`・`neon.py` のオーケストラヒット。残響を切るのはまだ。

### 2-5. ダウンリフター・テール【要登録／すぐ】
- 上昇音の逆。新しいまとまりの頭で「ヒューン」と落ちて、勢いを受け止める。盛り上がりの後に音を足して、落差をなめらかにする（テール）。
- この仕組みで：上昇音（`riser`）を書き出して逆再生すれば近い物になる。

### 2-6. ハーフタイム【済】
- テンポはそのままで、スネアを3拍目だけにして、半分の速さに感じさせる。間奏・落ちサビで対比を作る。例：`action.py` の間奏の前半。

### 2-7. ゴーストノートとフィルイン【一部済】
- ゴーストノート：強拍のあいだに入る、聞こえるか聞こえないかの小さな音。ビート全体の揺れを作る。
- フィルイン：1拍の短いフィルを土台にして、2拍・1小節へ広げる。8ビートも16ビートも同じ考え方。
- 例：各曲のタムのフィル。ゴーストノートはまだ入れていない。

### 2-8. 転調（アニソン・J-POP）【一部済】
アニメの主題歌108曲の調査（Music Theory Online、Li）より：
- 41% の曲に、調の変わる所が少なくとも1回ある。
- 一番多いのは **3度の転調**（短3度上の ♭III へ、または短3度下の VI へ）で、全体の半分以上。
  半音・全音上げ（ポンプアップ）は約2割。
- 置き場所は **盛り上げ→サビの境目** が一番多い（約46%）。次が A→盛り上げ（18%）、イントロ→A（17%）。
- ♭III への転調は、♭VI や iv で「フラット側」の響きを用意し、♭VII（新しい調の V）で盛り上げを終えてから、サビの頭で ♭III を主和音にする。
- サビで調を変えたら、サビの後（ポストコーラス）で元の調へ戻す。戻し方は、サビの調で一度終えてから半音などで飛ぶ／
  元の調の V で終えて解決する／すぐ戻る、の3通り。速い曲ほどポストコーラスがある。
- 例：`neon.py` は2回目のサビを半音上げ、最後の小節を元の調の G7 にして間奏で戻している。3度の転調はまだ使っていない。

### 2-9. ポストコーラス（サビの後の短いまとまり）【済】
- サビの後に、リフや掛け声の短いまとまりを置く。転調したサビから元の調へ戻す役も持つ。例：`neon.py` の間奏、`action.py` の間奏。

### 2-10. ギターは8分の裏から入る【すぐ】
- 小節の頭に音を置かず、8分の裏から入ると軽快になる。ブラッシング（音程の無いチャッ）と実音を組み合わせてカッティングに。歪ませすぎない。

### 2-11. 楽器の役割をまとまりごとに切り替える【済】
- A では装飾的な長い音、盛り上げの後半とサビではリードとして動く（ピアノ・シンセ）。メロディが動く所では伴奏はメロディに合わせ、
  メロディが止まる所で伴奏が自由に動く。メロディのすぐ隣の音は避けて、3度以上離す。

### 2-12. 十二音的な駆け上がり【すぐ】
- 調の音階を気にせず、約4オクターブに音をほぼ均等に散らして駆け上がる。疾走感・冒険感（YOASOBI「勇者」の B の後半のピアノの例が挙げられている）。
  曲調によっては合わないので、短く使う。

## 3. 次に試すなら（このゲームの曲に効きそうな順）

1. ~~サイドチェイン~~・~~逆再生のシンバル~~・~~ビルドアップで低音を抜く~~（2026-10-17 に3曲へ入れた）
4. **サビの頭で残響を切る＋インパクト**。
5. **スタッター**：フィル小節に1回だけ。
6. **3度の転調**：盛り上げ→サビの境目で（アニソンで最多の型）。
7. テープストップ・ボーカルチョップ・スーパーソウは、置き場所や音色の登録を決めてから。
