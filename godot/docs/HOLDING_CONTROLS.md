# 保持と運搬の操作

左クリックした表面点を物体ローカル座標で保存し、その時点の位置と、pitch・yaw・rollを含む姿勢を保持する。
つかむだけでは起こしたり、足元の高さへ持ち上げたり、手元へ引き寄せたりしない。
取得時の視点との相対関係を保存し、その後の視点移動・回転に追従する。
微調整の回転は選んだ表面点を支点とする。つかみ直すと新しい点を使う。

| 操作 | 効果 |
|---|---|
| 左クリック | つかむ／置く |
| 右ドラッグ、Q/E | 回転 |
| Alt+Q/E | roll方向の回転（ロックのない物） |
| Alt+右ドラッグ | 画面の左右・上下へ位置を調整 |
| ホイール | つかんだ位置から奥行きを調整 |
| Shift+右ドラッグ／ホイール／Q/E | 小さく調整 |
| R | 起こす。向きと下面の高さを基準に姿勢を直す |
| L／Shift+L | 20cm持ち上げる／下げる |
| Alt+ホイール | 高さを20cmずつ調整（Shift併用で5cm） |
| G | 一度起こして手元へ引き寄せる。その後の姿勢微調整は残る |

Fの既存操作、非保持時の右クリックによるモニター、中クリック/Vの目印は継続する。
R/G/Lは保持中の準備・カウントダウン・撮影時だけ使用する。
自分が乗っている保持物、または接着でつながった支持物の補助操作は、降りてから使用する。
支持している間は、足場の移動を保持目標へ戻す循環を避け、支持物との接触を残す。
接着は保持によって解除しない。

## 実装の境界

- `act_grab(pid, local_grip = null)` / `h_grab()` の追加引数は、レイヒットを物体ローカル座標へ変換したVector3。省略時は従来のコード呼び出し用に中心を使う。実クリックは省略しない。
- `prop.gd` の `hold_grip_local` に選んだ点、`hold_transform` に基準姿勢、`hold_view_transform` に視点基準を保存する。
- `main.gd:hold_target()` は従来の4要素を残し、5要素目に完全なBasis、6要素目に表面点のワールド目標を追加する。基準が未設定の機材用呼び出しは従来の目標を返す。
- `act_hold_command(command, amount)` / `h_hold_command()` のcommandは `upright`、`lift`、`pull`。
- `hold` / `hold_adjust` の形は `[owner, pid, snapshot]`。snapshotの追加項目は `grip_local: Vector3`、`view_transform: Transform3D`。基準姿勢・操作状態・世代番号も一緒に同期する。
- 移動パケットの8引数APIは継続する。追加操作は `send_hold_controls(dist, yaw, pitch, offset, roll, revision)` / `rx_hold_controls()` の専用パケットで同期する。補助操作前の古い操作パケットは新しい保持目標を上書きしない。
- 接着の判定は既存の `adhesive.connected_to(pid, carrier)` を利用し、接着側のAPIを変更しない。
- 保持側の目標速度と1物理フレームで加える速度変化を抑える。自由な物体の速度、衝突・爆発の速度を切り詰める世界共通の上限は設けない。
- キャスター付きの物は保持中だけ接触摩擦を最大0.08にし、箱型の接触形状でも転がして運べるようにする。質量を維持し、解放時に元の摩擦へ戻す。旧修正の45kg駆動2m/s²が床摩擦0.9に負ける問題を確認し、通常操作の駆動も扱いやすい応答へ戻している。
- 物理状態から重心を読み、回転中の中心移動を補償して表面点を支点にする。物体のTransformを直接移動させる処理ではない。
- スクリプトの構造・保持状態・RPC引数を変更したため、既存セッションへ状態を残して読み直す場合も、確認時はシーンを再構築する。

## 検証と統合

局所検証・ログは `artifacts/hold-local-20261012/`。専用ネット試験のポートは24816。
既存テストと `run_tests.sh` はこの担当では変更しない。
自動引き寄せを前提とする `carrytest`、`nettest`、`autotest`、カンペの自動整列の期待値は、新仕様では明示操作と区別して確認する。
全体の検証と公開commit/pushは統合担当へ引き継ぐ。

2026-10-12の局所確認では、取得時の姿勢保存、明示操作の物理的な目標到達、古い操作パケットの拒否、保持による速度変化の制限、支持物をつかんで90物理フレームの安定、制作モードのAPI互換性を確認した。
ENetホスト／参加者の専用試験は接続、取得姿勢、位置・roll、持ち上げの同期、世代番号、古いパケット、解放を確認した。
制限環境ではENetの接続待ちが時間切れとなり、許可された制限外のlocalhost実行で通過した。固定ポート試験は実行していない。
