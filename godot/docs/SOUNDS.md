# 音の一覧（ある音・足りない音）

2026-10-17 に、スクリプトの中で鳴らしている音を全部洗い出した。音の出どころと加工は `assets/audio/README.md`、
鳴らし方は `scripts/sfx.gd`（名前で鳴らす）・`game.host_ev("sfx", [名前, 場所])`（全員に鳴らす）。

## ある音

| 場面 | 音 |
| --- | --- |
| 体の動き | 足音・着地・車輪のロボットの走る音（`features/motion_sounds.gd`） |
| 物の扱い | 掴む（pickup）・置く（drop）・どすん（thump。特技で物が落ちる時だけ）・積む（load）・固定（fix）・外す（unfix）・風切り（whoosh・whoosh_soft） |
| 撮影 | カチンコ（clap）・カウントダウン・合図（cue）・成功（success_fanfare） |
| 仕掛け | 導火線（fuse）・爆発・不発・怪獣の鳴き声（roar）・突風（wind） |
| 移動 | 出発のエンジン（engine）・段差（bump）・門（gate） |
| 画面 | 全部のボタンの乗せる・押す（ui_hover・ui_press）。開く・戻る・決定・失敗（ui_open など）は一部の操作で |
| その他 | 電話（phone_ring）・拍手（applause） |

## 足りない音（優先の順）

1. ~~画面のボタン~~：済み（2026-10-17。全部のボタンに、乗せる「カチ」・押す「カシャッ」）。
   Escape・メニュー・台本を開く・閉じる音も済み（ページをめくる・本を閉じる。menu_open・menu_close）。
2. ~~車輪のロボット（M02）~~：済み（2026-10-17。走っている間、車輪とモーター。着地は足のあるキャラと同じ音）。
3. **物がぶつかる・落ちる音**：投げた物・吹き飛んだ物・倒れた物が、地面や物に当たっても無音（風切りのあとが無音）。
   今は手を離した時の「置く」と、特技の「どすん」だけ。→ 当たった速さと物の重さ・材質で鳴らし分ける。
4. **軽トラ・乗り物の走る音**：出発の時のエンジンだけで、走っている間は無音（`vehicle_ride.gd`・`truck.gd`）。
5. **道具ごとの音**：撮影カメラ（録画の開始・止め・ズーム）、接着剤（付ける・はがす）、カンペ・看板を描く（ペン）、
   火薬の袋（さらさら）、表情えらび、演技を呼ぶ、モニターの切り替え、ロープを張る・切れる。
6. **場所の音（環境音）**：町のざわめき・遠くの車・風。画面（メニュー）では要らないと決めたが、
   ゲームの中は無音のままで、足音などが浮いて聞こえる原因の一つかもしれない。試して決める。
