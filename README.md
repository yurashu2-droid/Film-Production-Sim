# 格安アクション映画制作班（試作）

大作映画の無茶な依頼を、わずかな機材と廃材で撮り切る協力ゲームの試作です。
最初の依頼「月下の城と大爆発」を、一人で「仕込み → 本番 → 確認 → 見返し → 納品」まで遊べます。

## 動かし方

Godot 4.7.2（Windows 64bit）が必要です。本体は容量が大きいためこのリポジトリには入れていません。

1. Godot 4.7.2 を入手し、`tools/godot/` に `Godot_v4.7.2-stable_win64.exe` と `Godot_v4.7.2-stable_win64_console.exe` を置く
2. `play_solo.bat` を実行する（初回は素材の取り込みに少し時間がかかります）

Godotのエディタから `godot/project.godot` を開いて実行しても動きます。

- `play_lab.bat`：モーション・演出を繰り返し確認する専用Lab（撮影ゲームと独立）
- `play_host.bat` / `play_join.bat`：同じネットワーク内での協力プレイ（ホスト方式・試験段階）
- `run_tests.sh`：画面なしの自動確認（ソロ2通り、失敗側、ホスト＋参加者。カチンコの奪取と保護も確認）
- `run_tests.sh --graphics`：上記に加え、画面つきで持ち物の回転・持つ姿・拡大した荷台、置き直しとソロ2通りの納品までを確認。FPSは画像保存を挟まない連続2秒で計測

## 操作

| 操作 | キー |
|---|---|
| 移動・走る・ジャンプ | WASD・Shift・Space |
| 持つ／置く、距離、回す | 左クリック、ホイール、右ドラッグ（Q・Eも可） |
| 固定／解除 | G |
| カメラ・ライトを操作 | F |
| 段ボールを開く／閉じる | 箱を持つ、または照準を合わせて F |
| キャラクター選択 | C（依頼画面・仕込み中） |
| 本番開始／カット | T |
| 合図（告白・爆発・再会） | 1・2・3 |
| 役者を立ち位置へ戻す | B |
| 見本のセットを組む | F9 |
| あそびかた | Tab |

右ドラッグ中は視点を止めて持ち物を回します。台車・三脚カメラは倒さず左右に回転します。段ボールと台車は各辺2倍（体積8倍）、荷台と当たり判定も同じ倍率です。

段差から降りて着地すると短くのけぞり、走り始め・急停止にも専用モーションが入ります。物を持っている間は腕の構えを保ちます。走り始めは短いためから加速し、歩行から走るときは現在の速度を保ちます。入力を離すと走り出しを中断します。

段ボールの4枚のふたを開閉できます。開くと中が空き、閉じると上に乗れるようになります。キャラクターは7種類からプレビューを見て選べます。選択後も位置と持ち物は保たれ、箱の開閉と見た目は参加者間で同期されます。

## Motion Lab

`play_lab.bat` を開くと、7キャラを選んで「走り始め → 加速 → 走行 → 停止」を試せます。Enterで再生、Pで一時停止・再開、`.`で1コマ送り（ゲーム内の1/60秒）、Rで先頭へ戻ります。0.5倍速、繰り返し、横・斜め・正面の視点も選べます。

「走行ループを確認」を選ぶと走り続け、全周期の足の動きを見られます。足のある6キャラには、靴底が沈む分だけ表示の高さを上げる補正を入れています。腕振り、歩幅、骨の角度、再生速度、移動と接地の処理は元のままです。ジャンプには適用しません。ロボットの車輪も元の動きです。

元のGLB素材・アニメーションは変更していません。Labの「足の埋まり補正」をOFFにすれば即座に元の表示へ戻せます。ゲーム全体を元へ戻す場合は `godot/project.godot` の `[animation]` にある `foot_grounding=true` を `false` に変更します。この修正前の状態はタグ `motion-before-foot-fix-20261007`（コミット `9788a88`）にも残っています。

足元のトゥーン土ぼこりは自作の改良版を標準にしています。蹴り出しでは地面を擦る短い筋と大きめの煙が出て、凹凸のある塊が転がり、小片へ崩れながら約1.2秒で消えます。走行中は左右の靴底が接地したときに小さな煙を出します（車輪のキャラは移動距離に合わせて出ます）。ジャンプ中・歩行中・物を持っている間には出ません。通常ゲームでも同期し、本番の見返しへ記録されます。

Labの「煙」で「自作・塊と余韻（改良版）」「元の自作の丸い煙」「Kenneyの無料素材」を比較できます。元の2方式は蹴り出しだけの演出をそのまま残しています。演出のON/OFF、大きさ（0.5〜1.5倍）、通常速度と0.5倍速も選べます。Labでの調整はゲーム本体には自動保存されません。

ゲーム全体を元の自作版へ戻す場合は `godot/project.godot` の `[vfx]` にある `dash_dust_style="sculpted"` を `"mesh"` に、無料素材版なら `"kenney"` に変更します。[Kenney Smoke Particles](https://kenney.nl/assets/smoke-particles) は無料素材（CC0）で、原画・ライセンス・出典を `godot/assets/vfx/kenney_smoke/` に収録しています。

「現在のコマをPNG保存」で、画像とフレーム・速度などのJSONを `%APPDATA%/Godot/app_userdata/格安アクション映画制作班/motion_lab/` に保存します。画面にも保存先が表示されます。床表示を外して足の動きも確認できます（接地判定は維持）。

## 構成

- `godot/scripts/`：ゲーム本体（`main.gd` が進行、`judge.gd` が撮影条件の判定）
- `godot/assets/`：キャラクター、小道具、撮影機材のモデル
- `godot/tests/`：自動確認用のスクリプト
