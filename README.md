# 格安アクション映画制作班（試作）

大作映画の無茶な依頼を、わずかな機材と廃材で撮り切る協力ゲームの試作です。
事務所で受注し、道具を選び、廃材と機材を軽トラへ積み、現場で撮って納品するところまで遊べます。会社の資金と売上は、その実行中の次の仕事へ持ち越されます。

## 動かし方

Godot 4.7.2（Windows 64bit）が必要です。本体は容量が大きいためこのリポジトリには入れていません。

1. Godot 4.7.2 を入手し、`tools/godot/` に `Godot_v4.7.2-stable_win64.exe` と `Godot_v4.7.2-stable_win64_console.exe` を置く
2. `play_solo.bat` を実行し、「ひとりで遊ぶ」「友達を招く」「友達の会社へ」を選ぶ（初回は素材の取り込みに少し時間がかかります）

友達へフォルダごと渡せるWindows版は `godot/tools/build_portable.ps1` で作れます。生成先と起動方法は [持ち運び版の説明](godot/docs/production/portable.md) にまとめています。

Godotのエディタから `godot/project.godot` を開いて実行しても動きます。

- `play_lab.bat`：モーション・演出を繰り返し確認する専用Lab（撮影ゲームと独立）
- `play_vfx.bat`：爆発・炎・煙・飛び道具・落雷を単体で眺めるVFX Lab
- `play_host.bat` / `play_join.bat`：同じネットワーク内での協力プレイ（ホスト方式・試験段階）
- `run_tests.sh`：画面なしの自動確認（ソロ2通り、失敗側、ホスト＋参加者。カチンコの奪取と保護も確認）
- `run_tests.sh --graphics`：上記に加え、画面つきで持ち物の回転・持つ姿・拡大した荷台、置き直しとソロ2通りの納品までを確認。FPSは画像保存を挟まない連続2秒で計測

ホストの事務所には参加用IPとコピー操作を表示します。同じネットワークの友達が起動画面へ入力して参加できます。ホストが会社を閉じたときは参加者も起動画面へ戻り、再参加・ひとりプレイを選べます。会社を閉じるとその実行中の残金と撮影は終了します。

## 制作会社の一日

初回の荷物選び・役割分担・撮影の順番は [最初の一本](godot/docs/production/first-game.md) にまとめています。

通常起動は「事務所 → 依頼 → 購入と積み込み → 軽トラ移動 → 現場 → 精算 → 帰社」。同じ脚本を倉庫・小さな室内スタジオ・野外ロケの3現場で撮れます。初期資金600コイン、道具は1仕事あたり最大600コイン。無料廃材も使い、積んだ物だけ現場へ運びます。

持った物は軽トラのそばで **F** を押すと荷台へ。カメラとカチンコを積み、全員が車のそばに集まれば、手ぶらで **F** または出発ボタンから8秒の移動が始まります。現場を借りられるのは **10分**。期限後も撮ったテイクを納品できます。成立した場面ごとに報酬が増え、全成立なら1200コイン。失敗作でも150コインで次の仕事へ進めます。資金の永続保存と物理運転はまだありません。

Downloadsの昇降台と清掃カートも無料で使えます。照準を合わせて **F** で、実素材の昇降・絞り機のアニメーションが動きます。昇降台のカメラは台と一緒に上下します。素材の出典と寸法は `godot/assets/production/` に記録しています。

現場ごとに追加注文があります。倉庫は最初のテイクで成功、室内はスタッフの映り込み0.5秒以内、野外は月を合計2秒映す。本編3場面と追加注文を両方満たすと150コイン追加です。テイクごとに記録し、納品するテイクで精算します。失敗時の基本報酬は減りません。映り込んだ制作班と早すぎた爆発は、精算画面のこぼれ話に残ります。

竜の頭・魔女の鍋・トマト怪獣も廃材置き場から持ち込めます。竜の頭は持ったまま **F** で口を開閉。遠近法で怪獣にしても、鍋を謎の儀式に使っても構いません。トマト怪獣は抱えて運べる1.4mの小道具です。

従来の撮影だけの試作は `play_film.bat`（または `--legacy`）から遊べます。元の `main.tscn` とMotion/VFX Labも残しています。

## 操作

| 操作 | キー |
|---|---|
| 移動・走る・ジャンプ | WASD・Shift・Space |
| 持つ／置く、距離、回す | 左クリック、ホイール、右ドラッグ（Q・Eも可） |
| 固定／解除 | G |
| カメラ・ライトを操作 | F |
| 段ボールを開く／閉じる | 箱を持つ、または照準を合わせて F |
| キャラクター選択 | C（依頼画面・仕込み中） |
| 本番開始／カット | カチンコを持ってF ／ Tでカット |
| 合図（告白・爆発・再会） | 1・2・3 |
| 役者を立ち位置へ戻す | B |
| 見本のセットを組む | F9（撮影だけモード） |
| 仲間へ「ここ！」目印（制作モード） | V・中クリック |
| 結果画面で見返して8コマPNG保存（制作モード） | P |
| 保存した映画画像のフォルダを開く | O |
| あそびかた | Tab |

制作モードの結果画面で **P** を押すと、選んだテイクを見返しながら8コマの映画画像を保存します。8枚（640×360）と2列4行の一覧PNG（1280×1440）、テイク情報のJSONを、押した参加者の `%APPDATA%/Godot/app_userdata/格安アクション映画制作班/film_stills/<日時>/` に保存します。保存後は **O** でフォルダを開けます。撮影カメラの映像だけなので、操作HUD・目印・IP表示は入りません。全員での見返しはRと同じです。8枚が揃う前に見返しが終わる、借り時間が切れる、会社を閉じると保存を中断します。

制作モードでは **V・中クリック** で視線の場所や道具を仲間に知らせます。30m以内の物理面に発信者名付きの目印が5秒表示され、同じ人の指示は1つに更新されます。移動中・結果・見返し・メニュー操作中には使えません。目印は撮影映像や追加注文の映り込みには含まれません。

右ドラッグ中は視点を止めて持ち物を回します。台車・三脚カメラは倒さず左右に回転します。段ボールと台車は各辺2倍（体積8倍）、荷台と当たり判定も同じ倍率です。

段差から降りて着地すると短くのけぞり、走り始め・急停止にも専用モーションが入ります。物を持っている間は腕の構えを保ちます。走り始めは短いためから加速し、歩行から走るときは現在の速度を保ちます。入力を離すと走り出しを中断します。

段ボールの4枚のふたを開閉できます。開くと中が空き、閉じると上に乗れるようになります。キャラクターは7種類からプレビューを見て選べます。選択後も位置と持ち物は保たれ、箱の開閉と見た目は参加者間で同期されます。

## Motion Lab

`play_lab.bat` を開くと、7キャラを選んで「走り始め → 加速 → 走行 → 停止」を試せます。Enterで再生、Pで一時停止・再開、`.`で1コマ送り（ゲーム内の1/60秒）、Rで先頭へ戻ります。0.5倍速、繰り返し、横・斜め・正面の視点も選べます。

「走行ループを確認」を選ぶと走り続け、全周期の足の動きを見られます。足のある6キャラには、靴底が沈む分だけ表示の高さを上げる補正を入れています。腕振り、歩幅、骨の角度、再生速度、移動と接地の処理は元のままです。ジャンプには適用しません。ロボットの車輪も元の動きです。

元のGLB素材・アニメーションは変更していません。Labの「足の埋まり補正」をOFFにすれば即座に元の表示へ戻せます。ゲーム全体を元へ戻す場合は `godot/project.godot` の `[animation]` にある `foot_grounding=true` を `false` に変更します。この修正前の状態はタグ `motion-before-foot-fix-20261007`（コミット `9788a88`）にも残っています。

足元のトゥーン土ぼこりは自作の改良版を標準にしています。蹴り出しでは地面を擦る短い筋と大きめの煙が出て、凹凸のある塊が転がり、小片へ崩れながら約1.2秒で消えます。走行中は左右の靴底が接地したときに小さな煙を出します（車輪のキャラは移動距離に合わせて出ます）。ジャンプ中・歩行中・物を持っている間には出ません。通常ゲームでも同期し、本番の見返しへ記録されます。

Labの「煙」で「自作・塊と余韻（改良版）」「元の自作の丸い煙」「Kenneyの無料素材」を比較できます。元の2方式は蹴り出しだけの演出をそのまま残しています。演出のON/OFF、大きさ（0.5〜1.5倍）、通常速度と0.5倍速も選べます。Labでの調整はゲーム本体には自動保存されません。

ゲーム全体を元の自作版へ戻す場合は `godot/project.godot` の `[vfx]` にある `dash_dust_style="sculpted"` を `"mesh"` に、無料素材版なら `"kenney"` に変更します。[Kenney Smoke Particles](https://kenney.nl/assets/smoke-particles) は無料素材（CC0）で、原画・ライセンス・出典を `godot/assets/vfx/kenney_smoke/` に収録しています。

「現在のコマをPNG保存」で、画像とフレーム・速度などのJSONを `%APPDATA%/Godot/app_userdata/格安アクション映画制作班/motion_lab/` に保存します。画面にも保存先が表示されます。床表示を外して足の動きも確認できます（接地判定は維持）。

## VFX

エフェクトは `godot/vfx/` にまとめています。エディタを使わずスクリプトとシェーダーで組み、必要な画像素材は `godot/assets/vfx/` に収録しています。

- **爆発**（効果機）：溜めの火花 → 閃光 → 火球 → 火花・破片・衝撃波 → 土煙 → 黒煙 → 残り火。テスト発火と爆炎の書割は小さい版
- **炎** / **煙**（アニメ調・フラット） / **飛び道具**（炎・秘術・毒。溜め・軌跡・着弾つき） / **落雷**：いまはVFX Labと部品としてのみ。ゲームの進行にはまだ使っていません
- **走りの演出（アニメ調）**：スミア（体が自分の色のまま後ろへ伸び、少し前のポーズが網点で重なる）、伸びた先は白く尖り、まわりを光らない白い曲線が流れる）・スミア × 雷（スミアの先がぎざぎざの雷の光になり、放電が散る）・雷の疾走（飛び道具と同じ組み立てで、オーラ・軌跡・放電をまとう）。Motion Labの「煙」の選択肢に並んでいます。ゲーム全体で使うには `godot/project.godot` の `[vfx]` にある `dash_dust_style` を `"smear"` / `"volt"` / `"thunder"` に変更します。土ぼこりの新しい版「蹴り上げ」（輪郭線つきの塊が順に弾け、尾を引いて巻き上がる。`"kick"`）と、脚が車輪のように重なって回る「脚ぐるぐる＋蹴り上げの煙」（`"scramble"`）も同じ選択肢にあります（標準は土ぼこりの `"sculpted"` のまま）

- **ドカン着地** / **火柱** / **気合のオーラ**：無料素材 [LeLu's Noise Pack](https://leluvfx.gumroad.com/l/freeTextures) の連番アニメや炎の絵を使ったもの。素材とライセンスは `godot/assets/vfx/lelu_noise/` に収録。VFX Labのみ

`play_vfx.bat` で一覧から選んで眺められます。←→で切り替え、Enterでもう一度、Pで一時停止、ドラッグで回転、ホイールで拡大。スロー再生と、撮影カメラの明るさでの確認もできます。「旧・爆発」は差し替え前の見た目です。

提供動画を基準にした白熱火球・火柱・炎輪・地面の炎は `play_vfx.bat --only=mushroom`。構成・消え方・参考との差は `godot/vfx/MUSHROOM.md`。所有者提供のLeLuパックの炎素材を使用しています。

自然現象をモチーフにした5試作（太陽・間欠泉・クシクラゲ・磁性流体・種さや）もLabに収録。`play_vfx.bat --only=motif_solar` で開けます。提示後に流れの要求を反映していないと指摘された案で、成功例ではありません。出典・構成・呼び出しIDは [MOTIFS.md](godot/vfx/MOTIFS.md)。

作り方・呼び出し方・確認手順は `.claude/skills/godot-vfx/SKILL.md` にまとめています（Claude Code はスキルとして読み、ほかのエージェントは `AGENTS.md` から辿れます）。

## 構成

- `godot/vfx/`：エフェクト（共通部品 `vfx_lib.gd`・土台 `vfx_base.gd`・各エフェクト・シェーダー・VFX Lab）
- `godot/scripts/`：ゲーム本体（`main.gd` が進行、`judge.gd` が撮影条件の判定）
- `godot/assets/`：キャラクター、小道具、撮影機材のモデル
- `godot/tests/`：自動確認用のスクリプト
